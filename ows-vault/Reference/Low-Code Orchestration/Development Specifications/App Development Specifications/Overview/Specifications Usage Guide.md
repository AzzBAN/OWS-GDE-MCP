# Specifications Usage Guide

The specifications cover all orchestration scenarios supported by GDE and are classified into general development specifications and security development specifications. General development specifications are classified based on orchestration scenarios, including: UI, function, process, API, network automation, RPA, data, and agent orchestration, basic specifications, and custom asset orchestration. Due to the complexity of app development, an app may involve the combination of multiple orchestration capabilities. Developers need to perform comprehensive check based on orchestration capabilities. For example, when you orchestrate a page, read and comply with the basic specifications and UI orchestration specifications.

From the perspective of security, security development specifications include access control, authorization, data verification, sensitive data protection, exception handling, logging, anti-DoS, anti-phishing, privacy protection, malicious operation prevention, and others. One specification involves multiple orchestration scenarios. Therefore, from the perspective of security, each specification is marked with applicable orchestration scenarios. Developers need to determine the involved orchestration scenarios and read and comply with the corresponding specifications.
