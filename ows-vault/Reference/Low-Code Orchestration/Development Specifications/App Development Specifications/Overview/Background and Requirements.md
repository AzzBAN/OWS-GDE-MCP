#### Background

GDE provides a development mode, which helps developers create an asset program that can run on the GDE app execution engine by simply dragging-and-dropping and compiling low-threshold script codes. Different from traditional computer programming, developers can focus on the service design without spending too much time on programming languages.

GDE lowers the development barrier and the skill requirements for developers who may be inexperience in programming, have no equivalent computer security capabilities, or develop low-quality or insecure assets.

Based on Huawei's security, reliability, availability, and serviceability baselines, the specifications development team summarizes best practices of asset orchestration and formulates this document to help developers comply with compliance requirements, avoid repeated mistakes, and improve development quality and efficiency.

General principles:

-   General development specifications: Excellent codes are not only correct, but also concise, maintainable, reliable, testable, efficient, and portable. Programming is a creative work. Coding specifications are used to instruct developers to form proper programing habits and write high-quality and readable clean codes with consistent styles.
-   Security development specifications: Excellent codes should be secure. Security specifications are used to enhance the security awareness of developers in the development process, enable the developers to think as attackers, form the habit of writing codes securely, and write secure and reliable codes.
