# Rule: Package Names and Python Standard Library Names Must Be Different

**Description**: When you write code in Python, the name of the created package cannot be the same as that of the standard Python library. Otherwise, the system displays a message indicating that the module fails to be loaded. For example, **json**, **lib**, or **os**.

Standard library: [https://pypi.org/](https://pypi.org/)

**Tool supported or not**: no

**Specification name**: General\_FaaS\_Package\_Cannot\_Same\_as\_The\_Python\_Standard\_Library

**Severity**: minor
