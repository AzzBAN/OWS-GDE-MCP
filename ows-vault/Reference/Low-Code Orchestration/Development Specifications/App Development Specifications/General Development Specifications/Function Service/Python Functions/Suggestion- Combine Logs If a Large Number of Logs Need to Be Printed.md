# Suggestion: Combine Logs If a Large Number of Logs Need to Be Printed

**Description**: Logs printed by the function service contain many identifiers, such as the time, tenant ID, and project name. The maximum length of run logs is 4 MB. Therefore, if a large number of logs need to be printed, you are advised to combine logs. Do not print a small number of characters in each line.

**Tool supported or not**: no
