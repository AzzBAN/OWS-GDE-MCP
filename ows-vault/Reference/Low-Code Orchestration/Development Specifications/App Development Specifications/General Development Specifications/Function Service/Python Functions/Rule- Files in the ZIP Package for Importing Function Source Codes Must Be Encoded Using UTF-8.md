# Rule: Files in the ZIP Package for Importing Function Source Codes Must Be Encoded Using UTF-8

**Description**: The file must be encoded using UTF-8. The encoding declaration **\# coding: utf-8** can be added to the file header.

**Check guide**: Check the file format when submitting the file.

**Positive example**: # coding: utf-8

**Tool supported or not**: no

**Specification name**: General\_FaaS\_The\_Files\_in\_the\_Package\_Must\_Be \_Encoded\_Using\_UTF\_8

**Severity**: minor
