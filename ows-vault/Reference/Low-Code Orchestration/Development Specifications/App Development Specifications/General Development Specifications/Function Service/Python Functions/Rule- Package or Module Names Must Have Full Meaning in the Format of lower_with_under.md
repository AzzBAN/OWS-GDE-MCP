# Rule: Package or Module Names Must Have Full Meaning in the Format of lower\_with\_under

Description: Modules should be named in the style of lowercase letters and underscores (\_), for example, **lower\_with\_under.py**. Although existing modules are named like **CapWords.py**, this naming is not recommended because a confusion comes if a module has the same name as a class.
