# Rule: Total Length of Input Parameters of the Function Service Cannot Exceed 90,000 Characters and That of Output Parameters Cannot Exceed 8,000 Characters

**Description**: The total length of input parameters of the Python function service cannot exceed 90,000 characters, and that of output parameters cannot exceed 8,000 characters.

**Tool supported or not**: no

**Specification name**: General\_FaaS\_Input\_Param\_Length

**Severity**: major
