# Suggestion: Use the Preconfigured Model Data to Import Initialized Data

**Description**: The system allows you to import Excel initialization data through customized assets and preset data through models. The capabilities in customized assets are mainly used for function compatibility.

**Check guide**: Check whether Excel initialization data exists in customized assets.

**Positive example**: Use the data presetting capability of the model.

![[en-us_image_0000001965136262.png]]

**Negative example**: If an Excel template is used to import data, the model can be used to preconfigure data capabilities.

![[en-us_image_0000001616524438.png]]

**Tool supported or not**: no

**Specification name**: General\_Custom\_Import\_Initialization\_Data\_Using\_Model\_Preset\_Data

**Severity**: suggestion
