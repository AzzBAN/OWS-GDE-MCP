# Rule: Use Notes in the Operator Combination Template

**Specification name**: General\_DataFactory\_Operator\_Combination\_Use\_Notes

**Description**: When defining an operator combination template, you need to use a note to describe the service logic of each operator and their combination in the template, so that other users can quickly understand the template functions when using the template.

**Check guide**: Check whether note description is included when the operator combination template is defined.

**Negative example**: The operator combination template contains only operator combinations without notes.

**Impact**: When other users reference the template, they cannot quickly and effectively get the usage mode of the template, which greatly increases the usage difficulty.
