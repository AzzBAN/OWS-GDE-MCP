# Suggestion: Use Metadata Models to Describe Data in a Unified Manner and Select Models to Set Attributes of the Extraction and Loading Operators

**Specification name**: General\_DataFactory\_Common\_Orchestration\_Metadata\_Model

**Description**: During data orchestration, you can manually configure operator attributes, such as the table name, column information, and data source, or select a model to set the operator attributes. Models can be used to automatically create tables and share data. In addition, assets can be accumulated, and models can be shared. You are advised to use metadata models to describe data in a unified manner. During orchestration, select models to configure attributes of the extraction and loading operators.

**Check guide**: Check whether operator attributes are configured by selecting metadata models.

**Impact**: If you comply with this term, you will have better development experience and higher development efficiency. In addition, unified metadata management and control can eliminate data inconsistency between apps.
