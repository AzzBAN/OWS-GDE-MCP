# Suggestion: Save the Content in a Timely Manner During Development to Prevent Content Loss

**Specification name**: General\_DataFactory\_Common\_Orchestration\_Save

**Description**: DataFactory can automatically save the draft to the cloud at a scheduled time. However, if an exception occurs during the interval between two automatic saving operations, the orchestrated content will be lost. You are advised to save the content in a timely manner during orchestration. If the content is lost unexpectedly, click **Restore from Draft** on the toolbar to obtain the data cached last time.

**Impact**: Drafts that are not automatically or manually saved will be lost.
