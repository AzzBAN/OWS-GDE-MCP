# Suggestion: Use Notes to Record Key Business Information and Implementation Logic to Improve App Maintainability

**Specification name**: General\_DataFactory\_Common\_Recommending\_Use\_Knowledge\_Note\_Function

**Description**: You can use notes to combine design solutions with implementation, describe a long data flow by category and phase, decompose data flows, and better explain data flow functions. This greatly improves the readability and maintainability of the orchestrated business logic.

**Check guide**: Check whether key business logic design and complex data conversion processing logic are recorded using notes.

**Impact**: If the key business logic design or complex data conversion processing logic is not recorded, the app maintainability will be poor.
