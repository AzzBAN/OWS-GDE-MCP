# Suggestion: Enable Smart Repair Before Modifying a Complex Flow to Improve Modification Efficiency

**Specification name**: General\_DataFactory\_Common\_Recommending\_Use\_Smart\_Repair\_Function

**Description**: Before modifying a complex flow, you are advised to click ![[en-us_image_0000001236944723.png]] on the toolbar to enable smart repair. In this way, the attributes of downstream operators can be modified and saved in a timely manner when the current operator is modified, greatly improving modification efficiency.

**Check guide**: Before modifying a complex data flow, check whether smart repair is enabled.
