# Suggestion: Use the Breakpoint and Branch Suspension Capabilities as Needed to Improve the Efficiency of Online Debugging and Problem Analysis

**Specification name**: General\_DataFactory\_Efficient\_Online\_Debug\_Analysis

**Description**: DataFactory provides the breakpoint and branch suspension capabilities for step-by-step debugging. By properly using breakpoints and branch suspension, you can efficiently analyze problems. During step-by-step debugging, you can add breakpoints to operators that you are more concerned about. In this way, you can obtain the running result of the breakpoint operator as soon as possible. In addition, you need to reduce unnecessary breakpoints as much as possible. Otherwise, the running efficiency decreases. You can use the branch suspension function to suspend an operator that is not concerned. After a branch is suspended, it will not be executed during the running process, improving execution efficiency.

**Version**: Functions such as step-by-step commissioning are supported in 2.1.0 and later versions.
