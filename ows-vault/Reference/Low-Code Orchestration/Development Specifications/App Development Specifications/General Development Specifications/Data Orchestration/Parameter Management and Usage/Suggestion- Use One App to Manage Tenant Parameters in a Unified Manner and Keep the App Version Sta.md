# Suggestion: Use One App to Manage Tenant Parameters in a Unified Manner and Keep the App Version Stable

**Specification name**: General\_DataFactory\_Tenant\_Parameter\_Centralized\_Management

**Description**: You are advised to manage tenant parameters of a tenant in a centralized manner. For example, use an app to define and manage tenant parameters, manage the app package as a basic one, and keep the app version stable.

**Check guide**: Check whether tenant parameters are centrally managed by one or a few apps.

**Positive example** Use the _xxx_\_Parameter-1.0.0 app to manage the tenant parameters in the _xxx_ domain.
