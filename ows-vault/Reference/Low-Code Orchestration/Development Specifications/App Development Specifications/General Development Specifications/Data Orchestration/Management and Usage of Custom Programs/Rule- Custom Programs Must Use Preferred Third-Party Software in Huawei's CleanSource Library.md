# Rule: Custom Programs Must Use Preferred Third-Party Software in Huawei's CleanSource Library

**Specification name**: General\_DataFactory\_Custom\_Programs\_CleanSource

**Description**: Open-source, third-party software used by custom programs must be available in Huawei's CleanSource library.

Using software in the CleanSource library can effectively avoid software aging issues and internal vulnerabilities.

**Check guide**: Check whether the open-source, third-party software used by the custom program is available in the CleanSource library.

**Impact**: Using non-preferred software may cause compliance issues.
