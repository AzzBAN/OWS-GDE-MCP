# Rule: The Custom Program Released with the App Must Pass the ICSL Security Inspection

**Specification name**: General\_DataFactory\_Custom\_Programs\_Security

**Description**: The custom program released with the app must pass the ICSL security inspection.

**Impact**: Programs that are not sent for security inspection may cause compliance issues.
