# Suggestion: Each Business Team Should Comply with the Unified App Planning, Theme Domain Division, and Entity Naming Rules During the Data Model Definition, Ensuring Standard Data Model Definition

**Specification name**: General\_DataFactory\_Data\_Model\_Definition\_Standardized

**Description**: During data modeling, it is recommended that each business team plan the app package scope and business domain division in a unified manner, promoting standardized data modeling.

**Positive example**: The business experience team plans several sub-theme topics in the SEQ Analyst customer analysis app SEQ.CUSTOMER\_ANALYSIS. The planning is clear, and the names are easy-to-understand.

| SEQ\_CUSTOMER\_ESA |
| SEQ\_CEM\_VIP\_MBANKING |
| PERIOD\_REPORT\_CUSTOMER |
| CUSTOMER\_ANALYSIS\_5G |
| CUSTOMER\_ANALYSIS |
| SEQ\_VIP\_VOICE | **Impact**: Non-standard model definition and app development may cause some issues, such as siloed apps and repeated construction.
