# Suggestion: Preprocess Data Before Processing It

**Specification name**: General\_DataFactory\_Stream\_Data\_Preprocessing\_Before\_Data\_Processing

**Description**: Preprocess data before processing it.

**Check guide**: Analyze the operator input data and check whether the input data format is consistent with that of the physical model.

**Impact**: If the input content does not match the data format, abnormal data may be generated, an error may be reported, and the flow may even fail to be executed.
