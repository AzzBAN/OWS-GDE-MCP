# Suggestion: When Data Skew Occurs and Multiple Connection Operators Are Used to Associate and Combine Multiple Tables to Generate a Big Table, Use Union and Group Operators to Orchestrate Data to Reduce the Impact of Data Skew

**Specification name**: General\_DataFactory\_Batch\_LightETL\_Filtering\_Some\_Fields

**Description**: When data skew occurs and multiple Connection operators are used to associate and combine multiple tables to generate a big table from the same dimension, you can use the Union and Group operators to orchestrate data to reduce the impact of data skew.

**Check guide**: Check whether data skew occurs during processing using the Connection operators.
