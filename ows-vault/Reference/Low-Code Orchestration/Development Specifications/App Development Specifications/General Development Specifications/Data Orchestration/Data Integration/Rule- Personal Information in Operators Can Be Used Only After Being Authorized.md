# Rule: Personal Information in Operators Can Be Used Only After Being Authorized

**Specification name**: General\_DataFactory\_AIP\_After\_Obtaining\_Authorization\_User

**Description**: Personal information in operators, such as mobile numbers, email addresses, ID card numbers, and bank card numbers, can be used only after being authorized.

**Check guide**: Check whether the orchestrated app flow contains personal information such as mobile numbers, email addresses, ID card numbers, and bank card numbers.

**Impact**: Serious personal information leakage may occur.
