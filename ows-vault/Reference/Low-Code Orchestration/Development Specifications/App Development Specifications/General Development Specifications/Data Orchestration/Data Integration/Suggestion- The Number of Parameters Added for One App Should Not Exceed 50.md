# Suggestion: The Number of Parameters Added for One App Should Not Exceed 50

**Specification name**: General\_DataFactory\_AIP\_Avoiding\_Parameter\_Too\_Many

**Description**: Too many flow parameters are inconvenient for app upgrade, configuration, modification, and fault locating, affecting app development efficiency. It is recommended that a maximum of 50 parameters be configured for one app.

**Check guide**: Check whether the number of flow parameters added during app parameter editing exceeds 50.

**Impact**: The app development efficiency is affected, and the app maintenance cost increases.
