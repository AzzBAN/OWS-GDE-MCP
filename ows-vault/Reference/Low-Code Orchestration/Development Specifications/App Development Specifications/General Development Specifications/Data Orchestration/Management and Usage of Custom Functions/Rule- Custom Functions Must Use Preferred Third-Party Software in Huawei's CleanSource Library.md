# Rule: Custom Functions Must Use Preferred Third-Party Software in Huawei's CleanSource Library

**Specification name**: General\_DataFactory\_Custom\_Function\_CleanSource

**Description**: Open-source, third-party software used by custom functions must be available in Huawei's CleanSource library.

Using software in the CleanSource library can effectively avoid software aging issues and internal vulnerabilities.

**Check guide**: Check whether the open-source, third-party software used by the custom function is available in the CleanSource library.

**Impact**: Using non-preferred software may cause compliance issues.

**Version**: Custom functions are supported in 2.3.0 and later versions.
