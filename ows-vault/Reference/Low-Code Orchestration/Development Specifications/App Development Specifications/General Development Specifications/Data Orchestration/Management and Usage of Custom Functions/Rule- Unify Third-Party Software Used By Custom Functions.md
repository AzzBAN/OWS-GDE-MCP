# Rule: Unify Third-Party Software Used By Custom Functions

**Specification name**: General\_DataFactory\_Custom\_Function\_OpenSource\_Normalization

**Description**: The versions of the same third-party software called by custom functions must be unified.

Purposes of unification:

-   To manage open-source software and versions used in the product in a unified manner.
-   To reduce the cost of fulfilling open-source software license obligations.
-   To keep consistent with the technology development trend of the community.
-   To reduce software vulnerabilities and improve product quality.

**Check guide**: Check whether the versions of the same third-party software called by custom functions are unified.

**Impact**: Using non-unified software may cause compliance issues.

**Version**: Custom functions are supported in 2.3.0 and later versions.
