# Rule: The Custom Function Program File Released with the App Must Pass the ICSL Security Inspection

**Specification name**: General\_DataFactory\_Custom\_Function\_Security

**Description**: The custom function program file released with the app must pass the ICSL security inspection.

**Impact**: Programs that are not sent for security inspection may cause compliance issues.

**Version**: Custom functions are supported in 2.3.0 and later versions.
