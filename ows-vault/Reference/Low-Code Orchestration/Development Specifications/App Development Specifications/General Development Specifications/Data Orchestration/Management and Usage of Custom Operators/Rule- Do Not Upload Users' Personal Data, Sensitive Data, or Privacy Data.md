# Rule: Do Not Upload Users' Personal Data, Sensitive Data, or Privacy Data

**Specification name**: General\_DataFactory\_Custom\_Operator\_Upload\_No\_Sensitive\_Data

**Description**: Custom operators should not contain any personal data, sensitive data, or privacy data.

**Check guide**: Check whether the uploaded custom operator contains personal data, sensitive data, or privacy data. Such data includes numbers that can identify natural persons, bank accounts, original communications content (emails and SMS messages), keys, session IDs, verification codes (including SMS verification codes), session tokens, and passwords (such as voucher passwords).

**Impact**: Using users' personal data, sensitive data, or privacy data in custom operators may violate laws, damage Huawei's reputation, affect Huawei's finance or operations, and have adverse impact on personal data subjects to different degrees.
