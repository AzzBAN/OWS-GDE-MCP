# Rule: Preferred Third-Party Software in Huawei's CleanSource Library Must Be Used for Custom Operators

**Specification name**: General\_DataFactory\_Custom\_Operator\_CleanSource

**Description**: Open-source, third-party software used by custom operators must be available in Huawei's CleanSource library.

Using software in the CleanSource library can effectively prevent software aging issues and internal vulnerabilities.

**Check guide**: Check whether the open-source, third-party software used by the custom operator is available in the CleanSource library.

**Impact**: Using non-preferred software may cause compliance issues.
