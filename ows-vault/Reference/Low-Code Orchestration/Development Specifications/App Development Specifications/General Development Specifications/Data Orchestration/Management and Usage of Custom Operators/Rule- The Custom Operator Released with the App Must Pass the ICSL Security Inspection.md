# Rule: The Custom Operator Released with the App Must Pass the ICSL Security Inspection

**Specification name**: General\_DataFactory\_Custom\_Operator\_Security

**Description**: The custom operator released with the app must pass the ICSL security inspection.

**Impact**: Custom operators that are not sent for security inspection may cause compliance issues.
