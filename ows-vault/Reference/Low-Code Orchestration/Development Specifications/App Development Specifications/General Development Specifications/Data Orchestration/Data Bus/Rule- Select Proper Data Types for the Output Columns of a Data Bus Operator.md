# Rule: Select Proper Data Types for the Output Columns of a Data Bus Operator

**Specification name**: General\_DataFactory\_DBUS\_Output\_DataType\_Selection

**Description**: Select a proper data type when defining an output column. For example, if you want to select the Numeric type, consider whether the precision is sufficient.

**Check guide**: Check whether the data types of the output columns can adapt to the source data.

**Impact**: If an improper data type is selected, data precision is affected or the task fails to be executed.
