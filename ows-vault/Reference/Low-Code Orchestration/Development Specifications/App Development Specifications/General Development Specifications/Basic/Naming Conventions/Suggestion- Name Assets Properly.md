# Suggestion: Name Assets Properly

**Description**: You need to clearly understand the asset usage to prevent misleading and conflicts between different teams during asset development.

**Check guide**:

Check whether the asset name complies with the following format: _Domain/Product (abbreviation)_**\_**_Function_. The underscore (\_) is a recommended separator and can be replaced by a hyphen (-). Do not use periods (.) as a connector.

The value can contain a maximum of 20 characters and must start with a letter.

Internationalized asset names must be easy to read and separated by spaces.

**Positive example**:

Asset name: SEQ\_SERVICE\_ALARM

Internationalized asset name: SEQ Service Alarm

**Negative example**: SERVICE\_ALARM

**Tool supported or not**: no

**Specification name**: General\_Basic\_Proper\_Asset\_Name

**Severity**: suggestion
