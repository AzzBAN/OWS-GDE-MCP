# Suggestion: Name Orchestration Elements Properly

**Description**: To help users clearly understand the design and development intent of orchestration elements, the name is the comment.

**Check guide**:

Check whether the names of orchestration elements in the asset are clearly defined and comply with the specifications. It is recommended that the elements be named using underscores (\_) and lowercase letters (use underscores (\_) to separate words). For a unique orchestration element of a tenant, the domain name or app module name must be added as the prefix.

**Positive example**: create\_alarm

**Negative example**: createalarm

**Tool supported or not**: no

**Specification name**: General\_Basic\_Proper\_Element\_Name

**Severity**: suggestion
