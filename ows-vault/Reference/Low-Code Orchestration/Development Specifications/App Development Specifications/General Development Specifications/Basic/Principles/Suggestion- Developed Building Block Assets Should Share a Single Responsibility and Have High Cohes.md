# Suggestion: Developed Building Block Assets Should Share a Single Responsibility and Have High Cohesion and Low Coupling

**Description**: Building block assets with a single responsibility can be easily reused and the maintenance cost is low. Therefore, the reusability of these assets must be considered during design and development.
