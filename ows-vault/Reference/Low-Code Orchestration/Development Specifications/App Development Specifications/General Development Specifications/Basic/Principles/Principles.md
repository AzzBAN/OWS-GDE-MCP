# Principles

From the perspective of development and running, assets are classified into apps and building blocks. Apps are assets that can be directly deployed in the runtime state. Building blocks are assets used for development and reuse. Different building block assets can be assembled into apps. There are dependencies and calling relationships between assets, and you need to define proper constraints to facilitate continuous asset evolution.
