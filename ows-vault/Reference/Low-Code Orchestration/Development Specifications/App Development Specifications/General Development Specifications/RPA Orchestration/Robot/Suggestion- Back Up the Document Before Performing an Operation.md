# Suggestion: Back Up the Document Before Performing an Operation

**Description**: Before performing an operation on the existing service data document, back up the original document. After the script is executed, delete the backup file.In this way, you can restore the data based on the backup file if the file is damaged due to exceptions during the execution.

**Check guide**: none

**Tool supported or not**: no

**Specification name**: General\_RPA\_Use\_Backup\_Document

**Severity**: suggestion
