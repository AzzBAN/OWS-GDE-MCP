# Suggestion: Move Basic Data Verification Operation Forward

**Description**: Before running the service operation script, you need to check whether the basic data format and data meet the script requirements. If yes, run the script. Otherwise, an error is reported.

**Check guide**: none

**Positive example**: In the current script, the control for verifying the data format is put in front of the main process.
