# Suggestion: Number of Controls in a Script Should Be Less Than 100

**Description**: If the number of controls in a script is too large, the script size is too large, which is hard to be maintained.

**Check guide**: Check the script content and the number of actions.

**Positive example**: The number of controls in each script in a robot project is less than 100.

**Tool supported or not**: no

**Specification name**: General\_RPA\_Component\_Number\_Less\_Than\_100

**Severity**: suggestion
