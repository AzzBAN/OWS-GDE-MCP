# Suggestion: Do Not Manually Modify the XML Process File

**Description**: When developing an RPA process, you are advised to use the RPA control in drag-and-drop mode. Do not directly edit the XML file of the process. The XML file contains the execution logic and dependency of the entire process. Incorrect modification may cause process execution exceptions.
