# Suggestion: Properly Plan the Number of Knowledge Bases and Tools Used by the Model

**Description**: During agent orchestration in autonomous model planning mode, you can select tools and knowledge bases for the foundation model to plan, use, and retrieve. It is recommended that the number of knowledge bases used by a single agent be less than or equal to 3 and the number of tools be less than or equal to 5 to ensure the usage effect.

![[en-us_image_0000002403637633.png]]

**Check guide**: Check the number of selected tools and knowledge bases on the page of the agent in autonomous model planning mode. It is recommended that the number of knowledge bases be less than or equal to 3 and the number of tools be less than or equal to 5.

**Tool supported or not**: no

**Specification name**: General\_Agent\_Tool\_Knowledge\_Less\_Than\_5

**Severity**: suggestion
