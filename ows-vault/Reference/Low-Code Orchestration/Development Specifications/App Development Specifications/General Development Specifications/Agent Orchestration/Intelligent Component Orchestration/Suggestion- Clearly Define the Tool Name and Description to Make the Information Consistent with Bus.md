# Suggestion: Clearly Define the Tool Name and Description to Make the Information Consistent with Business Capabilities

**Description**: The agent orchestration provides the tool customization capability. The business side can customize tools based on site requirements. It is recommended that the tool name, description, input and output parameter names, and parameter description be clear and consistent with the business capabilities, and be friendly to the foundation model. In this way, the foundation model can be accurately planned based on the names.

**Check guide**: Check whether the tool name and description as well as the names and descriptions of input and output parameters are proper and clear on the agent tool management page.
