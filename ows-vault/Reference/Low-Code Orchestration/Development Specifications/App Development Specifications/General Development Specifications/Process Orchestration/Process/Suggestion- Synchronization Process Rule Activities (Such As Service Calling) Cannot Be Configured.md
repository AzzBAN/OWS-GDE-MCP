# Suggestion: Synchronization Process Rule Activities (Such As Service Calling) Cannot Be Configured

**Description**: If synchronized rules are configured, the ticket execution efficiency may be affected, and problems, such as blocking and timeout, may occur.

**Check guide**:

Go to the page for viewing process rules and check whether the synchronization function is enabled. Disable it for all rules if unnecessary.
