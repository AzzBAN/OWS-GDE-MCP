# Suggestion: Process of the New Version Must Be Copied to If Major Modifications (Such As Adding or Deleting a Phase) Exist

**Description**: When a process is greatly modified, you can modify the copied process of the new version to prevent misoperations and commissioning from affecting the original process.

**Check guide**:

1.  Copy the modified process.
    
    ![[en-us_image_0000001657681581.png]]
    
    ![[en-us_image_0000001657841609.png]]
    
2.  Open and edit the new process.
3.  Release the process after editing it.
