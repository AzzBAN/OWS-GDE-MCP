# Suggestion: Configure a Default Group

**Description**: After a default group is configured, the ticket can be processed by members in the group.

**Check guide**:

Choose **Products and Services** > **Administration** > **Process Management** > **User Default Group Configuration** and check whether the default group is configured for the user.
