# Suggestion: Configure Less Than Ten SLAs for a Single Process

**Description**: Too many SLAs affect the execution efficiency. In addition, the SLAs may be overlapped, incorrect, or concurrent, which is inconvenient for understanding, maintenance, and fault locating.
