# Suggestion: Configure Less Than Ten Rules for a Single Phase in a Process

**Description**: If too many assignment rules are configured for a single phase, the execution efficiency is affected, errors may occur and cannot be easily located, making the subsequent process maintenance inconvenient. Extracting and merging assignment rules based on conditions and activities is recommended.

**Check guide**:

1.  In the **Operation** column of a process, choose **More** > **Manage Rule**.
    
    ![[en-us_image_0000001520607497.png]]
    
2.  On the displayed rule management page, query the number of rules in the phase and view the total number of rules.

**Positive example**:

The number of rules configured for a single phase in the process is less than the recommended value.

**Negative example**:

The number of rules configured for a single phase in the process is greater than the recommended value.
