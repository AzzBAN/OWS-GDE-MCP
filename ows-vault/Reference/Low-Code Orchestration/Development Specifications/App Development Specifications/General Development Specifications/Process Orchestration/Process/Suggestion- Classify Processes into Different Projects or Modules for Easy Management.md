# Suggestion: Classify Processes into Different Projects or Modules for Easy Management

**Description**: It is recommended that processes be classified into different projects or modules for easy management. Especially when there are many processes, classify closely related processes into one project or module.

**Check guide**:

1.  Create a project and a module on the **Asset Management** page.
2.  After the module is created, create a process under the module.

**Positive example**:

For example, you can create the test process in the test module.
