# Rule: Ensuring Normal Process Running When There Is Only One Egress If Configured Conditions on an Exclusive Gateway's Egress Connection Line Are Met, or a Default Egress Is Specified When No Condition Is Matched

**Description**: To ensure that the workflow can be smoothly transferred under various conditions, conditions need to be properly configured for the egress connection line of an exclusive gateway and there must be only one egress under any condition or a default egress connection line is specified.

**Check guide**:

Check whether conditions are configured for the egress connection line of the exclusive gateway and whether the workflow can be smoothly transferred under various conditions.
