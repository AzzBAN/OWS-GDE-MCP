# Suggestion: Error Code Cause and Solution Should Be Useful for Users

**Description**: The cause and description of the error code must be useful for users. The error code cause indicates the cause of an error, for example, parameter verification failure or incorrect status. The solution is provided for users to rectify faults, for example, check the input parameters.

**Check guide**: Check whether the error code definition is proper in the develop-state environment.

**Positive example**: Cause: The site ID can contain only letters, digits, and underscores (\_). Solution: Check whether the entered site ID meets the requirements.

**Tool supported or not**: no

**Specification name**: General\_ErrorCode\_Meaningful\_ErrorCode

**Severity**: suggestion
