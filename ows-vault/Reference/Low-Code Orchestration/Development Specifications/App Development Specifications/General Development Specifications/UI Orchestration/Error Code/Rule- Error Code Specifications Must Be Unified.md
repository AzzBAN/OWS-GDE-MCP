# Rule: Error Code Specifications Must Be Unified

**Description**: You are advised to use an eight-digit error code. The first four digits indicate the module and the last four digits indicate the error code. For example, **01010001**.

**Check guide**: Check whether the error code is properly defined in the develop-state environment.

**Tool supported or not**: yes

**Specification name**: General\_ErrorCode\_Unified\_Specifications

**Severity**: suggestion
