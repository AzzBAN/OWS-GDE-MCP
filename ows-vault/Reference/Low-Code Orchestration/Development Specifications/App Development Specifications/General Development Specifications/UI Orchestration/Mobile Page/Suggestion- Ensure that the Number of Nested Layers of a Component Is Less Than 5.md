# Suggestion: Ensure that the Number of Nested Layers of a Component Is Less Than 5

**Description**: If the number of nested layers of a component on a page exceeds the upper limit, page rendering will take a long time and page loading becomes slow.

**Check guide**: Reduce the number of nested layers of a component to improve the efficiency.

**Negative example**: There are too many nested layers of a component.
