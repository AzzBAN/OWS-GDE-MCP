# Suggestion: Use the Functions Provided by MessageProcessor to Handle API Requests

**Description**: In API requests, the loadData(opt) and process(opt) functions provided by MessageProcessor are used to obtain data, and the submitData(opt) function is used to submit requests. The client calls the unified native API to effectively solve common problems such as cross-domain access and account expiration.
