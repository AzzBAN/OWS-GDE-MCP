# Suggestion: Properly Define the Hierarchy of the Permission Tree

**Description**: The hierarchy of the permission tree must comply with the service logic, for example, User Management > User Query.

**Check guide**: 1. Check the rationality of the permission tree in the develop-state environment. 2. View the permission tree on the permission assignment page in the runtime-state environment.

**Tool supported or not**: no
