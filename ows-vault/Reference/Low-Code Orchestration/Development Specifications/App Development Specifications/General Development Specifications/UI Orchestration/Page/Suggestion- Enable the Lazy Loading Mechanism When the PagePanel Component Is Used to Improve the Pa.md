# Suggestion: Enable the Lazy Loading Mechanism When the PagePanel Component Is Used to Improve the Page Loading Speed

**Description**: When the PagePanel component under Tab is used, you are advised to set **Lazy Load** to **true**.

**Check guide**: Check whether the value of **Lazy Load** is **true**, excluding the first Tab.
