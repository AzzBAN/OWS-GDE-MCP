# Suggestion: Use the Page Panel Component During Page Loading to Improve Performance and Enable the Lazy Loading Mechanism to Improve the Page Loading Speed

**Description**:

1\. You are advised to replace the Frame Panel component with the Page Panel component to improve the page loading performance.

2\. When the Page Panel component under **Tab** is used, you are advised to set **Lazy Load** to **true**.

**Check guide**: 1. Check whether the Frame Panel component is used during page configuration. 2. Check whether the value of **Lazy Load** is **true** and skip the check for the first tab.
