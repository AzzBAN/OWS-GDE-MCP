# Suggestion: URLs of APIs in the Same Project Should Use the Same Root Path and URLs of APIs in Different Projects Should Use Different Root Paths

**Description**: APIs of the same project have the same URL prefix, and APIs of different projects have different URL prefixes. This effectively prevents API conflicts when GTS Product Convergence Solution is used and standardizes the API style.

**Check guide**:

1\. Go to the **Develop API** page, click the API name, and check whether the basic paths of all APIs are the same.

![[en-us_image_0000001520824489.png]]

2\. Access different projects and check whether the basic API paths are different.

**Tool supported or not**: no

**Specification name**: General\_API\_Use\_Identical\_Location\_In\_Project

**Severity**: suggestion
