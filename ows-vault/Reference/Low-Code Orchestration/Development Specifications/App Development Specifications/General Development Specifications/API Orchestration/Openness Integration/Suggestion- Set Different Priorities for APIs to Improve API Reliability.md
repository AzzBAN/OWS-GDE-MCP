# Suggestion: Set Different Priorities for APIs to Improve API Reliability

**Description**: The runtime engine logically isolates APIs of different priorities. That is, resource pools of different resource levels are used to reduce the impact of the system on APIs of high priorities.

**Check guide**: Go to the **Develop API** page, click the API name, and check whether the priorities of all APIs are properly configured under **More Settings** in the **Basic Information** phase.
