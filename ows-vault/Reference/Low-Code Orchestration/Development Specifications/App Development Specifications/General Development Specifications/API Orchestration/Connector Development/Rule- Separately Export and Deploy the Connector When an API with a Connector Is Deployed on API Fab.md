# Rule: Separately Export and Deploy the Connector When an API with a Connector Is Deployed on API Fabric in Runtime State

**Description**: The asset package exported from the **Develop API** page do not contain connectors.

![[en-us_image_0000002106764734.png]]

**Check guide**: After exporting the connectors from the **Connector** page, import the API asset package and connector asset package to API Fabric in runtime state.

![[en-us_image_0000002142482745.png]]

**Tool supported or not**: no

**Specification name**: General\_Connector\_And\_API\_Exporting\_Data\_Separately

**Severity**: major
