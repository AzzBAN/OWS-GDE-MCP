# Suggestion: Reduce Unnecessary Integration Log Recording

**Description**: There are four types of integration logs. The number of logs recorded for each type is different. To reduce system resource consumption, only necessary logs need to be recorded.

**Check guide**: Check whether the settings for saving integration logs are proper.

**Positive example**:

![[en-us_image_0000001475442164.png]]

**Negative example**: The function of recording all logs is configured but is not actually required by services.

**Tool supported or not**: yes

**Specification name**: General\_Integrate\_Avoid\_Unnecessary\_Integration\_Logging

**Severity**: suggestion
