# Appendix 2: Examples of Personal Data

Data is categorized based on the data source, content, and usage.

  
| Category | Personal Data Type | Remarks |
| :-- | :-- | :-- |
| Communication related data | Mobile number | Includes the phone number, fax number, and other communication numbers containing the phone number, such as a SIP number or mobile station international ISDN number (MSISDN). |
| Email address | Includes the email address and voice mailbox address. |
| Address book | Includes the contact list (group names and members), friend group, blacklist group, and address book. |
| Communications app account | Includes the instant message (IM) app, social app, and real-name BBS accounts and passwords. |
| Terminal device ID | Uniquely identifies a device (such as a computer, network adapter, mobile phone, or smart card), such as the MAC address, international mobile subscriber identity (IMSI), international mobile equipment identity (IMEI), temporary mobile subscriber identity (TMSI), and CDMA mobile equipment identifier (MEID). |
| Original content of communication | Includes the actual communication content between two parties (one party is a natural person), including the voice, SMS/MMS, fax, and data service (such as IMs, emails, video communication, and web browsing). |
| Personal identity | Authoritative social identity number | Includes the ID card number, social/insurance security number, driver's license, passport number, and visa authorization number. |
| Birth information | Includes the birth date, birth place, age, and other information that can be used to deduce a birth (such as constellations and Chinese zodiac). Note: Birth information includes birth-related information calculated through the Gregorian calendar and other common calendars. |
| Family information | Includes the marital status, family member information (name), and family composition. |
| Others | Includes the name, gender, signature, annuity, personal characteristics, work category, work place, activity type, professional background and achievement, behavior preferences, photos, voice, geographical data, traffic data, race, nationality, ethnicity, political opinions, religious belief, philosophical or moral principles, Trade Union membership, political parties, religious organizations, personal identification numbers, health status (health diagnosis information and disability information), medical record, genetic data, biological feature data (fingerprint and iris), sexual orientation, criminal record, prison record, disciplinary action, military service, SN, UDID, Android ID, and IMSI. |
| Location and topology | Logical address | Includes the logical addresses, such as the IPv4 address, IPv6 address, and MAC address of the personal device, base station ID or cell ID (CELL ID), and wireless access point ID, and other open ports. |
| Personal location information | Information such as GPS coordinates |
| Address and postal code | Includes the family address, temporary address, work address, postal code, and billing address. |
| Asset consumption | Asset status | Includes bank deposits, credit limits, credit records, current account balances, and historical balances. |
| Asset account | Includes the bank account, ebank account, network virtual asset account (such as Alipay), credit card number, and USERID (corresponding to the account). |
| Consumption and payment information | Includes the consumption amount, consumption details (bills and credit card bills), consumption method, and invoice ID. |
| Revenue information | Includes the income amount and composition. |
| Personal financial information | Includes the fines information, financial status/data, personal asset, and bank account information. |
| Historical records | Private browsing history | Includes the browsed URL list, cookies, session IDs, Flash cookies, HTTP logs, and browsing history. |
| Operation mode and app usage frequency | Includes the most frequently used apps (for example, website browsing and gaming most accessed by a mobile phone user) and the number of calls per day. Note: The app usage frequency is not personal data. However, if it is used together with IMSIs and IP addresses, data subjects can be identified and the involved data is personal data. The operation habits and usage frequency of users are collected for analyzing user behaviors. Generally, the collected information can be used by specific users. | Note: Personal devices refer to devices that are used by individuals and serve individuals.
