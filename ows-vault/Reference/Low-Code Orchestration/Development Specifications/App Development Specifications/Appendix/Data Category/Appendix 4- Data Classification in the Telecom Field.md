# Appendix 4: Data Classification in the Telecom Field

-   **Data in the BSS domain**: refers to data of the customer care and billing, charging, customer service, and settlement systems, such as the real-name authentication data, package data, mobile number, terminal model, traffic consumption data, call duration, bonus points, and complaints.
-   **Data in the OSS domain**: refers to Internet access behavior data, signaling data, and location data. Take data collected over the Gn interface as an example. The data includes web/WAP access log data, URL parsing data, application parsing data, and network track data.
-   **Data in the MSS domain**: refers to ERP data, portal management data, and project management data.
-   **Data in the virtualization domain**: refers to data of the virtual value-added services, including traditional enhanced services and basic services.
