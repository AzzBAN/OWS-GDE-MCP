# Terminology

**Table 1** Term explanation  
| Term Involved in this document | Description |
| :-- | :-- |
| General Digital Engine (GDE) | GDE is a platform+intelligence+agility universal engine that meets GTS service requirements and is provided for services. The engine includes the basic services & framework, data analysis service, AI service, ADC, and O&M operation center. |
| Application Development Center (ADC) | ADC is a key product in GDE that enables online orchestration. It provides the no-code/low-code/pro-code approaches for developers to build apps, supporting business scenarios. |
| Huawei IT Service (HIS) | Huawei IT service |
| HEC (Huawei Enterprise Cloud) | Huawei enterprise cloud |
| Data Cube | Data Cube is a big data processing platform of GDE. It provides one-stop data development and operation solutions for GTS solutions, carriers, enterprises, and partners, helping customers build independent and controllable big data platforms and data capability openness centers to maximize data value. |
| DataFactory | DataFactory is a big data development platform of Data Cube. It mainly uses the No-Code and Low-Code development modes and uses the Pro-Code development mode as a supplement. DataFactory provides development capabilities in all scenarios (including data access, exploration, modeling, processing, debugging, and governance), depending on the common capabilities of GDE and ADC. DataFactory supports asset accumulation and reuse, and helps business developers efficiently develop data apps to maximize data value. |
| Operation Web Services (OWS) | OWS is an online app development platform constructed based on the GDE capability. The online development capability is constructed based on ADC. OWS provides a series of cloud services for fields, such as communications network operation and management, service process management, asset and resource management, and fault and performance management. |
| Application (App) | An app is a collection of configurations and codes that are developed on GDE ADC and contain required functions. It can run on one or more servers or VMs. |
| BB (Building Block) | BB assets are used for secondary development. For example, common page components, page templates, and project templates are BB assets. |
| International Organization for Standardization (ISO) | An international association dedicated to establishing global standards for communications and information exchange. Its main achievement is the widely accepted ISO/OSI model, which defines the standards for the interaction of computers connected by a communications network. |
| Robotic Process Automation (RPA) | Record manual actions and develop codes to form a robot. The computer runs the robot to simulate manual operations, improving efficiency. |
| Artificial Intelligence (AI) | A technical science that studies and develops theories, methods, and applications for simulating and extending human intelligence. |
| User Interface (UI) | Operation interface between the user and system. |
| Top Query Language (TQL) | A language developed by Huawei GDE team to query top data, for example, top 10 data records. |
| Application Programming Interface (API) | A particular set of rules and specifications that are used for communication between software programs. | **Parent topic:** [[Appendix|Appendix]]
