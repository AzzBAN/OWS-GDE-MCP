# Rule: Functions Orchestrated Based on Process Customization Must Be Associated with Permission Items

**Description**:

1\. The permission items automatically generated during process orchestration may be different from those used in the actual service application scenario. You need to adjust the permission items based on service requirements.

2\. Permission items need to be customized for customized functions and managed based on the minimum permission principle.

**Tool supported or not**: no

**Specification name**: Security\_Authority\_BPM\_\_No\_Control

**Severity**: major

**Orchestration scenario**: process orchestration
