# Rule: Do Not Use the MML and TL1 Non-SSL Protocols for Network Automation

**Description**: If an insecure protocol, such as MML or TL1, is used to create a credential, you need to add the SSL configuration to the probe configuration.

**Check guide**: Check whether insecure protocols, such as MML and TL1, are used for connection.

**Specification name**: General\_MCP\_InsecureProtocol

**Severity**: major

**Orchestration scenario**: RPA orchestration
