# Rule: Security Guardrail Function Must Be Enabled During Agent Orchestration and Release

**Description**: During agent orchestration and release, the topic restriction and security guardrail functions must be enabled.

**Check guide**: Log in to the agent orchestration WebUI and check whether the topic restriction and security guardrail functions are enabled on the **Safety Guardrail Settings** page.
