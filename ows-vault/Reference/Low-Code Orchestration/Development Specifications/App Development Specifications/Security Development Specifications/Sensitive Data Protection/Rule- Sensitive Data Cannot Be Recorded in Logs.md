# Rule: Sensitive Data Cannot Be Recorded in Logs

**Description**: Passwords that include unencrypted and ciphertext passwords, keys, and other sensitive data cannot be recorded in logs. Handle sensitive data as follows:

-   Do not record sensitive data in logs.
-   Use asterisks (\*) with a fixed length to replace sensitive data if sensitive data must be recorded in logs due to special reasons.
-   Do not directly record the message body in logs because there is a high probability that sensitive data exists.
-   Sensitive data or content containing sensitive data cannot be used as the input of a log operator.
-   Debugging logs recorded in the orchestration script cannot be desensitized. All logs are recorded in the API debugging log file. Recording sensitive data violates the redline requirements.

For details about sensitive data types, see Appendix 1.

**Check guide**:

1.  Go to the develop-state environment, select the app to be checked, check the pages and server code one by one, and ensure that the code of the recorded logs does not contain sensitive data.
2.  Check whether the logs generated by the Python or Ruby script contain sensitive data.
3.  For API development and process orchestration, perform the following operations:
    
    (1) On the API development or process orchestration page, open all Service and Task diagram elements.
    
    ![[en-us_image_0000001716254833.png]]
    
    (2) Check all **log.error** statements in the orchestration scripts of all diagram elements and check whether the log content contains sensitive information.
    
    ![[en-us_image_0000001716255113.png]]
    

**Involved scenarios**:

Service scripts compiled using JavaScript and command scripts compiled using Python or Ruby

**Negative JS example**:

Recorded server logs

var logger = JsLogger.logger;

logger.info("Login success ,user is " + userName + "password is" + pwd);

**Negative example of a command script**:

logger = LoggerFactory.getLogger("PythonForSSH")

logger.info("Login success ,user is " + userName + "password is" + pwd)
