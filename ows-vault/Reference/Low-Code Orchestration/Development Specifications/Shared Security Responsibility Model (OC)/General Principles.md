# General Principles

General Digital Engine (GDE) provides a secure, reliable, and scalable cloud computing platform and various tools. It regards the confidentiality, integrity, and availability of customer services and data as its first priority for security.

Currently, GDE is built on Huawei HEC to provide services for tenants. Therefore, HEC, GDE, and tenants jointly build a security framework for cloud infrastructure, platform services, and data. Different from local data centers, when tenants transfer data to the cloud, HEC, GDE, and tenants share the security responsibilities. HEC ensures the security of the underlying infrastructure and basic platform. GDE ensures the security of the public service platform and the services and applications on the platform. Tenants ensure the security of their own accounts, data, and assets after secondary development. This mechanism is called the "Shared Security Responsibility Model".

In most cases, GDE and HEC have provided necessary security assurance measures. Tenants do not need to pay more attention to cloud configuration and service security. This reduces operation pressure and enables tenants to focus on their own service operation.
