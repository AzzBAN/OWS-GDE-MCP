# HEC's Security Responsibilities

All HEC services run on its global infrastructure, and HEC protects this infrastructure. The infrastructure includes physical data centers, hardware, software, networks, and auxiliary equipment. Protecting the infrastructure is the top priority of HEC. HEC establishes a global infrastructure security protection system in areas such as security organization and personnel, physical and environmental security, business continuity, and security compliance. Based on this infrastructure, HEC uses virtualization technologies to provide basic services for upper-layer services, including network services, computing services, and storage services. HEC is responsible for the security of these basic services. In addition, HEC provides tools and methods to ensure that data and applications on GDE are securely deployed on HEC. HEC isolates customers.
