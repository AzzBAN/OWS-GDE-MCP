# Tenant's Security Responsibilities

Although the security responsibilities of HEC and GDE cover the overall security framework and GDE has developed some security standards for tenants' reference, tenants (as end users of GDE) still have their own security responsibilities.

Tenants are responsible for routine security configurations and manage GDE tenant configurations, accounts, permissions, passwords, and activity log recordings, identify sensitive data during these activities, and ensure data security, especially the security of exported data.

The tenant monitors the security compliance of sensitive data, and GDE provides technical support.

On GDE, encapsulated module functions are called microservice. Tenants can call microservice in the develop state to perform secondary development. GDE is responsible for microservice security. However, the tenant is responsible for the security of secondary development products and related security configurations of the products in the ecosystem.

For more security measures, see _GDE Security White Paper_.
