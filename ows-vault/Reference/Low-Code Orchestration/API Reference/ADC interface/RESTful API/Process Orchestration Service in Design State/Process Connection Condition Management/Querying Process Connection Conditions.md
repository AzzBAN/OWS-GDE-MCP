#### Function

This interface starts with GDE 24.2, Interface script invoked by the instance: var response = ServiceInvoker.get("/adc-studio-bpm/rest/v1/flow-condition/query?project\_name = test1&module\_name = test1&process\_name = flow1&activity\_id = AQT3"); and is used to query the process connection conditions of a specified project, module, process, and phase.
