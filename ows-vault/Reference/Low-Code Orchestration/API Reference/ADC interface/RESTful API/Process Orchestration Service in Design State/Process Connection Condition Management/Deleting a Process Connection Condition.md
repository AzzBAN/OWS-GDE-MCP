#### Function Description

This interface starts with GDE 24.2, Interface script invoked by the instance: var response = ServiceInvoker.delete("/adc-studio-bpm/rest/v1/flow-condition/delete/2c928029967f627d01967f68091f0007", url\_params); and is used to delete a process connection condition with a specified ID. It is applicable to the service requirements where a specific connection condition needs to be removed in the process design scenario.
