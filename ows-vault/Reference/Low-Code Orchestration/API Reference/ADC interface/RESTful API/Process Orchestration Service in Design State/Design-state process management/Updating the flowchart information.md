#### Function

Starts with GDE 24.2, Interface script invoked by the instance: var request = {.

"project\_name": "test1",

"module\_name": "test1",

"process\_key": "flow1",

"json\_xml": ".....",

"description": "test"

};

This interface is used to update the metadata of a flowchart, including the project name, module name, process ID, flowchart canvas data, and description. The request parameters must be complete and meet the format requirements.
