#### Function

This interface starts with GDE 24.2, Interface script invoked by the instance: var response = ServiceInvoker.delete("/adc-studio-bpm/rest/v1/process-designer/delete/test1/test1/test1", url\_params); and is used to delete the process definition of a specified project or module. Ensure that the project name, module name, and process name comply with the naming rules.
