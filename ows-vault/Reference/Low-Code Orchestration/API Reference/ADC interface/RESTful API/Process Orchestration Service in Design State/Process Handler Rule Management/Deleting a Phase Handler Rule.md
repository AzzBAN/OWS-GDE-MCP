#### Function

This interface starts with GDE 24.2, Interface script invoked by the instance: var url\_params = {"id": "2c92802996480fa901964812e62a0000"}; var response = ServiceInvoker.delete("/adc-studio-bpm/rest/v1/assignee-rule/delete/2c92802996480fa901964812e62:0000", url\_params); and is used to delete a process handler rule with a specified ID. It is applicable to process configuration management scenarios.
