#### Function

Provides the pagination query function for process archiving configuration and supports multi-condition filtering and sorting. This method is applicable to the scenario where the archiving configuration information of a specific project, module, or process needs to be obtained. The request parameters include pagination parameters and search criteria. The response contains the configuration list and pagination information.
