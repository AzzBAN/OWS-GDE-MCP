#### Function

It starts with GDE24.2. Specifies the name of the FTP configuration table to be queried in pagination mode. The input parameters current\_module\_name, module\_name, name, open\_api, sort\_by, order, active, project\_name and current\_project\_name are reserved and do not take effect during query.
