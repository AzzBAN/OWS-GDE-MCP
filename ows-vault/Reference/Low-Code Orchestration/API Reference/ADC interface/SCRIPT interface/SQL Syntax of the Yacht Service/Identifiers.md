#### Description

-   The standard syntax SQL3 (SQL99) is used.
-   The MySQL syntax set is used.
-   Currently, only SELECT statements of DML are supported. Only some DDL statements are supported.
-   The columns, tables, and functions in SQL statements will be strictly verified.
