# SQL Editing Description

In service configuration of ADC develop state, ADC uses **DataService Query** under **Platform Services** to provide the SQL editor for the Yacht service to edit SQL statements for accessing Data Cube data in Yacht mode.

However, SQL statements in the develop state can only be edited. Statements cannot be directly compiled, executed, and debugged. To compile and execute statements, go to the runtime-state page.
