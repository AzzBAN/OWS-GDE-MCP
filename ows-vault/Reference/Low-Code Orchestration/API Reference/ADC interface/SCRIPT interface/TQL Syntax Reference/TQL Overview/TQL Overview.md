# TQL Overview

Top Query Language (TQL) is a unified query language of ADC. TQL statements can be considered as SQL statements of relational databases, but their syntax and capabilities are different. For example, TQL statements used in the model data query scenario are written based on the model concept (such as the model name and property name). Such statements cannot be used to determine the control value on a page. The functions and capabilities of TQL statements vary with the application scenarios. But, when the same semantics are to be expressed, the writing of TQL statements is the same.
