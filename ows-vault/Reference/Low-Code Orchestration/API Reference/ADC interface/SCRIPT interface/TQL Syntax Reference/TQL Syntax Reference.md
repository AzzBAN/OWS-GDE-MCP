# TQL Syntax Reference

This document describes the TQL syntax and usage reference in ADC.

![[note_3.0-en-us.png]]

-   The TQL syntax and capabilities of ADC 2._X_ versions are slightly different from those of ADC 1._X_ versions. The syntax of ADC 2._X_ versions described in this document applies to assets added to ADC 2._X_ versions. TQL statements in assets imported by apps of ADC 1._X_ versions and TQL statements executed by calling compatible APIs of ADC 1._X_ versions can retain the TQL syntax of ADC 1._X_ versions.
-   When a TQL statement constructed by a developer is used, it must be protected against TQL injection.
