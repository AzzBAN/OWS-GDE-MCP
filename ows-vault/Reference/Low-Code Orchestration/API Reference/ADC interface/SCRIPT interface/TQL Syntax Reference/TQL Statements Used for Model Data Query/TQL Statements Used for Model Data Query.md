# TQL Statements Used for Model Data Query

TQL statements can be used to limit the condition of operations such as querying, updating, and deleting model data in some service model operations and some APIs of model data operations. The TQL statement query capability varies with the underlying data storage mode of each model. This topic mainly describes TQL statements used for data model and data source model query. A few TQL statement capabilities support the elastic models and have some special functions, which are described in [[Introduction to the Elastic Model TQL Statements|Introduction to the Elastic Model TQL Statements]].
