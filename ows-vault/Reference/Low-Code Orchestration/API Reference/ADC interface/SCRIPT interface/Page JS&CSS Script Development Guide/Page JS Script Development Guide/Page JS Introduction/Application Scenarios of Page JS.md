# Application Scenarios of Page JS

On ADC, page JS can be used in the following scenarios:

-   Operate page objects and components.
-   Open a web page or normal page.
-   Obtain the web page information.
-   Verify the data and process the input data.
-   Process page and component events and respond to page operations.
-   Call internal and external services.
