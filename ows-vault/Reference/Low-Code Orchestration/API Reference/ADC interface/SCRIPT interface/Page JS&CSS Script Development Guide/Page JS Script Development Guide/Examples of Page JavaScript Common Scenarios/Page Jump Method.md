# Page Jump Method

**\_blank**: A new page is displayed.

**\_tab**: A new tab page is displayed. (The tab page in the develop state is not a component tab page. If there is no tab page in the private cloud, open the tab page in a new browser window.)

**\_self**: The current page is displayed.

**\_page**: The current page is displayed without changing the URL (SPA mode).

**\_panel**: The page is opened in the tab panel. The current page (not the page to be redirected to) must be in **pagePanel**.
