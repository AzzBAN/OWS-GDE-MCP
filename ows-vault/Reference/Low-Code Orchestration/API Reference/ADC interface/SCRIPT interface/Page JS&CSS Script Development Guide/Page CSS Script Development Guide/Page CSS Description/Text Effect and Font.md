# Text Effect and Font

-   CSS provides rich and colorful text processing properties. You can change the color, font, size, direction, alignment, indentation, case, and shadow as required.
-   **color**: Color property, which can be a hexadecimal number (for example, #FF0000), an RGB value (for example, RGB(255,0,0)), or a color name (for example, red) There are only 147 color names.
-   **direction**: Text direction, which is set to **ltr** by default, indicating from left to right. The value can also be **rtl**, indicating from right to left.
-   **text-align**: Alignment mode, which is set to **left** by default. The value can also be **center**, **right**, or **justify**. The value **justify** indicates that the text is aligned at both ends and the word spacing is the same.
-   **text-indent**: Indentation in the unit of px. The indent direction is the same as the text direction.
-   **text-transform**: Converts between uppercase and lowercase letters. The value can be **capitalize**, **uppercase**, or **lowercase**. This parameter is valid only for letters.
-   **text-shadow**: Shadow, for example, **text-shadow: 2px 2px #ff0000**. The first parameter indicates the horizontal offset, and the second parameter indicates the vertical offset. There are two options: blurred distance and shadow color.
-   **text-decoration**: Text decoration, which can be **underline**, **overline**, or **line-through**, indicating underscores, hyphens, or strikethrough
-   **font**: defines the font, boldness, size, and style. The values of the following properties can be directly written in the font property:
    -   **font-family**: specifies the font or font series, for example, **times**, **courier**, and **arial**. Multiple fonts can be entered in parallel and separated by commas (,). You can search for available fonts in sequence. You are advised to use common fonts.
    -   **font-style**: Italic fronts can be used.
    -   **font-size**: Font size, which is in the unit of px. You can also use **in**, **cm**, **mm**, **pt**, or **pc** as the unit.
