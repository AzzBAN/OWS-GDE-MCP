# Buttons

Button styles include the color, size, border, and shadow.

-   **background-color**: Button color. You can define the button color as required.
-   **color**: Color of the button text
-   **width** and **height**: Width and height of a button, which is in the unit of px or %
-   **font-size**: Font size of the button text. The larger the text, the larger the button. However, the button size is limited.
-   **border**: defines the color, thickness, and line style of the border. Generally, the thickness is in the unit of px. For example, border: red 2px solid.
-   **border-style**: Line style of the border You can define the styles of the four border lines. In this case, the full name of **border-style** must be used.
    -   **dotted**: Dotted line
    -   **solid**: Solid line
    -   **dashed**: Dashed line
    -   **double**: Double solid line
    -   **Hidden** and **none**: No border
    -   You can define the style of the four border lines in the sequence of top, right, bottom, and left. If the left and right lines are the same, the left side can be omitted. If the top, bottom, left, and right lines are the same, the lower left side can be omitted.
-   **border-radius**: Rounded corner of the border, which is in the unit of px or %. The maximum value is **50%**, which is close to an ellipse.
