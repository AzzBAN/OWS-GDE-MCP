# Service Node

The script written by the developer is the execution logic of the target service node. You can use the context variable \_message to obtain the input parameter of the running node. You can also use the return statement to view the returned object.

The returned object can be used as the output parameter of the service node, can only be the native object of JavaScript, and cannot be the object created through the class.
