# Log Console

In JavaScript, logs can be output through the console object.

**Table 1** Log API description   
| API | Description | Example |
| :-- | :-- | :-- |
| console.log(message \[,arg, \[ , ... \] \]) console.debug(message\[,arg, \[ , ... \] \]) console.info(message\[,arg, \[ , ... \] \]) console.warn(message\[,arg, \[ , ... \] \]) console.error(message\[,arg, \[ , ... \] \]) | Used to generate logs. Logs generated by this API are recorded in run logs (when the log level is allowed) and service debug logs. The logging and debugging methods are the same. The debug level must be used for logs that are generated for debugging. Parameters:
-   **message**: Log information or format to be output. The value of this parameter is a string. The following formatted character strings are supported:
    -   %s: Output the corresponding parameter value as a character string.
    -   %d: Output the corresponding parameter value as a decimal number.
    -   %i: Same as the above.
    -   %f: Output the corresponding parameter value as a decimal floating-point number.
    -   % %: Output a percent sign (%).
-   **arg**: Parameter value of the string or number type, which is recorded in logs. This parameter is optional. The sequence is the same as that of the formatted characters in a message.

Returned value: None | var orderId = "order1";
var elapsedDays = "15";
console.info("Order %s finished in %d days.", orderId, elapsedDays);
