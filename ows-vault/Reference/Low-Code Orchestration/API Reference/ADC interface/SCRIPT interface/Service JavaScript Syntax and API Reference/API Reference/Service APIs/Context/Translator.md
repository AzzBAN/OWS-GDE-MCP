# Translator

The script written by the developer is the execution logic of the target translator. You can use the context variable \_context to obtain the value of the node where the translator is located and other information. You can also use the return statement to view the translation result.

Only values of the number, string, and object types can be queried using the return statement. The object type can only be the native object of JavaScript, and cannot be the object created through the class.
