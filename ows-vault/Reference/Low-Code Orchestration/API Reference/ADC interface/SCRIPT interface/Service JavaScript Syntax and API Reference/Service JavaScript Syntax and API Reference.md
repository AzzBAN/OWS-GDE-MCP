# Service JavaScript Syntax and API Reference

In a service, JavaScript development is commonly used to make the business logic more flexible. For example, the service node, translator, and validator scripts are developed using JavaScript.

This document describes the syntax and APIs that can be used for JavaScript development in a service. To ensure the portability and compatibility of JavaScript scripts, do not use the syntax and APIs that are not described in this document. Unless otherwise specified, "JavaScript" in this document refers to the JavaScript of a service.
