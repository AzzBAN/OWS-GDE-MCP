#### Literals

A literal is a numeric value, character string, boolean value, or object that is directly written in a script. These values are fixed in the script. For example:

-   Numeric value: 0 or 3.14
-   Character string: Hello or You're welcome
-   Object:
    
    {author: "Tom", age: 30}
    \[0, 1, 1, 2, 3, 5\]
    
-   Function:
    
    function hello() {
        console.log('Hello');
    }
