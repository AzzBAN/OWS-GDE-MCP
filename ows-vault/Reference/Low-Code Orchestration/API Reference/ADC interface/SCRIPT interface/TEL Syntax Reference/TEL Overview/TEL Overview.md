# TEL Overview

Top Expression Language (TEL) is a unified expression calculation language of ADC. It can be roughly seemed as expressions in SQL statements, but the syntax and capabilities are different. The functions and capabilities of TEL vary according to application scenarios. However, when the same semantics are to be expressed, the writing of TEL statements is the same.
