# No Adaptation Is Performed on Nf.setValidateMsgPos

-   In the versions using EXT, this method is used to change the display position of the pop-up messages.
-   In the versions using VUE, the display position of pop-up messages in the new framework is at the end of **datafield** and cannot be changed.

Therefore, in the versions using VUE, no adaptation is performed on this method, and this method can be directly deleted if it is used.
