#### Prerequisites

-   The production environment has been created and configured, and the network between the asset library production environment and the customer asset library environment is connected.
-   **Type Of Technology** of the asset to be deployed is **App**.
-   To deploy assets that have been put away, the following requirements must be met:
    -   You have the administrator permission of the service domain to which the assets to be deployed belong.
    -   The system administrator of the develop-state environment has been bound to the permissions of the O&M administrator role **AssetMaintenanceAdmin**.
-   The following requirements must be met when local assets are deployed:
    
    The system administrator of the develop-state environment has been bound to the permissions of the O&M administrator role **AssetMaintenanceAdmin**.
