#### Prerequisites

The user has been granted the permission to access the remote GDE Store. For details about the configurations, see **Data Zone Configuration** > **Data Zone Configuration (default Tenant)** > **Application Asset Management** > **GDE Store Configuration** > **Remote Access to GDE Store** in _GDE x.x.x Product Documentation_.

You have the domain administrator permission of the service domain to access the assets that have been put away.

You have the administrator permission of the service domain that the assets to be subscribed belong to.
