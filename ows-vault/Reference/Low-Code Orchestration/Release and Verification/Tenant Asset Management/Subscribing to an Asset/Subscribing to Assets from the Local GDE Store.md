#### Prerequisites

The user has been granted the permission to access the local GDE Store. For details about the configurations, see **Data Zone Configuration** > **Data Zone Configuration (default Tenant)** > **Application Asset Management** > **GDE Store Configuration** > **Local Access to GDE Store** in _GDE x.x.x Product Documentation_.

You have the administrator permission of the service domain that the assets to be subscribed belong to.
