# Approving an Asset

This section describes the permissions required for developers to approve tickets on the asset management page and the ticket approval process.

-   **[[Approving an Asset Subscription Ticket|Approving an Asset Subscription Ticket]]**  
    The tenant asset management system allows you to subscribe to assets from GDE Store in both remote and local modes. You can query the assets, which are subscribed from the local GDE Store, in the local App Store of GDE Store or on the **Asset Management** page.
-   **[[Approving an Asset Putaway Ticket|Approving an Asset Putaway Ticket]]**  
    The tenant asset management system allows you to quickly release verified assets and use asset release application, approval, and control processes.
-   **[[Approving an Asset Deployment Ticket|Approving an Asset Deployment Ticket]]**  
    The tenant asset management system allows you to allocate asset deployment tickets to different reviewers.
