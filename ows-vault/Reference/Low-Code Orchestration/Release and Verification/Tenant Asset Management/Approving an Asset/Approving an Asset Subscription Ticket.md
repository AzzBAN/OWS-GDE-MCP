#### Prerequisites

1.  You have the administrator permission of the service domain to which the assets belong. (The tickets of these assets are to be approved.)
2.  To approve asset subscription tickets, you need to have permissions of one of the following roles:
    -   **System administrators in Develop State** role
    -   **AssetOperationsAdmin** role that has been bound to a user you have created. For details about how to bind the role to the created user, see [Associating Users with Roles](nottoctopics/en-us_topic_0000001527069129.html).
    -   Approval administrator role that is created by users and has the permission to approve asset subscription tickets
