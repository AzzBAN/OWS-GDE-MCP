# Tenant Asset Management

This document describes how users under a tenant manage assets in the ADC develop-state environment.

-   **[[Viewing Asset Details|Viewing Asset Details]]**  
    On the **Asset Management** page, you can view the asset information such as apps, APIs, and templates.
-   **[[Managing Labels|Managing Labels]]**  
    The following labels are available on the **Asset Management** page: **Service Domain**, **Asset Type/Asset Catalog**, and **Technology Category**.
-   **[[Subscribing to an Asset|Subscribing to an Asset]]**  
    GDE Store is used to put away and share assets. Developers can download required assets from GDE Store and share their apps within GDE Store.
-   **[[Uploading Assets to the Asset Management Page|Uploading Assets to the Asset Management Page]]**  
    Developers can use the asset upload function to upload personal assets to the **Asset Management** page. The personal assets are displayed on the **Local Assets** page.
-   **[[Putting Away Assets to the Asset Management Page|Putting Away Assets to the Asset Management Page]]**  
    Developers can put away assets through a pipeline or using the asset management page.
-   **[[Deploying Assets to the Customer Asset Library|Deploying Assets to the Customer Asset Library]]**  
    This section describes the parameters to be configured and operations to be performed by developers to deploy assets to the customer asset library.
-   **[[Approving an Asset|Approving an Asset]]**  
    This section describes the permissions required for developers to approve tickets on the asset management page and the ticket approval process.
-   **[[Viewing the Vulnerability Information|Viewing the Vulnerability Information]]**  
    In the scenario where an asset service is interworked with GDE Store, you can view the vulnerability information of the asset. Asset vulnerability information provided by GDE Store is displayed on the **Asset Management** page.
-   **[[Viewing the Asset Dependency Analysis|Viewing the Asset Dependency Analysis]]**  
    The information tree service enables developers to view the list of projects and apps synchronized from the local asset library or the **Project Management** page. It also allows them to parse elements in the project, and view the project element structure and project dependencies.
-   **[[Viewing Asset Difference Comparison Results|Viewing Asset Difference Comparison Results]]**  
    When multiple developers develop an app at the same time, the asset library provides a tool for comparing app differences.
