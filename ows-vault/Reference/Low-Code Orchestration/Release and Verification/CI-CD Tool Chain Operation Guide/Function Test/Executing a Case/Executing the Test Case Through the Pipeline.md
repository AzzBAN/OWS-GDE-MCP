# Executing the Test Case Through the Pipeline

1.  Access the **App Pipeline** tab page.
2.  Edit parameters.
    
    **Figure 1** App Pipeline tab page  
    ![[en-us_image_0000001829194961.png]]
    
3.  Select the test environment required by the test case, enter the user name and password, and click **OK**.
    
    **Figure 2** Environment for delivering a package  
    ![[en-us_image_0000001782515186.png]]
    
4.  Set pipeline parameters and click **Pack**.
    
    **Figure 3** App packaging page  
    ![[en-us_image_0000001782355514.png]]
    
5.  Wait until the function test is complete.
    
    **Figure 4** Function test page  
    ![[en-us_image_0000001829074921.png]]
