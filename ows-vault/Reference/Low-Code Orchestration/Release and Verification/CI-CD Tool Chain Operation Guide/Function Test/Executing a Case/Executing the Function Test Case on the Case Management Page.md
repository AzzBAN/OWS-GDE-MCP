# Executing the Function Test Case on the Case Management Page

1.  a. Click **execute** or **Execute immediately**. The system executes the case based on the default parameters.
    
    **Figure 1** Case management home page  
    ![[en-us_image_0000001782355478.png]]
    
    b. Click **Specify environment**. The case will be executed based on the parameters you set.
    
    **Figure 2** Setting the environment and login information  
    ![[en-us_image_0000001782355474.png]]
    
2.  After the case is started, the result page is automatically displayed and refreshed to obtain the latest status.
    
    **Figure 3** Viewing the case result  
    ![[en-us_image_0000001829194933.png]]
