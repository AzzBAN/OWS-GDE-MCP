# Adding a Case

1.  Click **Add Case**.
    
    **Figure 1** Case management page  
    ![[en-us_image_0000001782515386.png]]
    
2.  Record a case. If you do not download the recording tool, click **Download**.
    
    **Figure 2** Page for adding a case  
    ![[en-us_image_0000001782515374.png]]
    
3.  Use the UI recording function to record the case and ensure that the first step is to open a browser.
    
    **Figure 3** WeAutomate recording page  
    ![[en-us_image_0000001782355706.png]]
    
    **Figure 4** Recorder page  
    ![[en-us_image_0000001829075121.png]]
    
4.  After the recording is complete, upload the case. You can compress the **Project** and **ScreenShot** folders in the project directory into a .zip package and upload the package.
    
    **Figure 5** Recorder page displayed after the recording is complete  
    ![[en-us_image_0000001829075109.png]]
    
    **Figure 6** Opening the project directory  
    ![[en-us_image_0000001829195181.png]]
    
    **Figure 7** Compressing the file into a ZIP package and uploading it  
    ![[en-us_image_0000001829195153.png]]
    
    ![[note_3.0-en-us.png]]
    
    You can use a compression tool such as WinRAR or 7-Zip to compress the **Project** and **ScreenShot** folders into a .zip file. The default format of some compression software is not .zip. Select the .zip format.
    
5.  In the **Add Case** dialog box, click **Next** to go to the **Upload use case** step.
    
    **Figure 8** Uploading a case  
    ![[en-us_image_0000001782355726.png]]
    
6.  Click **Upload** and select one or multiple test case ZIP files. The test cases in the red box fail to be uploaded. The information in the brackets indicates the failure cause. The test cases in the green box have been successfully uploaded and saved in the backend. You can click the cross icon to delete the uploaded test cases. Clicking **Back** or **done** does not affect uploaded cases. Click **Click upload** to upload more cases.
    
    **Figure 9** Upload complete  
    ![[en-us_image_0000001829195165.png]]
    
7.  Click **done**. All uploaded cases are automatically displayed on the page.
    
    **Figure 10** Case list  
    ![[en-us_image_0000001829075141.png]]
