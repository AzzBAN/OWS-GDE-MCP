# Independently Putting Away an Asset

1.  Go to the home page of the develop-state environment, and choose **Asset Management** > **Asset Library**.
    
    **Figure 1** Home page of the develop-state environment  
    ![[en-us_image_0000001829195113.png]]
    
2.  Select the asset to be put away and click the put away icon.
    
    **Figure 2** Asset putaway  
    ![[en-us_image_0000001782355662.png]]
    
3.  Configure the asset putaway information. For details, see [[Putaway Page|Putaway Page]].
4.  Access the **History Record** page, click the **Putaway Record** tab, and view the asset putaway status. For details, see [[Viewing Historical Records|Viewing Historical Records]].
    
    **Figure 3** Putaway record  
    ![[en-us_image_0000001829195117.png]]
