# Asset Putaway

![[note_3.0-en-us.png]]

The following uses an app asset as an example to describe how to put away an asset. The procedure for putting away a project package and project template is the same as that for putting away an app.

Go to the **App Pipeline** tab page and choose **Asset Library** > **Putaway** or **GDE Store** > **Putaway** in the upper right corner.
