# Putaway Process

1.  Return to the pipeline details page and package the asset.
    
    **Figure 1** Asset packaging  
    ![[en-us_image_0000001782355686.png]]
    
2.  Sign the packaged assets with digital signature.
    
    **Figure 2** Digital signature  
    ![[en-us_image_0000001782515366.png]]
    
3.  Perform virus scanning.
    
    **Figure 3** Virus scanning  
    ![[en-us_image_0000001829195141.png]]
    
4.  Approve the asset putaway process for assets in **Approving** state.
    
    **Figure 4** Putaway approving  
    ![[en-us_image_0000001829075105.png]]
    
5.  After the asset putaway application is approved, the asset status is **Pass**, indicating that the putaway is successful.
    
    **Figure 5** Successful putaway  
    ![[en-us_image_0000001782355694.png]]
