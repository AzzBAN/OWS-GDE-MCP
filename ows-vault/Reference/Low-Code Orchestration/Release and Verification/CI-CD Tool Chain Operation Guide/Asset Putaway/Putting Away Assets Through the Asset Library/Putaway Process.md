# Putaway Process

1.  Return to the pipeline details page and package the asset.
    
    **Figure 1** Asset packaging  
    ![[en-us_image_0000001829194997.png]]
    
2.  Sign the assets with digital signature.
    
    **Figure 2** Digital signature  
    ![[en-us_image_0000001782355538.png]]
    
3.  Approve the asset putaway process for assets in **Approving** state.
    
    **Figure 3** Approving an asset putaway process  
    ![[en-us_image_0000001782355546.png]]
    
4.  After the asset putaway application is approved, the asset status is **Pass**, indicating that the putaway is successful.
    
    **Figure 4** Successful putaway  
    ![[en-us_image_0000001829074953.png]]
