# Putaway Page

1.  In the displayed **Putaway** dialog box, configure the putaway information.
    
    **Figure 1** Basic Info  
    ![[en-us_image_0000001829195053.png]]
    
    **Figure 2** Putaway Info  
    ![[en-us_image_0000001782515282.png]]
    
    **Table 1** Parameters on the basic information page  
    | Parameter | Description |
    | :-- | :-- |
    | Display Name | Indicates the asset name displayed by default. |
    | Putaway Version | Indicates the version of the asset that is successfully packaged. |
    | Technical Support | Used for consultation and help seeking when an asset is used. |
    | Developer Type | Indicates whether an asset is developed by an individual developer or a team developer. This parameter cannot be set. |
    | Developer Info | The value cannot be selected. |
    | Category | Indicates the asset category. You can select only one option. |
    | Business Domain | Only one domain can be selected. You can select a domain starting from level 2 or 3. |
    | Is Managed | Select an option. |
    | Delivery Method | 
    -   **SAAS**: The asset is deployed as a SaaS service.
    -   **OP**: The asset can be used only after being downloaded.
    
     |
    | Custom Label | Indicates the list of asset labels added by the developer. Multiple labels are separated with commas (,). Each label contains a maximum of 64 characters. A maximum of 16 labels are supported. | **Figure 3** Asset introduction page 1  
    ![[en-us_image_0000001782355610.png]]
    
    **Figure 4** Asset introduction page 2  
    ![[en-us_image_0000001829075021.png]]
    
    **Table 2** Parameters on the asset introduction page  
    | Parameter | Description |
    | :-- | :-- |
    | LOGO | Asset icon. |
    | background Image | Only one JPG, PNG, or JPEG image is allowed. The size of a single image must be less than 200 KB. |
    | Homepage Image | Only one JPG, PNG, or JPEG image is allowed. The size of a single image must be less than 500 KB. |
    | Introduction | Introduction in Chinese or English, which is mandatory |
    | Asset Description | Rich-text Chinese and English description |
    | Dev Tutorial | Rich-text Chinese and English description |
    | Sample | Rich-text Chinese and English description |
    | Help Document | Only one ZIP file can be uploaded. The total file size cannot exceed 100 MB. | **Figure 5** Version change description page  
    ![[en-us_image_0000001782515266.png]]
    
    **Table 3** Parameters on the version change description page  
    | Parameter | Description |
    | :-- | :-- |
    | Putaway Description | Asset putaway description |
    | Add Images | A maximum of five files in JPG, PNG, or JPEG format can be uploaded, and the size of each file cannot exceed 500 KB. | 2.  Click **Preview** to preview the parameter settings.
3.  Click **Confirm** to go to the putaway process.
