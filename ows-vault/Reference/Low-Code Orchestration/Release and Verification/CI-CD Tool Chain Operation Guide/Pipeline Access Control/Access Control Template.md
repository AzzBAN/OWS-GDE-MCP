# Access Control Template

Access the GDE runtime-state environment. Click **GDE Common Configuration**, and click ![[en-us_image_0000001782355566.png]] in the upper left corner to expand the menu. Choose **Access Control Template** from the menu.

**Figure 1** Access control template configuration menu  
![[en-us_image_0000001782515238.png]]

**Figure 2** Accessing the control template configuration page  
![[en-us_image_0000001829195021.png]]

2\. Click **Add Gate Template**. Enter the template name and description, add access control metrics, and click **Save**.

**Figure 3** Adding an access control template  
![[en-us_image_0000001829075005.png]]

**Figure 4** Setting the access control template  
![[en-us_image_0000001829195005.png]]

3\. Locate the target access control template, click **Modify** in the **Operation** column. Modify the access control description and metric information, and click **Save**.

**Figure 5** Editing the access control template  
![[en-us_image_0000001782515226.png]]

**Figure 6** Adding the metric information  
![[en-us_image_0000001782355586.png]]

4\. Locate the target access control template, click **Delete** in the **Operation** column. In the displayed dialog box, select "I have read the message carefully and are fully aware of the risks involved with this operation.". Then, click **OK** to delete the template.

**Figure 7** Deleting the access control template  
![[en-us_image_0000001782355578.png]]

5\. Locate the target access control template, click **Enable** in the **Operation** column. In the displayed dialog box, click **OK**.

**Figure 8** Enabling the access control template  
![[en-us_image_0000001829074981.png]]

**Figure 9** Enabled template  
![[en-us_image_0000001829074989.png]]

6\. Enter an access control template name in the text box and click ![[en-us_image_0000001829195029.png]] to query the specified template.

**Figure 10** Querying the access control template  
![[en-us_image_0000001782515246.png]]
