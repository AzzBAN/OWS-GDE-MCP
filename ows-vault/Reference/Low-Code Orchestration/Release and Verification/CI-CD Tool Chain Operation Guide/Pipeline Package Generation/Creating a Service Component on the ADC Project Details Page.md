# Creating a Service Component on the ADC Project Details Page

1.  Access the pipeline details page by following instructions provided in [[Creating an App on the ADC Project Details Page|Creating an App on the ADC Project Details Page]].
2.  Switch to **Service Component Pipeline**.
    
    **Figure 1** Selecting a service component pipeline  
    ![[en-us_image_0000001829195093.png]]
    
    Click **Deliver** to create a service component.
    
3.  In the displayed **Packed as a Service Component(Copy)** dialog box, complete the information.
    
    **Figure 2** Packed as a service component  
    ![[en-us_image_0000001782515310.png]]
    
    **Figure 3** Packed as a service component\_Adding a module  
    ![[en-us_image_0000001829075057.png]]
    
    Parameter description
    
     
    | Name | Description |
    | :-- | :-- |
    | Name | The parameters can be modified. |
    | Asset Allocation Business Domain | 
    -   Locating and impact analysis
    -   Fault and hidden trouble identification
    -   Health Check
    -   Resource Data Synchronization
    -   Check and quality inspection
    
     |
    | Other Parameters | Same as that described in Table 1. | 4.  Click **Pack** to go to the project pipeline page.
5.  After the building is complete, view the displayed page, as shown in the following figure.
    
    **Figure 4** Pipeline details page  
    ![[en-us_image_0000001782355638.png]]
