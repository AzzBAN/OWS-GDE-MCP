# Creating a Project Package on the ADC Project Details Page

1.  Access the pipeline details page by following instructions provided in [[Creating an App on the ADC Project Details Page|Creating an App on the ADC Project Details Page]].
2.  Click the **Project Package Pipeline** tab to view the project package pipeline details.
    
    **Figure 1** Project Package Pipeline tab page  
    ![[en-us_image_0000001782515270.png]]
    
    Click **Deliver** to create a project package.
    
    **Figure 2** Deliver button  
    ![[en-us_image_0000001829195061.png]]
    
3.  In the displayed dialog box, complete the information.
    
    **Figure 3** Packaged into a project package  
    ![[en-us_image_0000001829075025.png]]
    
    -   Parameter description
    
     
    | Name | Description |
    | :-- | :-- |
    | App Name | Same as the project name and cannot be modified. |
    | Other Parameters | Same as that described in Table 1. | Click ![[en-us_image_0000001782355614.png]] to start the pipeline.
    
4.  Refresh the page.
5.  After the package is delivered, view the displayed page, as shown in the following figure.
    
    **Figure 4** Pipeline details page  
    ![[en-us_image_0000001782355598.png]]
