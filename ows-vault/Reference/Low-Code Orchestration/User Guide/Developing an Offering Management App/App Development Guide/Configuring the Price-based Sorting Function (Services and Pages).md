#### Scenario Description

In the automatically generated _xxx_**\_get\_list** service, the data sorting function is supported by default. That is, transfer the field to be sorted in the **sort** field through services and specify the ascending or descending order in the **dir** field.

![[en-us_image_0000001508431129.png]]

On the page, you need to configure specified fields to sortable so that the sorting function can be used during front-end data query.
