#### Prerequisites

The app has been deployed.

If hot deployment is enabled during project creation, you can directly debug the project after configuration. If hot deployment is not enabled, you can click ![[en-us_image_0000001674902061.png]] in the upper right corner of the project and select **One-Click Deployment** to debug the project after the deployment is complete.
