#### Scenario Description

The _xxx_\_get\_list service automatically generated based on the model is used to query the result list. By default, data can be filtered only by primary key. To add the category-based (such as **goods\_type**) filtering function, you need to adjust the service.

In addition, the automatically generated _xxx_\_grid page supports query only by primary key by default. You need to add a page component for category-based query.
