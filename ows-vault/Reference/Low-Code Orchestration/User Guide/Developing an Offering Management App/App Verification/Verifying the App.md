#### Verification Scenarios

Test personnel need to plan complete test cases based on scenarios. The test is performed based on the following scenarios.

The manager role **Mary\_manager** and common employee role **Jack\_staff** are planned to perform operations in different permission scenarios.

**Table 1** Verification scenarios   
| User Name | Role | Scenario |
| :-- | :-- | :-- |
| Mary\_manager | manager | The user has obtained permissions on the Goods Category Management and Goods Information Management menus. On the Offering Information Management page, you can view the Import button and perform the import operation. |
| Jack\_staff | staff | The user has obtained the permission only on the Goods Information Management menu. On the Offering Information Management page, you can add, delete, and modify offerings, but cannot view the Import and Export buttons. |
