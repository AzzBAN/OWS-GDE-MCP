# Understanding the Low-Code Development Platform

GDE provides a **full-scenario** development platform for service developers and a complete **asset life cycle** tool chain to meet **high development requirements** and shorten **development period**, forming a new development mode with **service assets as its core and efficient development and reuse**.

-   All-scenario development platform: GDE supports application development and governance, such as simple object orchestration, process orchestration, integration orchestration, data orchestration, RPA orchestration, network operation orchestration, data visualization screen orchestration, mobile app orchestration, trusted development, and asset governance.
-   Low learning threshold: The online application development and running platform provides graphical operations and drag-and-drop app design and creation. Common service personnel can start application development after one to two weeks of training.
-   Flexible configuration and quick customization: You can modify application elements such as GUIs, service logic, and models as required to shorten the innovation period from idea to production. Developers are free from repetitive works such as adding, deleting, modifying, and querying data in the database. They can focus more on high-level service logics. In addition, the development cycle is not as long as that of the traditional mode.
-   Online development and deployment: Online development can be performed in any place and environment. After the development test is complete, the development can be immediately released and take effect as required. Online changes are logged.
-   Complete asset life cycle tool chain: provides an asset development, release, and management platform to help business personnel manage and reuse various assets.

You can develop an app in the develop-state environment. Create a project, orchestrate various elements in each type of module, and package and release the project.

1.  GDE orchestration help developers create an asset program that can be run on the GDE app execution engine through dragging and dropping orchestration elements and writing basic JavaScript code. Due to its orchestration flexibility, developers can customize code execution, which may cause malicious code execution risks. To securely use the orchestration flexibility, the following requirements must be met:
    -   All developers must strictly follow _Knowledge Asset Development Specifications_ to implement orchestration and development. Any form of malicious code is prohibited, including but not limited to viruses, rogue software, Trojan horses, backdoors, listening programs, and mining programs.
    -   The system administrator must strictly review the development qualification of developers and assign permissions to developers who have obtained the asset development certification. Assigned permissions cannot be used without control.
2.  The develop-state environment of the low-code platform is used only by developers to develop and debug apps. Sensitive data is not desensitized. Developers are advised not to use real data for debugging in the develop-state environment.
