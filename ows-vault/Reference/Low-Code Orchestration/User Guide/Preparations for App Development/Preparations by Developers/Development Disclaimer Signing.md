#### Context

Before developing an application, you must understand the responsibilities of a developer and sign the development disclaimer.

The system provides multiple entries for signing the development disclaimer. If a developer does not sign it, the signing page is displayed when the developer performs operations such as project creation.

Read the development disclaimer carefully and sign it after confirming it. If the developer does not sign the development disclaimer, the developer cannot develop applications.

The system prompts you to sign the development disclaimer in the following scenarios:

-   In the runtime-state environment, choose **Development State Studio** to go to the orchestration home page.
-   Manage developer certificates.
-   Access the orchestration-related menus, such as **Project Management** and **Team Management**.
-   Access the menus related to general configuration, such as **General Settings** > **Environment Management**, **General Settings** > **Service Domain Management**, and **General Settings** > **Quality Evaluation Rule Management**.
