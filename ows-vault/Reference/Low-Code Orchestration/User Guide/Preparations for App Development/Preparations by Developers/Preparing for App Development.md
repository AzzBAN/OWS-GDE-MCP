#### Context

GDE consists of the develop-state environment and the runtime-state environment. You can easily switch between them.

The runtime state is accessed through the unified portal, for example, **https://**_IP address_**:**_Port number_**/portal-web/portal/homepage.html**.

In the runtime-state environment, you can choose **Development State Studio** from the navigation pane to go to the develop-state environment.
