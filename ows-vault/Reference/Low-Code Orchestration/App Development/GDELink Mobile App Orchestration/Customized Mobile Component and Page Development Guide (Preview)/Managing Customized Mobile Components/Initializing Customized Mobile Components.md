#### Procedure

1.  In the local file directory, press **Shift**, right-click the mouse, and choose **Open PowerShell Here** or **Open command window here** from the shortcut menu.
2.  Run **adc init** to initialize the project. Confirm and enter information as prompted.
    
    ![[en-us_image_0000001398935489.png]]
    
    **Table 1** Information to be confirmed and entered  
    | Information | Description |
    | :-- | :-- |
    | Select a project type | Use arrows on the keyboard to select Customized Mobile Components. |
    | Name of nocode component | Enter a customized name. |
    | Description | Information description. | 3.  After the project is initialized, verify that the message "Construction completed!" is displayed.
4.  Access the local project directory, use the VSCode-huawei tool to open the folder, and view the initialization code file.
