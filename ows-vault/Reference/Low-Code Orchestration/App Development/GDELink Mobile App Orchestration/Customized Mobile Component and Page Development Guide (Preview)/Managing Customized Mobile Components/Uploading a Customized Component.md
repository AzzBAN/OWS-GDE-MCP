#### Procedure

1.  Choose **Mobile Page** > **Orchestrating Resources** > **Customized Page Component**.
2.  Click **Import**. Click **Add** and select the component package to be imported.
    
    **Figure 1** Uploading a file  
    ![[en-us_image_0000001830149273.png]]
    
3.  Click **OK**.
4.  In the displayed dialog box, configure the import information and click **OK**.
    
    ![[en-us_image_0000002193995293.png]]
    
    **Table 1** Parameter description  
    | Parameter | Configuration |
    | :-- | :-- |
    | Developer Type | Resource development permission control, that is, developers to whom the permissions to view, use, and delete themes are assigned.
    -   **PERSONAL**: Grant the development permission only to the individual who creates the asset.
    -   **TEAM**: Grant the development permission to a specified team.
    
     |
    | Share Asset | Whether resources can be shared, that is, whether to allow other users except individuals or teams to view, use, copy, and export page templates (excluding change operations). Resource sharing is a restricted disclosure of resource permissions. That is, only the resource usage permission is shared, and the resource change permission is not. |
    | Business Type | Asset category catalog. After the template is saved to the asset library, the template in the asset library can be filtered by category. |
    | Release Notes | Version information |
