#### Procedure

1.  Open the VSCode-huawei tool, select **webpack/envs.js**, and configure the environment address.
    
    ![[en-us_image_0000001398975489.png]]
    
2.  Choose **View** > **Terminal** from the toolbar.
3.  In the displayed window at the bottom, enter **adc run** to perform local debugging.
4.  In the displayed window at the bottom, enter **adc build** to run the packaging command.
5.  Verify that the message "Build successfully!" is displayed, indicating that the packaging is successful.
6.  In the local code directory, obtain the compressed package _xxxxxx_**.zip**.
