#### Procedure

1.  Access a created project and module.
2.  Import a customized page project.
    
    1.  Choose **Mobile Page** > **Orchestrating Resources** > **Customized Page**.
    2.  In the upper right corner of the displayed page, click **Import**.
    3.  Click **Add** to select the customized project package to be imported.
        
        **Figure 1** Uploading a file  
        ![[en-us_image_0000001783511628.png]]
        
    4.  Click **Confirm**.
    5.  In the displayed dialog box, click **OK**.
        
        ![[en-us_image_0000002158715492.png]]
        
    
3.  Click ![[en-us_image_0000001830111353.png]] on the left of the name of an imported project to view the project details.
    
    ![[en-us_image_0000002158719768.png]]
    
4.  Click **View Code** to view project code.
    
    **Figure 2** Viewing project code  
    ![[en-us_image_0000001783511640.png]]
    
5.  Click **View Page** and ![[en-us_image_0000001783351976.png]] to view the page effect.
    
    **Figure 3** Viewing a page  
    ![[en-us_image_0000001830111361.png]]
