#### Procedure

1.  Access a created project and module.
2.  Choose **Mobile Page** > **Orchestrating Resources** > **Customized Page**.
3.  Select the customized mobile page to be used, expand it, and copy the resource address.
    
    ![[en-us_image_0000001348136184.png]]
    
4.  Choose **Mobile Page**. In the mobile designer, drag **Frame Panel**, and set the resource address to the copied address.
    
    **Figure 1** Selecting a component  
    ![[en-us_image_0000001398775961.png]]
    
    **Figure 2** Configuring the component properties  
    ![[en-us_image_0000001348455748.png]]
    
5.  Save and preview the mobile page.
    
    **Figure 3** Preview effect  
    ![[en-us_image_0000001398935497.png]]
