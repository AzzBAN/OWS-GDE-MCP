# Overview of the Mobile Page Development

When frontline engineers need to execute field tasks, for example, checking base stations, they need to view task assignment, take and upload photos, and confirm the process on their mobile phones. Therefore, mobile apps are required. GDELink is an execution platform on the mobile phone. Developers can develop apps on ADC, orchestrate mobile pages, and release mobile apps to GDELink. You can obtain GDELink from the app store on the mobile phone, and obtain various service apps provided by developers from GDELink.

**Figure 1** Mobile app  
![[en-us_image_0000001280416768.png]]

Mobile pages can be rendered in the GDELink style or compatible Mateline style.

By default, the Mateline style is used. To use the GDELink style, set the tenant-level system parameter **mobile\_engine\_type**. For details, see **Data Zone Configuration** > **Data Zone Configuration (default Tenant)** > **Mobile Service Configuration** > **Mobile Service Parameter Configuration** > **Tenant-Level System Parameters** in _GDE x.x.x Product Documentation_.
