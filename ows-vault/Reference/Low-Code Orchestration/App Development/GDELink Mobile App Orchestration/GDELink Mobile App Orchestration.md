# GDELink Mobile App Orchestration

To support mobile app development of GDE developers, GDELink provides visualized Web-based orchestration pages, rich orchestration resources, low-barrier drag-and-drop development mode, and flexible and convenient UI customization capabilities. In addition, it has the following advantages: native code expansion of the mobile app, integration of custom plugins, HTML5 apps, and applets, and flexible release and upgrade management modes for mobile apps to achieve custom packaging and release or upgrade management for services. GDELink provides multi-layer orchestration and development capabilities in multiple dimensions and at multiple intervals to enable ecosystem users and partners to quickly build mobile app capabilities and support efficient implementation of various mobile office solutions.
