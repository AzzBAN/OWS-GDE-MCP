#### Procedure

1.  Download the GDELink app.
    
    Log in to [the Support website](https://support.huawei.com/carrier/productNewOffering?col=product&path=PBI1-7275736/PBI1-8134855/PBI1-8134857/PBI1-23550152&resTab=SW), select the desired software version, download the GDELink software package by referring to [Table 1](#EN-US_TOPIC_0000001247204701__table1441616112912), and check the software package integrity by referring to [OpenPGP Signature Verification Guide](https://support.huawei.com/carrier/docview!docview?nid=DOC1100840124&path=PBI1-253383977/PBI1-23710112/PBI1-21431666/PBI1-253386765/PBI1-22562161/PBI1-22562163/PBI1-22562164/PBI1-22562166/PBI1-253374093). _x.x.x_ in the following table indicates the version.
    
    **Table 1** GDELink software packages  
    | Software Package | Description |
    | :-- | :-- |
    | ADC\_x.x.x\_Software\_Android-Any\_Pkg-GDELink-Any.zip | GDELink software package for Android |
    | ADC\_x.x.x\_Software\_IOS-Any\_Pkg-GDELink-Any.zip | GDELink software package for iOS |
    | ADC\_x.x.x\_Software\_HARMONY-Any\_Pkg-GDELink-Any.zip | GDELink software package for HarmonyOS | 2.  Upload the GDELink app.
    
    Upload the GDELink software packages to the GDE data zone based on site requirements. For details, see **Data Zone Configuration** > **Data Zone Configuration (default Tenant)** > **Mobile Service Configuration** > **Client Management** > **App Version Management** in _GDE x.x.x Product Documentation_.
    
3.  After the GDELink app is uploaded, click **Details** on the right. On the displayed version details page, click **Download** on the right of the corresponding version to scan the QR code to download and install the app.
    
    ![[notice_3.0-en-us.png]]
    
    After downloading and installing the app of the iOS version, you need to choose **Settings** > **General** > **VPN and Device Manage** and add the app certificate to the trustlist. In this way, the app can be used.
