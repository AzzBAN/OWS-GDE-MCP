#### Context

-   Avatar
    
    Only the default profile picture can be displayed.
    
-   Switching a tenant
    
    You can apply for joining a tenant only in the personal center in runtime state. Operations on mobile apps are not supported.
    
    If a logged-in user has joined multiple tenants, the user can switch between tenants.
    
-   User name
    
    The user name is displayed.
    
-   Task management
    
    Files that fail to be uploaded or downloaded and files that have been uploaded are displayed. You can manually upload the files that fail to be uploaded.
    
-   About
    
    The following functions are supported: viewing privacy statements, automatically updating privacy statements, and detecting new versions.
