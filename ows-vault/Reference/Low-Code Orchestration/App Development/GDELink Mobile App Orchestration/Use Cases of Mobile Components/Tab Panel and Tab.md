#### Orchestration Procedure

1.  Drag a **Tab Panel** component and then drag a **Tab** component under that component.
    
    ![[en-us_image_0000002194099261.png]]
    
2.  If icons need to be displayed, use either of the following ways:
    
    -   To display a platform icon, choose **Styles** > **Icon** and select the desired icon
        
        ![[en-us_image_0000002158734446.png]]
        
    -   To display a customized icon, select the uploaded icons from the **Icon URL** and **Activate Icon URL** drop-down lists in the **Styles** area. The icon can be displayed only after both properties are configured.
        
        ![[en-us_image_0000002194015061.png]]
        
    
3.  Set **Tab Position** to **bottom** to simulate the effect of the bottom navigation bar.
    
    ![[en-us_image_0000001679024689.png]]
