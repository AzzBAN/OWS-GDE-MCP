#### Orchestration Procedure (Scenario 1: Using a Buttons Group on the Right of the Top Navigation Bar)

![[en-us_image_0000001679024741.png]]

1.  Drag a **Header** component, and drag a **More Buttons Group** component under **Button Group**.
    
    ![[en-us_image_0000001630585270.png]]
    
2.  Drag the required button component under **Button Group**. Three script buttons are dragged here to show an example.
    
    ![[en-us_image_0000001679344821.png]]
    
3.  Set **CSS Class** in the **Styles** area to **button-light**.
    
    ![[en-us_image_0000001679144729.png]]
