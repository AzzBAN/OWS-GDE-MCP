#### Orchestration Procedure

1.  Drag a **Frame Panel** component to the component tree.
    
    ![[en-us_image_0000001679318473.png]]
    
2.  Set **Src** to the address of the customized page resource imported to the project in advance.
    
    ![[en-us_image_0000001532055429.png]]
    
    -   Obtain the resource address of a customized page by referring to the following figure.
        
        ![[en-us_image_0000001678998429.png]]
        
    
3.  After the preceding configurations are complete, click **Preview**. The page accessed through the address of **Src** is displayed.
4.  The parameter value can be transferred to the customized page. The following figures show the parameter configuration.
    
    ![[en-us_image_0000001679198617.png]]
    
    ![[en-us_image_0000001630558756.png]]
    
    ![[note_3.0-en-us.png]]
    
    **1111** can be obtained from the source code of the customized page through **U. getUrlParameter("test")**.
