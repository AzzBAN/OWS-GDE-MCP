#### Orchestration Procedure

1.  Drag a **List Redirect Button** component under **Button**.
    
    ![[en-us_image_0000001679024693.png]]
    
2.  Set **Text** to **Redirection**.
    
    ![[en-us_image_0000001630425318.png]]
    
3.  Set **Location** to an existing page.
    
    ![[en-us_image_0000001679144609.png]]
    
4.  Set **Parameters** to values in the following figures.
    
    ![[en-us_image_0000001630905146.png]]
    
    ![[en-us_image_0000001630745190.png]]
    
    The configured parameters are transferred to the target page.
    
    ![[en-us_image_0000001679225125.png]]
    
    ![[en-us_image_0000001679224877.png]]
    
5.  Set **Confirm Message** to **Are you sure you want to redirect?**
    
    ![[en-us_image_0000001679024853.png]]
    
    After you configure **Confirm Message** and click the button, a dialog box is displayed. You need to click **OK** before performing subsequent operations.
    
    ![[en-us_image_0000001679224985.png]]
    
6.  Set **Icon Class** to **ion-plus**.
    
    ![[en-us_image_0000001630905158.png]]
    
7.  After the preceding configurations are complete, click **Preview** and swipe left on the list data to view the button.
    
    ![[en-us_image_0000001630425478.png]]
