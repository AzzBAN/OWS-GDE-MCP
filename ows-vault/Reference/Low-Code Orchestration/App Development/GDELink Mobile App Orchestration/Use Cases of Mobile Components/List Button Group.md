#### Orchestration Procedure

1.  Drag a **List Button Group** component under **Button Group**.
    
    ![[en-us_image_0000001614275038.png]]
    
2.  Set **Text** to **More**.
    
    ![[en-us_image_0000001662634961.png]]
    
    -   The following shows the display effect.
        
        ![[en-us_image_0000001613955086.png]]
        
    
3.  Set **Icon Class** to **ion-group**.
    
    ![[en-us_image_0000001614275074.png]]
    
    -   The following shows the display effect.
        
        ![[en-us_image_0000001662235165.png]]
        
    
4.  Set **Displayed Button Number** to **2**.
    
    ![[en-us_image_0000001662515137.png]]![[en-us_image_0000001614115130.png]]
    
    -   **Displayed Button Number** is used to control the number of buttons to be displayed in the bottom column. Extra buttons will be placed in the **More** button.
        
        ![[en-us_image_0000001613955090.png]]
        
    
5.  Drag a button under **Button**.
    
    ![[en-us_image_0000001662675001.png]]
    
6.  After the preceding configurations are complete, click **Preview**, and press and hold the list data to view the button in the button column group.
    
    ![[en-us_image_0000001614115174.png]]
    
7.  The **List Button Group** component mainly functions as a container and needs to work with other batch operation components.
