#### Orchestration Procedure

1.  Drag a **Column** component under **Columns**.
    
    ![[en-us_image_0000001679321965.png]]
    
2.  Set **Data Index** to **name**.
    
    ![[en-us_image_0000001532365081.png]]
    
    The value of **Data Index** needs to match the field name returned by the service.
    
3.  Set **Header** to **Name**.
    
    ![[en-us_image_0000001679321961.png]]
    
4.  Set **Weight** to **default**.
    
    ![[en-us_image_0000001481605432.png]]
    
    ![[note_3.0-en-us.png]]
    
    By setting **Weight**, you can configure the width of the current column in the table. If the default value **default** is used, the width of this column is evenly allocated with other columns whose values of **Weight** are also **default**. For example, if there are four columns whose values of **Weight** are **default**, each column occupies 25% of the total width.
    
5.  Configure the **sex** and **age** columns based on the preceding steps.
    
    ![[en-us_image_0000001679121797.png]]
    
6.  After the preceding configurations are complete, click **Preview**. The list as shown in the following figure is displayed.
    
    ![[en-us_image_0000001679001905.png]]
