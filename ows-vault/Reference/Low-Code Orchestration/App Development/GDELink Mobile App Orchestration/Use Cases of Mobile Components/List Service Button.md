#### Orchestration Procedure

1.  Drag a **List Service Button** component under **Button**.
    
    ![[en-us_image_0000001679344785.png]]
    
2.  Set **Text** to **Service**.
    
    ![[en-us_image_0000001630425226.png]]
    
3.  Set **Interface** to the service to be called.
    
    ![[en-us_image_0000001630585022.png]]
    
4.  Set **Parameters** to values in the following figures.
    
    ![[en-us_image_0000001679144733.png]]
    
    ![[en-us_image_0000001679024721.png]]
    
    The configured parameters are transferred to the service.
    
    ![[en-us_image_0000001679225093.png]]
    
5.  Set **Confirm Message** to **Are you sure you want to delete it?**
    
    ![[en-us_image_0000001679344781.png]]
    
    After you configure **Confirm Message** and click the button, a dialog box is displayed. You need to click **OK** before performing subsequent operations.
    
    ![[en-us_image_0000001679344745.png]]
    
6.  Set **Success Message** to **Service invoking succeeded!**
    
    ![[en-us_image_0000001679144797.png]]
    
7.  Set **Icon Class** to **ion-delete**.
    
    ![[en-us_image_0000001630745198.png]]
    
8.  After the preceding configurations are complete, click **Preview** and swipe left on the list data to view the button.
    
    ![[en-us_image_0000001679144601.png]]
