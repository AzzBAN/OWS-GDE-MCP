#### Orchestration Procedure

1.  Drag the **Recent Time Filter Item** component under **Filter Items**.
    
    ![[en-us_image_0000001630585142.png]]
    
2.  Set **Label** to **Recent Time Filter**.
    
    ![[en-us_image_0000001679225005.png]]
    
    ![[en-us_image_0000001679144845.png]]
    
3.  Set **Model Key** to **time**.
    
    ![[en-us_image_0000001679024941.png]]
    
4.  Set **Unit** to **Days**.
    
    ![[en-us_image_0000001679344865.png]]
    
5.  Set **Options** to values in the following figure.
    
    ![[en-us_image_0000001630904886.png]]
    
    ![[en-us_image_0000001630585042.png]]
    
    -   **Name** of an option is used to display the filtering item, and **Value** of an option is used to calculate the range of the recent time. If **Unit** is set to **Days**, the range is 15 days earlier than the current time. If **Unit** is **Hours**, the range is 15 hours earlier than the current time.
        
        ![[en-us_image_0000001630905126.png]]
        
        ![[en-us_image_0000001630745086.png]]
        
        After change of the value of Unit to Hours
        
        ![[en-us_image_0000001679224857.png]]
