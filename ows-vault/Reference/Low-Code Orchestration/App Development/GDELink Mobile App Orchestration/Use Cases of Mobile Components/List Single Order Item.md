#### Orchestration Procedure

1.  Drag a **List Single Order Item** component under **Order Items**.
    
    ![[en-us_image_0000001630904894.png]]
    
2.  Set **Attribute field** to **age**, **Header** to **Age**, and **sort** to **asc**.
    
    ![[en-us_image_0000002194721101.png]]
    
3.  Drag another **List Single Order Item** component under **Order Items**.
    
    ![[en-us_image_0000001679144581.png]]
    
4.  Set **Attribute field** to **name**, **Header** to **Name**, and **sort** to **desc**.
    
    ![[en-us_image_0000002159401746.png]]
    
5.  Two sorting items are displayed above the list. Click **Age** to sort the data in the list in ascending order and click **Name** to sort the data in the list in descending order.
    
    ![[en-us_image_0000001679224845.png]]
    
    ![[en-us_image_0000001679344881.png]]
    
    ![[en-us_image_0000001679225033.png]]
