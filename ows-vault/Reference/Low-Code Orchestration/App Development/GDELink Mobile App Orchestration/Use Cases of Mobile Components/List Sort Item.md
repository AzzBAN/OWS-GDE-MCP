#### Orchestration Procedure

1.  Drag a **List Sort Item** component under **List Multiple Sort Item**.
    
    ![[en-us_image_0000001630425434.png]]
    
2.  Set **Attribute field** to **age**, **Header** to **Age**, **Text** to **ASC**, and **sort** to **asc**.
    
    ![[en-us_image_0000002194725697.png]]
    
3.  Drag another **List Sort Item** component under **List Multiple Sort Item**.
    
    ![[en-us_image_0000001679344993.png]]
    
4.  Set **Attribute field** to **age**, **Header** to **Age**, **Text** to **DESC**, and **sort** to **desc**.
    
    ![[en-us_image_0000002159244454.png]]
    
5.  The sorting item **Age** is displayed above the list. Expand the item to view the ascending and descending orders.
    
    ![[en-us_image_0000001679224933.png]]
    
    Click an item to perform the sorting operation.
    
    ![[en-us_image_0000001679144809.png]]
    
    ![[en-us_image_0000001679225065.png]]
