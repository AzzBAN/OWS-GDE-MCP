#### Orchestration Procedure

1.  Drag a **List Filter** component under **List View**.
    
    ![[en-us_image_0000001679144625.png]]
    
2.  Set **Filter Title** to **Filter Example**.
    
    ![[en-us_image_0000001679144741.png]]
    
    When **Filter Items** or **Order Items** is configured for a filter, the value of **Filter Title** is displayed in the dialog box on the side bar.
    
    ![[en-us_image_0000001630585066.png]]
    
3.  Set **Sorting Parameter** as shown in the following figure.
    
    ![[en-us_image_0000001630905138.png]]
    
    ![[en-us_image_0000001679024677.png]]
    
    The **Name** area shows the value of **sort** transferred to the service, and the **Value** area shows the sorting item displayed on the page.
    
    ![[en-us_image_0000001630744982.png]]
    
    ![[en-us_image_0000001630425198.png]]
    
4.  Set **Sorting** to **desc**.
    
    ![[en-us_image_0000001630905170.png]]
    
    The default sorting order is **asc**. After the sorting order is changed to **desc**, the value of the **dir** parameter in the service changes to **DESC**.
    
    ![[en-us_image_0000001630425366.png]]
    
5.  Set **Sliding Direction** to **left**.
    
    ![[en-us_image_0000001630744978.png]]
    
    When **Filter Items** or **Sort Items** is configured for the list filter, the filter dialog box is displayed. **Sliding Direction** is used to control the pop-up direction of the dialog box. If you do not select a value from the drop-down list, the default value **right** is used, indicating that the filter is displayed on the right.
    
    ![[en-us_image_0000001630904930.png]]
