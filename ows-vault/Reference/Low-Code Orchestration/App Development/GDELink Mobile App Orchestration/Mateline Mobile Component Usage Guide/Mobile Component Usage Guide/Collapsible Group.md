# Collapsible Group

**Properties**

 
| Property Name | Description |
| :-- | :-- |
| Bar CSS | Customized collapse bar style |
| Bar Title | Collapse bar title |
| Icon CSS | Customized icon style |
| Bar Style | Indentation style of the collapse bar |
| Can collapsible | Whether the component can be collapsed |
| Fold Tag Location | Collapse button position |
| Initial Action | Whether the component is expanded or collapsed by default |
| Height | Collapse bar height | **APIs**

**hide**

Description: Hide a component.

**show**

Description: Show a component.
