# Service Button

**Properties**

 
| Property Name | Description |
| :-- | :-- |
| Access Control | Whether to enable the permission control. The default value is false. |
| Action Type | Service type. The value can be Create, Update, Delete, or DeleteAfterSuccess. |
| Can Use When Offline | Whether the button can be used in offline mode |
| Confirm Message | Confirmation information before the button is clicked |
| Go Back After Success | Whether to return to the previous page after the service is successfully submitted. |
| ID | Component ID |
| Ignore Item Page History | Whether to ignore the page redirection history |
| Link Parameters | N/A |
| Location | OWS page that is redirected to |
| Parameters | URL redirection parameter. Dynamic parameters are supported. |
| Service ID | Submitted service |
| Success Message | Success message |
| Success To | Page displayed after a successful operation |
| Text | Text in the button |
| Which Form To Submit | ID of the form bound to the service button |
| Visible | Whether to display the button |
| Align | Button position |
| Css Class | Button style |
| Icon Class | Button icon |
| Style | Used with CSS Class and Icon Class | **APIs**
