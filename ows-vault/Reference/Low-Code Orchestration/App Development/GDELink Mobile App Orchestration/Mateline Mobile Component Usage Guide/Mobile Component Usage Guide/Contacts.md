# Contacts

Note: Display contacts.

**Properties**

 
| Property Name | Description |
| :-- | :-- |
| Id | Component ID |
| KeyMapping | Key value table, which is used to configure the service field corresponding to the contact information. The format is {"fullName":"xx","role":"xx","telephone":"xx","imCount":"xx","state":"xx"}. |
| Name | (Mandatory) Name |
| Parameters | Parameter of the service to be called |
| Service Id | ID of the service to be called |
| Visible | Components that meet the conditions are visible. |
| Split | Style of the dividing line. This parameter is optional. The options are dashed, dotted, and solid. | **Parent topic:** [[Mobile Component Usage Guide|Mobile Component Usage Guide]]
