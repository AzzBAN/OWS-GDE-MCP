# Column

This component is configured on Data Grid.

**Properties**

 
| Property Name | Description |
| :-- | :-- |
| Data Index | Source of the data in columns, which is a key value returned by the service. |
| Header | Information displayed in the column header |
| Location | Redirection position. After this property is configured, the column changes to a link. |
| Weight | Percentage of the column width to the width of the entire table | **APIs**
