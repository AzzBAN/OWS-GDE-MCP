# Single Contact

**Properties**

 
| Property Name | Description |
| :-- | :-- |
| fullName | Full name of a user. This parameter is used when EaseMob chat is used. If this parameter is not set, contact information is not displayed. |
| imCount | Used when EaseMob chat is used |
| Name | Component name |
| Role | User role |
| State | User status. 0: offline; 1: online |
| telephone | User phone number |
| visible | Component display condition | **APIs**
