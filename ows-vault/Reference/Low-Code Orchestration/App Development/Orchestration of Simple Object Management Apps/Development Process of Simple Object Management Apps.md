#### Scenario Description

Simple object management apps are usually used to model data and allow users to perform operations such as adding, deleting, modifying, and querying data through pages and services in offering, member, and device management scenarios.

The core functions of such apps are to add, delete, modify, and query data. Therefore, data models need to be designed first and then data can be added, deleted, modified, and queried based on the data models.
