# Orchestration of Simple Object Management Apps

The simple object management apps are used to orchestrate basic elements, including models, services, events, timers, pages, documents, menus, data processing, and permission management.

-   **[[Development Process of Simple Object Management Apps|Development Process of Simple Object Management Apps]]**  
    This section describes the process of developing a simple object management app.
-   **[[Model Configuration|Model Configuration]]**  
    Simple object management apps are mainly used to add, delete, modify, and query data and a model used for storing data is indispensable. Therefore, you need to design a model first and create it based on the plan.
-   **[[Configuring Pages|Configuring Pages]]**  
    
-   **[[Configuring Services|Configuring Services]]**  
    A service is used to orchestrate various operations of a model based on logical conditions.
-   **[[Configuring a Model Flow|Configuring a Model Flow]]**  
    
-   **[[Configuring a Trigger|Configuring a Trigger]]**  
    In the data model, events of specified types, service calling, and data operations can be triggered based on data changes.
-   **[[Configuring an Event and an Event Listener|Configuring an Event and an Event Listener]]**  
    An event and an event listener are used to define scenarios where specified actions are executed under specific conditions.
-   **[[Configuring Data Import and Export Services|Configuring Data Import and Export Services]]**  
    In actual data configuration scenarios, data needs to be imported in batches. This section describes how to configure the data import service.

-   **[[Configuring a Timer|Configuring a Timer]]**
