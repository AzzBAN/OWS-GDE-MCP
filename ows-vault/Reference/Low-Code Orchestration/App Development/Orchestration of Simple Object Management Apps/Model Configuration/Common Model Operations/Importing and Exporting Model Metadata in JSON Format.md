#### Context

After you configure a model in a project, if the same model configuration is required in another project, you can export the model metadata in JSON format and import it to another project.

The model metadata in JSON format includes the basic model definition, model property configuration, model index, and sharding policy of the model.

![[note_3.0-en-us.png]]

-   You can export the metadata of a maximum of 20 models at a time.
-   When you export the model metadata in JSON format, if the exported model metadata file needs to be imported to another project module, you need to modify the file to meet the requirements of the new module.
