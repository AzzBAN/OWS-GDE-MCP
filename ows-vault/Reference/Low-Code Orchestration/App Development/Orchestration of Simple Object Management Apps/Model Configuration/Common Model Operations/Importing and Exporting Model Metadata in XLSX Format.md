#### Context

If you want to add multiple properties to a model, use an Excel file to sort out the properties. In this case, using an Excel file is more convenient and faster than using the console. After the properties are sorted out by using the Excel file, use the Excel file to import model metadata. This improves the data import efficiency.

![[note_3.0-en-us.png]]

To use an Excel file to import model metadata, you need to take note of the following items:

-   The maximum size of the Excel file is 2 MB.
-   The Excel file can be used to import metadata of up to 20 models, and each model can contain up to 200 fields.
