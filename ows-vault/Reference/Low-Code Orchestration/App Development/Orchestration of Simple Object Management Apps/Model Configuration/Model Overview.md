#### Introduction to Models

In ADC simple object management apps, a data model is equivalent to a table created in the database when a service system is developed in traditional mode. The data model is used to store the configuration data and service data required by the service system.

If you want to develop an offering management system to perform operations, such as adding and querying offering information, you need to create a table to store the offering information, such as offering names and prices. The offering information table is a data model to be planned.
