# Model Archiving Configuration

The system allows you to archive a single model or associated models at a specified time. Archived models can be deleted or dumped.

-   **[[Introduction to Model Archiving|Introduction to Model Archiving]]**  
    The system allows you to archive a single model or associated models at a specified time. Archived models can be deleted or dumped.
-   **[[Independent Model Archiving Configuration|Independent Model Archiving Configuration]]**  
    For models that do not have dependencies or models depended on the root node, archive them independently. This section describes how to configure independent archiving.
-   **[[Associated Model Archiving Configuration|Associated Model Archiving Configuration]]**  
    The system allows you to archive a single model or associated models at a specified time. Archived models can be deleted or dumped.
