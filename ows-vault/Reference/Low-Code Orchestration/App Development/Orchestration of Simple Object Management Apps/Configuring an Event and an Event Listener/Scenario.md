# Scenario

In actual application scenarios, when an event needs to be triggered under a certain condition, you can use events and event listeners to define the scenario.

For example, in model A, the event and event listener are used to define the **status** field of data. When the value of **status** changes to a value indicating completion, a service is triggered to send a completion notification to the third party.
