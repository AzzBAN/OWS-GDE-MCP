#### Context

In a same app, you can use roles to differentiate permissions for different users.

For example, a common user can only view pages and services. The administrator can add, delete, modify, and query pages and services.

In this case, you can create a common user role and only assign the role the permission for viewing pages and services. Create an administrator role and assign permissions for adding, deleting, modifying, and querying pages and services.

When creating a user, you can select different roles for the user to obtain different permissions.
