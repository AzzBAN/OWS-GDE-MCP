#### Context

**Permission Compatibility** is available only when historical legacy assets are imported. If a project is created based on ADC 2._X_ or later, skip this section.

The permission compatibility function can be used for historical legacy assets to manage permission items in a unified manner. The logic for managing permission items is the same as that in earlier versions but different from that in the current version.
