#### options

After you click **data** and **name** parameters under **series**, the **Variable Input** dialog box is displayed, which contains three fields: **Object**, **Value**, and **Input**.

Select a data source from **Object**, a variable type from **Value**, and the variables that are finally entered to the system from **Input**. You can also enter the name of **series** in **Input**.

**Figure 1** series  
![[en-us_image_0000001212092081.png]]

-   Select a data source from the **Object** drop-down list box. The **Input**, **Page**, **Get**, and customized data source names are displayed in this drop-down list box.
    
     
    | Option | Description |
    | :-- | :-- |
    | Input | Variable value of the Parameter property for the ECharts component. |
    | Page | Obtain the component value of the page according to the component ID. |
    | Get | Obtain the values of parameters in the page URL. | In addition to the preceding default settings, you can select user-defined data source names.
    
-   User-defined data source values

When **Object** is set to a customized data source, the **Value** drop-down list shows customized columns and built-in variables of the system. For example, **timeValues**, **ind1Values**, **ind2Values**, and **ind3Values** in the following figure are the values of customized columns.
