#### aotoRefresh Properties

After you set the autoRefresh properties, the system refreshes charts at a specified interval.

Right-click **Echarts** and choose **autoRefresh** from the shortcut menu. Enter a digit (unit: s), which means that the charts are refreshed periodically.
