#### Context

To facilitate the definition of upper-layer services on the GUI style, you can customize the style of an existing theme by extending the theme and setting custom variables.

Baseline themes and custom themes can be extended but extended themes cannot be extended.

Each baseline theme and custom theme can be configured with only one extended theme.
