#### Rapid Reuse of Component Assets

-   **Basic**: provides built-in basic components, for example, **Layout**, **Navigator**, and **Button**.
-   **Extended**: provides components that are extended based on basic components and contain certain scenarios and service meanings. Generally, a component is developed and customized by developers using Pro Code.
-   **Template**: provides page template components. Preset and customized page templates are included. When creating a page, you can select a template. After the page is created, the page template can still be used as a component for quick use and reuse.
