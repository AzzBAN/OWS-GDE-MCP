#### Context

The system allows users to customize labels for orchestration elements such as data visualization screen and page.

The entry for configuring labels for each orchestration element is different.

-   Entry path for configuring data visualization screen card labels: **Card** > ![[en-us_image_0000001572606758.png]] (**Card List**) > **Tag Management**
-   Entry path for configuring data visualization screen card templates: **Card** > ![[en-us_image_0000001572127942.png]] (**Card List**) > **Tag Management**
-   Entry path for configuring data visualization screen page labels: **Data Visualization** > ![[en-us_image_0000001622487453.png]] (**Data Visualization List**) > **Tag Management**
-   Entry path for configuring PC page labels: **Page** > ![[en-us_image_0000001622553625.png]] (**Page List**) > **Tag Management**
-   Entry path for configuring data visualization screen block labels: **Data Visualization** > **Orchestration Resource** > **Data Visualization Block Management** > **Tag Management**
-   Entry path for configuring data visualization screen template labels: **Data Visualization** > **Orchestration Resource** > **Data Visualization Template Management** > **Tag Management**

The following procedure uses a page label as an example to describe the configuration method.
