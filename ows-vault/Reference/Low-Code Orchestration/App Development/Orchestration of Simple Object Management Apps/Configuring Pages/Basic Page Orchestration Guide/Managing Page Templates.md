#### Context

You can select an existing page template and create a page based on the template.

Alternatively, you can create a template and use it to create a page. Using a template to create a page can improve the efficiency of creating pages with similarities.

Page templates are global assets, that is, page templates created in projects. Page templates have a permission system independent from projects.
