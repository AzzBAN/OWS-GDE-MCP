#### Context

The system provides preset script templates based on common scenarios. Developers can quickly insert these preset script templates into scripts, improving orchestration efficiency.

In complex projects, developers can define script templates, encode template scripts in advance, and then insert template scripts where templates are required to improve development efficiency.
