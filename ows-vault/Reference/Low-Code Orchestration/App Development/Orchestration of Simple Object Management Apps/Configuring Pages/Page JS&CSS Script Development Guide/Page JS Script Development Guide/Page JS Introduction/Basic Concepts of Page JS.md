# Basic Concepts of Page JS

-   JavaScript (JS) is a lightweight, interpreted, or just-in-time compiled programming language with first-class functions. It is the most popular script language for developing Web pages. Almost all modern HTML pages and browsers support JavaScript.
-   The main functions of the page JS script are as follows:
    -   Embed dynamic text into HTML pages.
    -   Respond to browser events.
    -   Read and write HTML elements.
    -   Validate data before the data is submitted to the server.
    -   Detect guests' browser information.
