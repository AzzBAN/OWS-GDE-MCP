# Restrictions

Due to security and trustworthiness requirements, the front-end/terminal-defined CSS may be prohibited from directly depending on the DOM element structure, and some native properties may also be disabled. Do not use complex properties during development to avoid maintenance inconvenience caused by restrictions in the future.
