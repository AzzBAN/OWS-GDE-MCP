# Common Properties

-   **margin**: Outer margin used by most components
-   **padding**: Inner margin used by most components
-   **color**: Color used by components such as the button, text, list view, bulletin, button bar, and collapse bar
-   **border-radius**: Rounded border used by components such as the button, list view, date text box, drop-down list box, and process status.
-   **background**: Background used by components such as the button, date text box, process status, list container, search box, and text box.
-   **font-size**: Font size used by components such as the button, text, list view, bulletin, button bar, collapse bar, search box, and text box.
