# Basic Concepts of Page CSS

-   Cascading Style Sheets (CSS) is a computer language used to represent web page styles. CSS can statically decorate pages and dynamically format page elements using various scripts. CSS can precisely control the layout of elements on web pages at the pixel level, support almost all font sizes, and edit web page objects and model styles.
-   Page CSS has the following features:
    -   Rich style definitions
    -   Easy to use and modify
    -   Able to be moved to multiple pages for a unified style
    -   Separation of the page function and style design, facilitating redesign and replacement
-   Restrictions on using page CSS are as follows:
    -   Properties can be set only by ID. Class is not supported.
    -   Only the property whitelist is supported. Other properties are filtered.
