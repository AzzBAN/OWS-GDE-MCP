#### Prerequisites

A Node.js whose version is between v14.17.1 and v18.20.1 has been installed.

-   To check the Node.js version, open the CMD window on the local PC and run **node -v** on the CLI to check the node version.
-   You can download Node.js from **https://nodejs.org/en/download/**. **If the version of the installed Node.js is too early, download and install it.**
-   There is a version mapping between Node.js and npm. Ensure that the NPM version matches the Node.js version based on the mapping provided in [Nodejs Version Mapping](https://nodejs.org/en/about/previous-releases) to avoid version mismatch caused by manual npm upgrade.
    
    Method of checking the NPM version: Open the CMD command window on the local host and run the **npm -v** command to check the NPM version.
