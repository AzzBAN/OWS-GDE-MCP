#### Procedure

1.  On the menu bar, choose **Page** > **Orchestration Resource** > **Third-Party JS Class Libraries**.
2.  Click **Import**.
3.  Click **Add** to select a third-party JS class library package to be imported.
    
    **Figure 1** Uploading a third-party JS class library package  
    ![[en-us_image_0000001168467355.png]]
    
4.  Click **Confirm**.
5.  Specify **Release Note** after the system automatically obtains the JS class library information upon parsing.
    
    **Figure 2** Information confirmation  
    ![[en-us_image_0000001168547381.png]]
    
6.  Click **OK**.
