#### Context

A third-party JavaScript class library can automatically create **adcui.json** during initialization.

{
  "name": "thirdJS",
  "projectName": "DEMO\_ZJ",
  "moduleName": "ZJ",
  "version": "0.0.1",
  "type": "jsLib",
  "description": "test",
  "dependencies": \[
    "index.js"
  \]
}
