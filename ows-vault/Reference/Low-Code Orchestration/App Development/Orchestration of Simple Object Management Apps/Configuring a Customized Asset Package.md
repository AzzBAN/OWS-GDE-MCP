#### Prerequisites

-   A project and a module have been created.
-   The **Data Package** > **Customized Asset** menu has been displayed. For details, see [[Configuring the Module Navigation Menus|Configuring the Module Navigation Menus]].
-   The service to be called by the scheduled job has been configured.
