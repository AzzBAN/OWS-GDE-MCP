# Configuring a Timer

A timer is used to define a one-off or periodic job that is executed at specified time.

-   **[[Introduction to Timers|Introduction to Timers]]**  
    
-   **[[Configuring a Repeat Timer|Configuring a Repeat Timer]]**  
    A Repeat timer is used to configure jobs that are executed at a fixed interval and number of times.
-   **[[Configuring a Cron Timer|Configuring a Cron Timer]]**  
    A Cron timer is used to configure scheduled jobs with complex time rules.
