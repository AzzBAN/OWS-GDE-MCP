#### Context

For apps that contain operation pages, you need to mount the pages to the menu path to facilitate user operations. Menu names can be translated into multiple languages. External URLs can be integrated to the system through menu configuration.

![[note_3.0-en-us.png]]

If no menu is preset for the page, no visible entry is available for users after the app is installed, which affects user experience.

For example, in the offering management system, the offering information management page is mounted as the **Offering Information Management** menu. Users can click the menu to access the corresponding page.

If an application has multiple menus, you can plan multi-level menus. For example, two-level menus listed in the following table are planned based on the functions of the offering management system.

**Table 1** Menu   
| Level-1 Menu | Level-2 Menu | Description |
| :-- | :-- | :-- |
| Offering Management System | Offering Information Management | 
-   Level-1 menu: directory menu. No URL or page needs to be mounted.
-   Level-2 menu: pages orchestrated in the app are mounted.
