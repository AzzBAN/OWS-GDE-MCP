#### Context

After the template for importing and exporting data is configured, a page for importing and exporting data needs to be provided for users. In this way, users can use page components to call data import and export services.

When a model is created based on ADC and services and pages are automatically generated, the automatically generated **xx\_xx\_grid** page contains the **Import** button by default and can call the automatically generated **xx\_xx\_import** page.

This section describes how to assemble and configure a page when a developer needs to create a page to call the Excel service.
