#### Context

-   Model operations include creating, updating, deleting, querying a single data record or the data list in a batch. You can select a template when creating a service to quickly create a model.
-   You can create, update, and query a single data record or a list, and create, update, and supplement them in a batch using the service automatically generated by a model.
-   In complex service scenarios, you can drag and drop different orchestration elements based on service requirements. If you do not use a template to create a service, manually set the input and output parameters of the service.
-   On each operation node, you can customize the input parameter filtering function. If the filtering function is enabled, only the parameters configured on this node are transferred. If the filtering function is disabled, all output parameters of the previous node are used as input parameters for the current node.
