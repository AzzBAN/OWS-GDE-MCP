#### Context

Various types of interfaces can be called through service calling.

-   Service: You can call other services in a service.
-   Model: built-in model interfaces for data addition, deletion, modification and query.
-   SOAP: Outbound SOAP interface, which is called by the integration service.
-   REST: Outbound REST interface, which is called by the integration service.
-   Function: Function service to be called.
-   Outbound API: Outbound interface introduced through API Fabric (on the **Outbound API** tab page).
-   API: Public API asset registered with API Catalog.
