#### Context

In the scenario where there is a large number of script codes, the common capabilities are used as common functions. In this case, the common functions can be called in the script to improve the script maintenance efficiency.

For details about the syntax and examples of RunScript, see [[Service JavaScript Syntax and API Reference|Service JavaScript Syntax and API Reference]].
