#### Context

When editing a script, you can click **Insert Script** to quickly obtain the script code snippet.

In addition, you can view the script template to learn about the script sample and template information provided by the system. Script templates preset in the system are read-only and cannot be edited or modified.

In addition, users can create custom script templates for use in projects.

The script templates are classified into the following types and can be used in different scenarios:

-   **Run Script**: provides the script sample used in the run script of the service.
-   **Validator**: provides the script sample used in the validator.
-   **Translator**: provides the script sample used in the translator.
