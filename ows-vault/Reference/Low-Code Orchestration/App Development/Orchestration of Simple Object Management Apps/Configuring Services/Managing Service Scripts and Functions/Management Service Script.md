#### Context

When a RunScript script is created during service orchestration, each script is stored independently. You can create and select scripts on the Run Script node, validator, and translator of a service.

To facilitate script management, the system provides the **Service** > **Orchestration Resources** > **Script Management** page. On this page, you can edit scripts and view association relationships between scripts.
