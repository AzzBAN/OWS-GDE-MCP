# Configuring Services

A service is used to orchestrate various operations of a model based on logical conditions.

-   **[[Preparations|Preparations]]**  
    
-   **[[Service Orchestration Elements|Service Orchestration Elements]]**  
    This topic describes the orchestration elements involved in services.
-   **[[Creating a Service (Blank Template)|Creating a Service (Blank Template)]]**  
    
-   **[[Creating a Service (Based on a Preset Template)|Creating a Service (Based on a Preset Template)]]**  
    When you use a template to create a service, the system automatically generates corresponding operation nodes based on the selected template type and imports the model data to the service parameters based on the associated model.
-   **[[Configuring the Element Validator|Configuring the Element Validator]]**  
    The element validator provides a validation mechanism for input elements of a service.
-   **[[Configuring the Element Translator|Configuring the Element Translator]]**  
    The element translator provides a mechanism to convert the input and output elements of a service to store or return the converted elements.
-   **[[Managing Service Scripts and Functions|Managing Service Scripts and Functions]]**  
    
-   **[[Running Services|Running Services]]**  
    
-   **[[Step Debugging Service|Step Debugging Service]]**  
    
-   **[[Registering a Service with the API Catalog|Registering a Service with the API Catalog]]**  
    Developers can register services with the API catalog to use services in other scenarios.
-   **[[Configuring a Customized Authentication Service|Configuring a Customized Authentication Service]]**
