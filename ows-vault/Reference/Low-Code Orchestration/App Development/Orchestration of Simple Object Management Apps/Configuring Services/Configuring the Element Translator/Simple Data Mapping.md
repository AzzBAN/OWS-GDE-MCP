#### Context

By using the **Simple data mapping** translator in input parameters, the input character string **mbb** is mapped to **m** to store it in the database.

By using the **Simple data mapping** translator in output parameters, the returned information **m** can be mapped to **mbb** and then returned.

For example, if the following mapping is required for the element, you can configure the mapping by referring to the procedure in this topic.

**Table 1** Mapping relationship  
| Original Element | Target Element After Mapping |
| :-- | :-- |
| m | mbb |
| f | fbb |
