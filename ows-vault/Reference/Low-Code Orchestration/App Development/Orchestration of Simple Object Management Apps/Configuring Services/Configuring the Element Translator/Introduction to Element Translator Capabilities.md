# Introduction to Element Translator Capabilities

The element translator is used to translate service elements. Translators vary with parameter types.

**Table 1** Introduction to element translator capabilities  
| Element Type | Translator Type |
| :-- | :-- |
| String | 
-   General Configuration
    -   Date Time Converter
    -   Common functions
    -   Merging Information
    -   Simple data mapping
    -   Searching for Related Models
    -   UI Component Display Value Translation
    -   i18n translator
-   Run Script

 |
| Object/Array | -   General Configuration
    -   Common functions
    -   Attachment Translator
-   Run Script

 |
| Integer | -   General Configuration
    -   Merging Information
    -   Common functions
    -   Simple data mapping
    -   Searching for Related Models
    -   UI Component Display Value Translation
-   Run Script

 |
| Decimal | -   General Configuration
    -   Merging Information
    -   Common functions
    -   Simple data mapping
    -   Searching for Related Models
    -   UI Component Display Value Translation
-   Run Script

 |
| Boolean | -   General Configuration
    -   Merging Information
    -   Common functions
    -   Simple data mapping
    -   Searching for Related Models
    -   UI Component Display Value Translation
-   Run Script

 | Translators can be used in input and output parameters at the service level and input parameters at the operation level.
