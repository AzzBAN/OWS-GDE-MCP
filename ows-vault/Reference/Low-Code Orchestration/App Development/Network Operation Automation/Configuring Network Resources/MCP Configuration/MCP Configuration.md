# MCP Configuration

This topic describes how to manage APIs and configure common protocols, sensitive fields, command whitelists, and the device login information. You can create, modify, delete, import, and export configurations.

-   **[[Managing APIs|Managing APIs]]**  
    Configure APIs to interwork with different data sources, which means that you can obtain the EMS and device information from different systems.
-   **[[Configuring a Sensitive Field|Configuring a Sensitive Field]]**  
    Configure a sensitive field so that the field corresponding to input parameters in execution logs will be anonymized.
-   **[[Configuring a Command Whitelist|Configuring a Command Whitelist]]**  
    Configure a command whitelist. Only commands in the whitelist can be delivered to devices.
-   **[[Configuring the Device Login Information|Configuring the Device Login Information]]**  
    The system provides the page and model for configuring protocol login commands. After a command is issued to deliver the configured login details to the probe, you can log in to the device using this command.
