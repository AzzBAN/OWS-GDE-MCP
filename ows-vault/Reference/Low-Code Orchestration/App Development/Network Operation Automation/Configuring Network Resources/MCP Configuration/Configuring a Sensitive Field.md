#### Procedure

1.  Choose **General Settings** > **MCP Settings** > **Sensitive Field Config**.
2.  Click **Create**.
    
    ![[en-us_image_0000001135304230.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Sensitive Field | Field to be anonymized. Set this parameter based on site requirements. |
    | Description | Description of a sensitive field. | 3.  Click **OK**.
