#### Procedure

1.  Choose **General Settings** > **Resource Type Management** > **Network Type**.
2.  Click **Create** and set parameters.
    
    **Figure 1** Configuring a network type  
    ![[en-us_image_0000001181424549.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Network Type | Network type of a device. Set this parameter based on site requirements. |
    | Label | Network type label. The value can be customized. |
    | Mapping Name | Mapping name of a network type. This parameter is reserved and does not need to be set. |
    | Description | Description of a network type. | 3.  Click **OK**.
