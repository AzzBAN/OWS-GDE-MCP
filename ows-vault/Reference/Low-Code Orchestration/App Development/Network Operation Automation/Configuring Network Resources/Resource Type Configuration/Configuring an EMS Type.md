#### Procedure

1.  Choose **General Settings** > **Resource Type Management** > **EMS Type**.
2.  On the displayed page, click **Create** and set parameters.
    
    **Figure 1** Creating an EMS type  
    ![[en-us_image_0000001135304736.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | EMS Type | EMS type. Set this parameter as required, for example, Huawei M2000. |
    | Label | EMS label name. The value can be customized. |
    | Description | Description of an EMS type. | 3.  Click **OK**.
