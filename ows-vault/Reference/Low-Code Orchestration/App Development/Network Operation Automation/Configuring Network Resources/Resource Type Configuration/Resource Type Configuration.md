# Resource Type Configuration

Resource type management is the basis of resource management. It works with the resource management module to establish a complete resource management model.

You can add resource types one by one or in batches, export them in batches, and modify or delete configured resource types.

-   **[[Configuring an EMS Type|Configuring an EMS Type]]**  
    Configure an EMS type before adding an EMS or a device.
-   **[[Configuring a Network Type|Configuring a Network Type]]**  
    Configure the network type of a device.
-   **[[Configuring a Device Vendor|Configuring a Device Vendor]]**  
    Configure a device vendor.
-   **[[Configuring an NE Type|Configuring an NE Type]]**  
    Configure the type of the NE to which the device belongs.
-   **[[Configuring an NE Model|Configuring an NE Model]]**  
    Configure the model of an NE.
