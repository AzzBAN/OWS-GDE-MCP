#### Procedure

1.  Choose **General Settings** > **Resource Type Management** > **Device Vendor**.
2.  Click **Create** and set parameters.
    
    **Figure 1** Configuring a device vendor  
    ![[en-us_image_0000001181265577.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Device Vendor | Device vendor. Set this parameter based on site requirements, for example, ALU or Huawei. |
    | Label | Device vendor label name. The value can be customized. |
    | Vendor Code | Unique ID of a device vendor. Set this parameter as required. |
    | Actual | Whether the vendor is used. Select Yes or No. |
    | Mapping Name | Set this parameter as required. |
    | Description | Description of a device vendor. | 3.  Click **OK**.
