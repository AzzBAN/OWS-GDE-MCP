# Configuring Network Resources

This section describes how to configure MCP network resources.

-   **[[Resource Type Configuration|Resource Type Configuration]]**  
    Resource type management is the basis of resource management. It works with the resource management module to establish a complete resource management model.
-   **[[MCP Configuration|MCP Configuration]]**  
    This topic describes how to manage APIs and configure common protocols, sensitive fields, command whitelists, and the device login information. You can create, modify, delete, import, and export configurations.
