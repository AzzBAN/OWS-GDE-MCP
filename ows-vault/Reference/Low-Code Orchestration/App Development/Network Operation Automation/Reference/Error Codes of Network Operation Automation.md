# Error Codes of Network Operation Automation

This section describes common error codes and error descriptions of the network operation automation service.

**Table 1** Common error codes  
| Error Code | Description |
| :-- | :-- |
| 99999000 | A maximum of three commands can be concurrently debugged by a user. |
| 99999001 | Calling a service fails. |
| 99999002 | Obtaining the MCP probe corresponding to the EMS or device fails. |
| 99999003 | Obtaining device information fails. |
| 99999004 | Obtaining information about available EMSs or devices fails. |
| 99999005 | Obtaining the command configuration corresponding to the device information fails. |
| 99999006 | Device ID does not exist. |
| 99999007 | The device version is not configured. |
| 99999008 | The device vendor is not configured. |
| 99999009 | The device EMS is not configured. |
| 99999010 | Creating and delivering parameters fail. |
| 99999011 | Select a command. |
| 99999013 | Calling the collection service fails. Check the collector or probe status. |
| 99999014 | Delivering a file fails. |
| 99999016 | dstPath cannot contain spaces and '..'. |
| 99999017 | filePath cannot contain spaces and '..'. |
| 99999018 | Executing the command using the agent microservice fails. |
| 99999019 | batchId of the attachment is empty. |
| 99999020 | The attachment size cannot exceed 200 MB. |
| 99999021 | Obtaining the file name fails. The possible cause is that batchId does not exist. |
| 99999022 | A maximum of 100 characters are supported for the file name, excluding spaces or the special characters: (. /\\) |
| 99999023 | The attachment is empty. |
| 99999024 | Creating a temporary ZIP file fails. |
| 99999025 | The system is abnormal. | **Parent topic:** [[Reference|Reference]]
