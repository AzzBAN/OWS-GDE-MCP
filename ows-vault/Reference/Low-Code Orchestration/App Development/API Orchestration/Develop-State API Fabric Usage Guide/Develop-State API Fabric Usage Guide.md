# Develop-State API Fabric Usage Guide

This section describes how to use the develop-state API Fabric for API design and orchestration.

Single-tenant and multi-tenant modes are supported. In single-tenant mode, tenant switchover is not supported. That is, the default tenant after user login is the tenant specified during installation (the ID of the default tenant specified during installation is 1002).
