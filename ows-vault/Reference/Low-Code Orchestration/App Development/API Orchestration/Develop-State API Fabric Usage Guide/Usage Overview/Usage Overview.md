# Usage Overview

This section describes the function restrictions and the content that you need to pay attention to when using the functions.

![[notice_3.0-en-us.png]]

With this development mode enabled by the API Fabric, developers can create asset programs that can run on the API Fabric app execution engine by simply dragging and dropping with simple JavaScript code. Due to orchestration flexibility, developers can run any custom code, which may cause malicious code execution risks. To better utilize this capability, the following requirements must be met:

1.  All developers must perform orchestration and development by strictly following the operations in section "Development Specifications" in _API Fabric VXXXRXXXCXX Product Documentation (Customized Development)_. Malicious code in any form is prohibited, including but not limited to viruses, rogue software, Trojan horses, backdoors, listening programs, and mining programs.
2.  The system administrator must strictly review the development qualification of developers and assign permissions to developers who have obtained the asset development certification. Assigned permissions cannot be abused.
