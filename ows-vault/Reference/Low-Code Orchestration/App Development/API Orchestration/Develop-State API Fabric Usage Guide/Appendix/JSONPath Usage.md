#### Function Overview

JSONPath is used in JSON to replace XPath. The greatest advantage of XML is that a large number of tools can be used to analyze, convert, and selectively extract data from a document. XPath is one of these most powerful tools.

If XPath can be used to parse JSON, the following problems can be solved:

1.  The data does not use special scripts. You can find and obtain the scripts on the client.
2.  The JSON data requested by the client can reduce so that the data amount is the same as that of the data on the server, which minimizes the bandwidth usage for the response of server.
