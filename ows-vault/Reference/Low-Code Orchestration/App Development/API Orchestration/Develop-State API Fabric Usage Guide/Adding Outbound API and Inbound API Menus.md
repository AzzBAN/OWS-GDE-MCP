# Adding Outbound API and Inbound API Menus

In the GDE scenario, you need to manually add menus related to the API Fabric service in develop state to the navigation pane.

1.  Log in to the GDE data zone portal, and choose **Products and Services** > **Development State Studio**.
2.  After a project is created, the page for creating a module is displayed. After the module is created, click **More** in the lower left corner.
    
    ![[caution_3.0-en-us.png]]
    
    When creating a project, check whether the project permission is **PUBLIC**. If the permission is not **PUBLIC**, you cannot found menus under **Openness Integration**.
    
3.  Choose **Outbound API** and **Inbound API** under **Openness Integration**, and click **Save**.
