#### Procedure

1.  Select **Inbound API** or **Outbound API** as required and click **Develop APIs**.
2.  Go to the **Public Definition** tab page.
    
    Click **Public Definition** on the API Builder page. The **Variable Definition** page is displayed by default.
    
    **Figure 1** Accessing the Common Definition page  
    ![[en-us_image_0000001584969464.png]]
    
3.  Select **Public Process** and click **Add** to create a common process.
    
    In the displayed dialog box, enter the process name and description, and click **Confirm**.
    
4.  Define common process variables.
    
    1.  Select the common process to be defined. The process orchestration page is displayed.
    2.  Click **Process Variable**. On the displayed **Process Variable** page, click **Add**.
        
        Enter the variable name, type, and parameter attribute (**input** or **output**) as required. The type can reference the common structure.
        
    
5.  Orchestrate a common process.
    
    For details, see [[Orchestration|Procedure]].
    
6.  Click **Confirm**.
