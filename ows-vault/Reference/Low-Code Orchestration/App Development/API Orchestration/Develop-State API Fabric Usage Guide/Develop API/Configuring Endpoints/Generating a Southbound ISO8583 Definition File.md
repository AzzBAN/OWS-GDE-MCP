#### Context

The develop-state API Fabric bears the ISO8583 protocol through the RPC protocol to implement data forwarding and exchange.

Only northbound APIs using the RESTful protocol are supported. During process orchestration, you can click the RPC graphical element and select the ISO8583 protocol endpoint.
