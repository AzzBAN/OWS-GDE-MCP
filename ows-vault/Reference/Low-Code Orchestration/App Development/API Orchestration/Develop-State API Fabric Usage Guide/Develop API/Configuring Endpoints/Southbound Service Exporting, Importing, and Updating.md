#### Procedure (Exporting Southbound Services)

1.  Select the endpoint to be exported.
    
    On the **Endpoint Management** tab page, select one or more service endpoints to be exported.
    
2.  Click **Export Endpoint**.
    
    You can export the project package or source code package as required.
