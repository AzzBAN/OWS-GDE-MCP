#### Procedure

1.  Choose **More** > **Mock** next to the endpoint. The **EndpointMock** tab page is displayed.
    
    ![[en-us_image_0000001517349789.png]]
    
2.  Select the endpoint to be mocked, and click ![[en-us_image_0000001213980092.png]] next to **Test Stub Switch** to automatically obtain a simulation address. A test stub is automatically added to the list below.
    
    ![[note_3.0-en-us.png]]
    
    If the southbound address is configured in endpoint management, the obtained address is the configured southbound address.
    
3.  Click the test stub name. The test stub configuration page is displayed. For details, see [[(Optional) Creating a Test Stub|(Optional) Creating a Test Stub]].
