#### Prerequisites

-   You have accessed the **Endpoint Management** page to configure an endpoint.
    
    You can configure all common endpoints in the develop state.
    
    Click **Endpoint Management** on the API Builder page, as shown in the following figure.
    
    **Figure 1** Endpoint Management  
    ![[en-us_image_0000001635440089.png]]
    
-   Click the API for which an endpoint needs to be configured in the API list, and click **Endpoint Configuration**.
    
    You can only configure the common endpoint bound to the API.
