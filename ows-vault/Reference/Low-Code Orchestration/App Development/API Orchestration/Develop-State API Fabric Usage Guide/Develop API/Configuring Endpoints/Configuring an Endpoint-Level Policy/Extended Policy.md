#### Procedure

1.  Click the name of the endpoint to be configured, and choose **Endpoint-Level Policy** > **Extension Policy**.
2.  (Optional) Configure an extended policy.
    
    In the navigation pane, choose **Extension Policy**. The **Extension Policy** tab page is displayed.
    
    This function is customized for a specific site. After a policy is configured, you can select the policy in the runtime state.
    
    The policy is named in letters, for example, **policy1**.
