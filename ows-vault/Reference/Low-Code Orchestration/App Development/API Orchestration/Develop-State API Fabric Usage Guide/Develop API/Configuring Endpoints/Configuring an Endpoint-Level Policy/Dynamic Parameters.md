# Dynamic Parameters

Only REST and SOAP endpoints are supported. Dynamic parameters need to be configured on the page displayed after you choose **Common Definition** > **Common Policy** > **Dynamic Parameters**. You can choose **Endpoint Management**, click the corresponding service name, choose **Dynamic Parameters**, and reference existing dynamic parameters.

![[note_3.0-en-us.png]]

One endpoint can be bound to only one common policy of dynamic parameters, but one common policy of dynamic parameters can be bound to multiple endpoints.
