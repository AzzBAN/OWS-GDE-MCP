#### Prerequisites

-   An API has been added.
-   A protocol conversion diagram element has been added to the process orchestration, and the endpoint and method called by the API associated with the diagram element have been configured.
-   You have accessed the **Policy Configuration** page and clicked the **API-Level Policy** tab.
    
    After adding an API or clicking an added API, click **Policy Configuration**.
