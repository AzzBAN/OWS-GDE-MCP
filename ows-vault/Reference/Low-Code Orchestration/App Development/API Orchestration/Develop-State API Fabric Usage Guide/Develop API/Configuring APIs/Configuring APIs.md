# Configuring APIs

This function is used to manage northbound APIs. Northbound APIs or APIs refer to APIs provided by the API Fabric for third-party systems to call.

These APIs can be managed and customized, such as configuring policies, referencing southbound services, and orchestrating processes. In addition, this function is used to convert protocols used for southbound and northbound APIs to solve the problem that the northbound and southbound APIs in the real service system cannot be interconnected because they use different protocols. Quick customization can be implemented for baseline APIs.

-   **[[Adding an API|Adding an API]]**  
    Add APIs called by third-party systems. After the APIs are added, API definitions can be displayed or modified, processes can be orchestrated, and policies can be configured.
-   **[[Generating an SMPP Definition File|Generating an SMPP Definition File]]**  
    The develop-state API Fabric supports the function of generating APIs by importing SMPP definition files and configuring policies on the page.
-   **[[Generating a Northbound ISO8583 Definition File|Generating a Northbound ISO8583 Definition File]]**  
    The develop-state API Fabric supports the function of generating APIs by importing ISO8583 definition files and configuring policies on the page.
-   **[[Orchestrating APIs|Orchestrating APIs]]**  
    The API Fabric supports graphical orchestration. You can adjust the diagram element structure and configure diagram element data for orchestration.
-   **[[Configuring API Policies|Configuring API Policies]]**  
    This section describes how to configure API-level policies and sensitive logs.
