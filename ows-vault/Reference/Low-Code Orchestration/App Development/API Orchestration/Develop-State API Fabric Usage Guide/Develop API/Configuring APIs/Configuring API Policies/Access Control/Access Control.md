# Access Control

-   **[[Authentication|Authentication]]**  
    Configure the API security authentication mode so that only users meeting the requirements can access the API. Malicious users are not allowed to construct URLs that are not authenticated by copying URLs and access the APIs without permission. Both the API-level and method-level authentication can be configured.
-   **[[Blacklist and Whitelist|Blacklist and Whitelist]]**  
    The API Fabric supports the configuration of the IP address blacklist and whitelist for each API.
-   **[[JWT Validation|JWT Validation]]**  
    JSON Web Token (JWT) is a JSON-based open standard. The API Fabric can verify whether a request sent by a client is valid based on the JWT.
