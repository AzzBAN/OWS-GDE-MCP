#### Procedure

1.  Choose the **Bypass** mode.
    
    The **Orchestration** mode is used by default. You can click ![[en-us_image_0000001532133010.png]] next to the method and choose **Bypass** from the shortcut menu, as shown in [Figure 1](#EN-US_TOPIC_0000001582641165__en-us_topic_0000001582532889_fig674075711619).
    
    **Figure 1** Choosing the bypass mode  
    ![[en-us_image_0000001532292962.png]]
    
2.  Select the southbound service and method to be called.
3.  Click **Save**.
