#### Restrictions and Description

-   You can choose **More** > **API Definition File Management** next to the API to import or add a definition file. If a definition file already exists, you cannot add a definition file.
-   You can import WSDL and ZIP files. The size of a WSDL file (including an XSD file) cannot exceed 5 MB.
-   For details about special usages and restrictions of the SOAP protocol in the API Fabric, see [[SOAP|SOAP]].
-   Currently, the API Fabric can parse the following SOAP media types:
    -   text/xml
    -   application/soap+xml
