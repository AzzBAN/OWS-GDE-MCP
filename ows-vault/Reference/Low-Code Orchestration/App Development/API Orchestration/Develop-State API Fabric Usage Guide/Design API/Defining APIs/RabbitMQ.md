#### Prerequisites

1.  The operations in [[Adding APIs|Adding APIs]] have been performed.
2.  Before an API is added, the addresses of the virtual host and switch have been configured.
    
    ![[notice_3.0-en-us.png]]
    
    Set parameters of the virtual host and switch based on parameters configured in the RabbitMQ service interconnected with the runtime state production environment. Otherwise, the APIs fail to be published when they are imported to the runtime state.
    
3.  You have accessed the **Parameter Definition** page. For example, an API named **rabbitmqexample** has been added.
    
    You can click the target API in the API list.
