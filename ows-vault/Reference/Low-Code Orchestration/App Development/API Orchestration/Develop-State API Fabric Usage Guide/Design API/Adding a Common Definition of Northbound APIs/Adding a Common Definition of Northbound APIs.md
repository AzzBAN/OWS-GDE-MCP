# Adding a Common Definition of Northbound APIs

On the **Common Definition** tab page, you can define common configuration for all APIs or northbound services, including common structures and common error codes.

Configurations defined on the **Common Definition** tab page are global variables.

-   **[[Common Structures|Common Structures]]**  
    Currently, the Investigator supports the definition of common REST structures. After the definition, the common structures can be directly referenced in the API definition to meet the requirement of reusing the common structures across APIs.
-   **[[Common Error Codes|Common Error Codes]]**  
    Global error codes are defined for reuse in APIs.
-   **[[Data Source|Data Source]]**  
    Global data sources are defined so that they can be referenced during the definition of middleware protocol types.
