# Developing an Inbound SOAP API

This section describes how to develop an inbound SOAP API.

-   **[[Configuring an Inbound SOAP API|Configuring an Inbound SOAP API]]**  
    Configure an inbound SOAP service to encapsulate developed services into an SOAP API. The third-party systems can call the inbound SOAP API to use the corresponding service functions.
-   **[[(Optional) Uploading the Inbound Authentication Strategy Certificate|(Optional) Uploading the Inbound Authentication Strategy Certificate]]**  
    If an inbound SOAP API uses the WSSE authentication mode and **Signature Type** or **User Name Token** is enabled, or an inbound SOAP API uses the Custom Account authentication mode, you need to upload the WSSE signature certificate file to the system or change the user password to ensure smooth API debugging.
-   **[[Debugging the Inbound SOAP API|Debugging the Inbound SOAP API]]**  
    After an inbound SOAP API is configured, you can debug the API to verify the configuration correctness.
-   **[[Verifying the Inbound SOAP API (by Calling the API by a Simulated Third-Party System)|Verifying the Inbound SOAP API (by Calling the API by a Simulated Third-Party System)]]**  
    This section describes how to use a tool to simulate a third-party system and call the inbound SOAP API to verify it.
