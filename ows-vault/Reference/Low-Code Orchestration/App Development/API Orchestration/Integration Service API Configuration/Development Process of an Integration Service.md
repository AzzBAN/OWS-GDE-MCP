#### Scenario Description

Integration services provide the capability of interacting with third-party systems through REST or SOAP APIs. From the perspective of service interaction direction, integration services are classified into outbound and inbound APIs. For example, a third-party system calls an inbound API developed in ADC to query specified service data, or ADC calls a developed outbound API to obtain service information from the third-party system.
