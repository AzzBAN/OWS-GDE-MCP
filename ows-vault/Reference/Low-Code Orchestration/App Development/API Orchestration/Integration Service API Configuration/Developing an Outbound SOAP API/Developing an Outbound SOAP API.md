# Developing an Outbound SOAP API

This section describes how to develop an outbound SOAP API.

-   **[[Configuring an Outbound SOAP API|Configuring an Outbound SOAP API]]**  
    This section describes how to configure an outbound SOAP service so that the SOAP API provided by a third-party system can be called on a page or in a service to use the corresponding service functions.
-   **[[Uploading the Outbound Authentication Strategy Certificate|Uploading the Outbound Authentication Strategy Certificate]]**  
    If an outbound SOAP API uses the basic authentication mode or the protocol specified in the authentication strategy is HTTPS, you need to change the user password or upload the truststore certificate file required by the HTTPS protocol to ensure smooth API debugging.
-   **[[Debugging the Outbound SOAP API|Debugging the Outbound SOAP API]]**  
    After an outbound SOAP API is configured, you can debug the API to verify the configuration correctness.
