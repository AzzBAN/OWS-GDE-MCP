# Developing an Inbound REST API

This section describes how to develop an inbound REST API.

-   **[[Configuring an Inbound REST API|Configuring an Inbound REST API]]**  
    Configure an inbound REST service to encapsulate developed services into an REST API. The third-party systems can call the inbound REST API to use the corresponding service functions.
-   **[[Debugging the Inbound REST API|Debugging the Inbound REST API]]**  
    After an inbound REST API is configured, you can debug the API to verify the configuration correctness.
-   **[[Verifying the Inbound REST API (by Calling the API by a Simulated Third-Party System)|Verifying the Inbound REST API (by Calling the API by a Simulated Third-Party System)]]**  
    This section describes how to use a tool to simulate a third-party system and call the inbound REST API to verify it.
