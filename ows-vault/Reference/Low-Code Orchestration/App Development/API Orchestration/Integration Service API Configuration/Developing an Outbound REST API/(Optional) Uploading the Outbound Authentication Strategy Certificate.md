#### Prerequisites

-   The project designed for the outbound REST API has been deployed to the runtime-state environment.
-   You have obtained the authentication keystore file of the third-party system or created the integration service certificate file by referring to [[How Do I Create a Truststore Certificate for HTTPS-based Outbound APIs-|How Do I Create a Truststore Certificate for HTTPS-based Outbound APIs?]]
-   (Optional) You have obtained the keystore certificate files required for authentication.
