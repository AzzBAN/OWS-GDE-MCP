# Developing an Outbound REST API

This section describes how to develop an outbound REST API.

-   **[[Configuring an Outbound REST API|Configuring an Outbound REST API]]**  
    This section describes how to configure an outbound REST service so that the REST API provided by a third-party system can be called on a page or in a service to use the corresponding service functions.
-   **[[(Optional) Uploading the Outbound Authentication Strategy Certificate|(Optional) Uploading the Outbound Authentication Strategy Certificate]]**  
    If an outbound REST API uses the basic authentication mode or the protocol specified in the authentication strategy is HTTPS, you need to change the user password or upload the truststore certificate file required by the HTTPS protocol to ensure smooth API debugging.
-   **[[Debugging the Outbound REST API|Debugging the Outbound REST API]]**  
    After an outbound REST API is configured, you can debug the API to verify the configuration correctness.
