# Preparing for Integration Service Development

Before developing an integration service, you need to create a project for the integration service, set common parameters, create a machine-machine user, and upload the integration service certificate.

-   **[[Creating a Project for the Integration Service|Creating a Project for the Integration Service]]**  
    Before developing an integration service, you need to create and configure a project for the integration service to facilitate subsequent project packaging and deployment.
-   **[[Configuring Common Parameters for the Integration Service|Configuring Common Parameters for the Integration Service]]**  
    Before developing an integration service, you need to configure required common parameters.
-   **[[Creating a Machine-Machine User for Authentication|Creating a Machine-Machine User for Authentication]]**  
    Before developing an integration service, you need to create a machine-machine user required for the integration service to perform authentication.
