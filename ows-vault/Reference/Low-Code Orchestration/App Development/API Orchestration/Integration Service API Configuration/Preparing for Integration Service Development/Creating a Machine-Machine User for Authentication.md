#### Prerequisites

-   You have logged in to the runtime-state environment.
-   The role required by the machine-machine user has been created. For details, see [User and Role Permission Management](nottoctopics/en-us_topic_0000001517745325.html).
-   (Optional) The IP address access control policy required by the machine-machine user has been created. For details, see [Creating an IP Access Control Policy](nottoctopics/en-us_topic_0000001098055410.html).
