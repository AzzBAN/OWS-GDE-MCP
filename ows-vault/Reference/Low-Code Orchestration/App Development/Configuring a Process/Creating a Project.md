#### Context

The project template provides a project template. You can create a project based on this template or using a blank template.

-   When a process is created based on a process template, the menus required by the process are automatically displayed for new modules.
-   When a project is created based on an existing project or using a blank template, you need to manually adjust the menus to be displayed.

The following shows how to create a project and project using a process template.

![[notice_3.0-en-us.png]]

You can import or export a process by importing or exporting a project or module. If you create a project or process by importing a project or module, pay attention to the following points:

-   Hot deployment cannot be directly enabled for the project imported with a process.
-   Hot deployment cannot be enabled for the existing project to which a compatible process is imported.
