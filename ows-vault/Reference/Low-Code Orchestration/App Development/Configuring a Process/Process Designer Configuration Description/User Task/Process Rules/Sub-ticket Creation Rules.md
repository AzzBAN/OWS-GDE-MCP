#### Context

If a sub-ticket needs to be automatically created for a process, you can configure sub-ticket creation rules.

Before configuring rules, plan the required rule events and rule activities by referring to [[Rule Design|Rule Design]]. The actual scenario is subject to the actual plan.

![[note_3.0-en-us.png]]

Sub-ticket creation rules can be configured only when the rule event is set to **Task Completed** or **Task Started**.
