#### Context

When other services need to be called during ticket handling, you can configure service call rules.

Before configuring rules, plan the required rule events and rule activities by referring to [[Rule Design|Rule Design]]. The actual scenario is subject to the actual plan.

![[note_3.0-en-us.png]]

If the rule event is **Before Task Completed**, service call rules cannot be configured. In other cases, service call rules can be configured.
