#### Context

You can configure field update rules if ticket fields need to be modified during ticket handling.

Before configuring rules, plan the required rule events and rule activities by referring to [[Rule Design|Rule Design]]. The actual scenario is subject to the actual plan.

![[note_3.0-en-us.png]]

Field update rules can be configured only when the rule event is **Before Task Completed**.
