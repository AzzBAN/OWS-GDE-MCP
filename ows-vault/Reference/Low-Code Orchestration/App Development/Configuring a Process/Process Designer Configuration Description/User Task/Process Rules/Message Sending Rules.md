#### Context

You can configure message sending rules when notifications need to be sent during ticket handling.

Before configuring rules, plan the required rule events and rule activities by referring to [[Rule Design|Rule Design]]. The actual scenario is subject to the actual plan.

![[note_3.0-en-us.png]]

If the rule event is **Ticket Participant** or **Before Task Completed**, service call rules cannot be configured. In other cases, service call rules can be configured.
