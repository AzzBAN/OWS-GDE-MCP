#### Context

You can configure status change rules to automatically change the service status of a ticket during ticket handling.

Before configuring rules, plan the required rule events and rule activities by referring to [[Rule Design|Rule Design]]. The actual scenario is subject to the actual plan.

![[note_3.0-en-us.png]]

Status change rules can be configured only when the rule event is **Ticket Canceled**, **Ticket Completed**, **Ticket Resume**, **Ticket Suspend**, **Subticket Updated**, or **Task Completed**.
