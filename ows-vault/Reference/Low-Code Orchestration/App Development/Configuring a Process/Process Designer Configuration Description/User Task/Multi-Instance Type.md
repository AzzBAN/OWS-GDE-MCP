#### Context

The multi-instance type is applicable to the scenario where multiple persons approve a task. In scenarios where multiple persons need to handle the task and make decisions at the same time, that is, a countersign task scenario, dynamic approvers are involved. In addition, different transfer paths need to be implemented based on the countersign approval result.
