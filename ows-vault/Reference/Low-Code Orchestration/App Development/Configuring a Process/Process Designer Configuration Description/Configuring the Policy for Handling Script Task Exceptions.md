#### Context

When an exception occurs in a script task, you can configure an exception handling policy including the following information:

-   **Terminate Exception**: The process ticket of the current script task is terminated unexpectedly, and the ticket status changes to **Completed**.
-   **Abort Exception**: The process ticket of the current script task is stopped unexpectedly, and the ticket status changes to **Running**.
-   **Ignore Exception**: The process ticket of the current script task ignores the exception and the ticket continues to be transferred.
