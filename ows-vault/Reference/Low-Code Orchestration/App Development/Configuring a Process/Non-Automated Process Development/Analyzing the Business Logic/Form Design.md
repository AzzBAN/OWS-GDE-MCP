#### CreateTask

**Table 1** Form of the CreateTask phase    
| Property Name | Property Type | Mandatory (Yes/No) | Data Source |
| :-- | :-- | :-- | :-- |
| First Occur Time | Date and time input | Yes | Selected or input by the event proposer. |
| Attachment | File input | No | Input by the event proposer. Multiple types of input materials, such as PDF, Excel and Word files and JPEG and PNG image files, are supported. |
| Description | Text input | No | Input by the event proposer. |
| Assign To | Handler selection | Yes | Selected by the event proposer. |
