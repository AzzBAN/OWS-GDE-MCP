# Process Design

Key elements of the design for non-automated processes are listed based on the requirement analysis.

The following uses a trouble ticket dispatching process as an example to describe the key elements that need to be analyzed in the customer process:

1.  Trouble ticket dispatching process (for example, user task process)
2.  Three process activity phases, including **CreateTask**, **ProcessTask**, and **ConfirmTask**
3.  Handler of each phase
4.  Branch and judgment conditions of each phase
