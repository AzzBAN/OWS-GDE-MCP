# Non-Automated Process Development

This topic describes how to create, configure, and debug a non-automated process.

-   **[[Analyzing the Business Logic|Analyzing the Business Logic]]**  
    Business logic analysis converts customer requirements into a process.

-   **[[Configuring Handlers for Process Phases|Configuring Handlers for Process Phases]]**  
    This section describes how to configure handlers for process phases.
