# Managing a Custom Process Component

This section describes how to manage custom process components, including creating, importing, exporting, and saving them as assets.

-   **[[Creating a Custom Process Component|Creating a Custom Process Component]]**  
    You can create a custom component on the **Orchestration Resource > Custom Process** Component page.
-   **[[Importing or Exporting a Custom Process Component|Importing or Exporting a Custom Process Component]]**  
    You can manage a custom process component by importing or exporting it.
-   **[[Saving a Custom Process Component as an Asset|Saving a Custom Process Component as an Asset]]**  
    You can save a custom process component as an asset for other projects to use based on site requirements.
