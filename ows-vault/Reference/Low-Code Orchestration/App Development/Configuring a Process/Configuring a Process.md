# Configuring a Process

A process is designed for a business object and is operated by different roles in different phases. This helps customers configure and develop processes in graphical mode.

-   **[[Process Development Overview|Process Development Overview]]**  
    Before using a process, you are advised to understand the basic concepts, permission description, and process designer of the process.
-   **[[Creating a Project|Creating a Project]]**  
    This section describes how to create a project required by a process on the **Project Management** page.
-   **[[Non-Automated Process Development|Non-Automated Process Development]]**  
    This topic describes how to create, configure, and debug a non-automated process.
-   **[[Automated Process Development|Automated Process Development]]**  
    An orchestrated API can handle a specific process. The input and output parameters, conditions, and phases of an API are set when it is developed. This ensures that phases are triggered when this API is applied to generate desired results.
-   **[[Development Guide of Introductory Processes|Development Guide of Introductory Processes]]**  
    This section describes how to create an introductory non-automated process using a simple process template. The introductory non-automated process contains common process components and can directly run the game of displaying all the prime numbers between one start number and end number.
-   **[[Process Designer Configuration Description|Process Designer Configuration Description]]**  
    This section describes the components and component properties in the process designer in detail and provides configuration examples.
-   **[[Custom Process Component Development Guide|Custom Process Component Development Guide]]**  
    A custom process component provides the capability of developing the process component and can be directly used in the process designer.
-   **[[Common Operations for Process Configuration|Common Operations for Process Configuration]]**  
    After developing a process, you can configure more properties for the process.
