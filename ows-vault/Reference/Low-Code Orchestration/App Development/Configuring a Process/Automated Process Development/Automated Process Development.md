# Automated Process Development

An orchestrated API can handle a specific process. The input and output parameters, conditions, and phases of an API are set when it is developed. This ensures that phases are triggered when this API is applied to generate desired results.

-   **[[Creating an Automated Process|Creating an Automated Process]]**  
    This section describes how to create a simple automated process, so that users can understand its basic configuration.
-   **[[Drawing a Diagram for the Automated Process|Drawing a Diagram for the Automated Process]]**  
    This section describes how to use the process diagram designer to draw a diagram for the automated process.
-   **[[Configuring an Automated Process Node|Configuring an Automated Process Node]]**  
    This section describes how to set common parameters in API orchestration, and configure process components from the start node (**Start Event**), processing nodes (such as **Service Task**), to the output node (**End Event**) based on the API orchestration sequence.
