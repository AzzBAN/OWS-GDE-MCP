# Development Guide of Introductory Processes

This section describes how to create an introductory non-automated process using a simple process template. The introductory non-automated process contains common process components and can directly run the game of displaying all the prime numbers between one start number and end number.

    This section describes how to create an introductory process to understand the basic configuration of the introductory process.
-   **[[Debugging an Introductory Process|Debugging an Introductory Process]]**  
    A process created based on a simple process template for quick start can be directly debugged without modification.
