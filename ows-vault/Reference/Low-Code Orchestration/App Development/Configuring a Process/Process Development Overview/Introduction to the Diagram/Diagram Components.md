# Diagram Components

The diagram designer allows users to drag various components to draw diagrams.

Components provided by the process designer include extended components and common process components. On the **APIs** and **Activity** tab pages, extended components including custom APIs and activities are provided for customizing orchestration elements. The dragging method of these extended components is the same as that of common process components.

-   Custom APIs, including APIs registered in the automated process and APIs in the runtime-state environment, can be filtered by permission. In addition, service task parameters can be configured.
-   Custom activities can be directly registered with the process management module to implement activity orchestration.

Static operation items are displayed based on the phase type of the process. **Recommended Action** is displayed only when there is no egress connection line in the current phase. That is, the possible next action is predicted based on the current user behavior on the canvas.
