# Drawing Method

This section describes the common methods of drawing a diagram.

-   Method 1 (drag-and-drop mode): Drag the required component from the component bar to the work area, as shown in the following figure.
    
    ![[en-us_image_0000001933966030.png]]
    
    ![[note_3.0-en-us.png]]
    
    -   If a user task is to be dragged, you need to initialize the task before drawing the process diagram.
    -   Activities, gateways, and components under **Activity** support quick insertion of a third node between two nodes.
    -   If a single node exists in the process canvas or the connection line between nodes is incomplete, the node is highlighted in red.
    
-   Method 2 (shortcut mode): Select a process component (for example, User Task) in the workspace, choose **Change Task** from the shortcut menu, and select the desired task, as shown in the following figure.
    
    ![[en-us_image_0000002159041804.png]]
    

![[note_3.0-en-us.png]]

Use sequence flows to connect components. If necessary, you can move components to check whether the sequence flows are successfully connected. Pay attention to the following skills for line connection s and shapes:

-   Line connection (drag-and-drop mode): Drag a sequence flow component from the left component bar to the canvas, and drag the start or end node of the line to the area around the component to be connected. When a green line (![[en-us_image_0000001483305222.png]]) appears around the component, release the mouse.
-   Line connection (shortcut mode): Click the start component to be connected in the work area, select the sequence flow from the shortcut menu, and drag the line to the area around the target component. When a green line (![[en-us_image_0000001534184945.png]]) appears around the target component, release the mouse.
-   Line shape change: Click a line (sequence flow component). Folding points appear on the line. Move the pointer to a folding point. When a cross appears, drag the line to change its shape (![[en-us_image_0000001483625062.png]]).
