# Diagram Designer

This section describes the page layout of the diagram designer.

![[en-us_image_0000002277654957.png]]

**Table 1** Description of the diagram designer page  
| Category | Function |
| :-- | :-- |
| Top - toolbar | Shortcut tools used for editing a diagram, including tools used for searching for nodes, saving, debugging, generating menus, undoing, redoing, deleting selected items, automatic layout, aerial view, zooming in, zooming out, and restoring the page, as well as selecting proportions. |
| Left - component bar | Components required for editing the diagram. For details, see Diagram Components. |
| Middle - work area | Work area for editing a diagram, which functions as a canvas. NOTE: By default, the system generates three simple user tasks. You can edit the tasks directly or delete the tasks and edit them as required. |
| Right - property bar | Property of the configured flow component. Select the component to be configured from the work area and set the corresponding property parameters in the property bar. Primary Property: core configuration items of a component. Non-automated process: includes properties such as process name, label, model, type, multi-instance type, default handler, filter handler, skip expression, condition, policy configuration, and rule. Automated process: includes properties such as process name, label, type, service task parameter, and script. More Properties: common properties (such as the style) in most cases, which are optional. You can retain the default values for them. | **Parent topic:** [[Introduction to the Diagram|Introduction to the Diagram]]
