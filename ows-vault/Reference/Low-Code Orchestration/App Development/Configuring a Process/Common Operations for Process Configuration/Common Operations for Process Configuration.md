# Common Operations for Process Configuration

After developing a process, you can configure more properties for the process.

-   **[[Manually Generating Menus|Manually Generating Menus]]**  
    You can create a menu item corresponding to the ticket creation page of the current process.
-   **[[Configuring a Service Type|Configuring a Service Type]]**  
    You can set the business process type.
-   **[[Configuring the Process Archiving|Configuring the Process Archiving]]**  
    Users can configure archiving for processes, and view the archiving configuration information.
-   **[[Configuring a Data Dictionary|Configuring a Data Dictionary]]**  
    To ensure the normal running of non-automated processes, the administrator needs to configure the data dictionary for the parameters used by the process based on site requirements.
-   **[[Configuring a Property Conversion|Configuring a Property Conversion]]**  
    A process property conversion is used to maintain the mapping between the process model reference type fields and the conversion service.
-   **[[Unlocking the Process Canvas|Unlocking the Process Canvas]]**  
    Administrators can view and manually unlock locked process page assets.
-   **[[Creating a Batch Handling Form|Creating a Batch Handling Form]]**  
    You can create a batch handling form corresponding to a non-automated process.
-   **[[Registering an Automated Process|Registering an Automated Process]]**  
    Orchestrated automated processes can be registered with the service catalog of the platform.
-   **[[Saving a Non-automated Process as a Process of Multiple Versions|Saving a Non-automated Process as a Process of Multiple Versions]]**  
    You can save an existing non-automated process as a process of multiple versions.
-   **[[Detecting Redundant Fields|Detecting Redundant Fields]]**  
    Redundant field detection is provided for processes. Based on the list of model properties that are not used in the form, you can determine whether to delete historical redundant fields.
