#### Prerequisites

-   You have logged in to the develop-state environment.
-   You have obtained the process configuration permission.

![[notice_3.0-en-us.png]]

In the runtime-state environment, the transfer logs of automated processes can be archived separately. When there are a large number of tickets, especially when there are a large number of phases in an automated process, the amount of log data to be archived is large. To ensure that the archiving speed is consistent with the new data generation speed and the disk usage is stable, the business side needs to plan disks in advance based on the number of tickets and archiving configuration.
