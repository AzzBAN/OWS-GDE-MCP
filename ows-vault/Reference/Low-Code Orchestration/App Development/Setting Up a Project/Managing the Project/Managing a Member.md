#### Procedure

1.  Choose **Project Management**.
2.  On the **Project Management** page, click ![[en-us_image_0000001443517813.png]] in the **Operation** column of the created project.
3.  On the displayed page, click the **Member Management** tab.
4.  Click **Add Member**.
    
    **Figure 1** Adding a member  
    ![[en-us_image_0000001356652053.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Member | Select a user other than the creator. |
    | Role | Set a role for the selected employee.
    -   **Project Developer**: performs orchestration and development only in the project.
    -   **Project Maintainer**: modifies a project and adds, deletes, and changes the personnel who can access the project.
    
     | 5.  Click **OK**.
