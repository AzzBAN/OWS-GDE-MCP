#### Context

When a project is deleted, assets released by the project can be deleted in cascading mode. Asset deletion in cascading mode will delete the project packages and app assets released by the project and stored in the local asset library.

![[caution_3.0-en-us.png]]

After a project is deleted, all data in the project is deleted and cannot be restored. Therefore, exercise caution when deleting a project.
