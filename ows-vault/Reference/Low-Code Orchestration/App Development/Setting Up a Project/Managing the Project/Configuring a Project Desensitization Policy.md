#### Context

Project desensitization policy functions as an app-level desensitization policy and is used to desensitize sensitive data when logs are recorded during app running, to prevent the exposure of sensitive data.

After a project desensitization policy is configured, you can enable the log desensitization function and reference the configured policy during model, service, and function service configuration.
