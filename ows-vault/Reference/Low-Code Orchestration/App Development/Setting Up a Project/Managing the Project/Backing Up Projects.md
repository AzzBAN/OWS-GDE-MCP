#### Context

During app orchestration, developers usually need to back up projects to avoid data loss.

On the **Project Management** page, you can back up all non-read-only projects of the current tenant as project packages in one-click mode.

Only users with the **Develop Asset Management** permission can back up projects. By default, only the administrator has this permission.
