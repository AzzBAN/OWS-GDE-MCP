#### Prerequisites

-   You have logged in to the develop-state environment and created RPA-related projects and modules based on site requirements. For details, see [[Setting Up a Project|Setting Up a Project]].
-   A plugin package has been recorded using RPA Studio and compressed into a ZIP package whose size is less than 200 MB. For details, see [[RPA Development Guide|RPA Development Guide]].
