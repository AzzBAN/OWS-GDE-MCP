# Development of a Hyper-Automation Process for RPA

A hyper-automation process is a super process that integrates various digital capabilities such as RPA, AI, and low-code capabilities. This section describes how to orchestrate and develop a hyper-automation process for RPA through a typical process instance.

-   **[[Service Scenario Description|Service Scenario Description]]**  
    Analyze the requirements of a typical service scenario of the hyper-automation process to prepare for the subsequent development.
-   **[[Development Steps of a Hyper-Automation Process|Development Steps of a Hyper-Automation Process]]**  
    This section describes the steps for developing a hyper-automation process.
-   **[[Creating a Project for the Hyper-Automation Process|Creating a Project for the Hyper-Automation Process]]**  
    Before orchestrating a hyper-automation process, you need to create and configure a project for the process to facilitate subsequent project packaging and deployment.
-   **[[Uploading Robot Scripts of the Hyper-Automation Process|Uploading Robot Scripts of the Hyper-Automation Process]]**  
    After a project is created, you need to import the developed weather information collection robot scripts to the system for orchestration of the hyper-automation process.
-   **[[Orchestrating the Hyper-Automation Process|Orchestrating the Hyper-Automation Process]]**  
    Create a hyper-automation process, and orchestrate and develop process nodes based on the service scenario description.
-   **[[Debugging the Hyper-Automation Process|Debugging the Hyper-Automation Process]]**  
    After the hyper-automation process is orchestrated, you can debug the hyper-automation process to verify service functions.
-   **[[Configuring Permissions of the Hyper-Automation Process|Configuring Permissions of the Hyper-Automation Process]]**  
    After a hyper-automation process is verified, you need to configure permissions for the process to ensure that users in the runtime-state environment can use the functions.
