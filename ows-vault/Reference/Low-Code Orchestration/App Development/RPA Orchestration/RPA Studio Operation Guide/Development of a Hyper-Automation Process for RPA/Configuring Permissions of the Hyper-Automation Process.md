#### Context

[Table 1](#EN-US_TOPIC_0000001649137929__table057184715127) lists the roles corresponding to the hyper-automation process.

**Table 1** Roles corresponding to the hyper-automation process  
| Role Name | Description |
| :-- | :-- |
| HyperautoAdmin | Administrator of the hyper-automation service, who has the hyper-automation service management and hyper-automation service app permissions in the runtime-state environment and can release and run the hyper-automation service. |
| HyperautoUser | User of the hyper-automation service, who has the hyper-automation service app permission in the runtime-state environment and can only run the hyper-automation service. |
