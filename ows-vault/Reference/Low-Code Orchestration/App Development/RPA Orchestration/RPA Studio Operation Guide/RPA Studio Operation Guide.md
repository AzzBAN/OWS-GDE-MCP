# RPA Studio Operation Guide

This section describes how to manage robot scripts and plugins on the develop-state page of the GDE data zone.

-   **[[About RPA Studio|About RPA Studio]]**  
    This section describes the background and functions of RPA Studio.
-   **[[RPA Script Package Management|RPA Script Package Management]]**  
    An RPA script package is a single robot created by a user to complete a specified job. On the page for managing RPA script packages, you can upload, download, view, and delete a single robot.
-   **[[Managing RPA Plugin Packages|Managing RPA Plugin Packages]]**  
    The RPA plugin package is a third-party software package required for script execution. This section describes how to upload, download, view, and delete a plugin package.
-   **[[Development of a Hyper-Automation Process for RPA|Development of a Hyper-Automation Process for RPA]]**  
    A hyper-automation process is a super process that integrates various digital capabilities such as RPA, AI, and low-code capabilities. This section describes how to orchestrate and develop a hyper-automation process for RPA through a typical process instance.
