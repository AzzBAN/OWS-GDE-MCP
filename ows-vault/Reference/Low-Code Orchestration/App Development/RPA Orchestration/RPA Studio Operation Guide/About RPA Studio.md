#### Background

Robotic Process Automation (RPA) is the software that automates the working process by simulating the interaction between humans and computers. It reduces the repetitive work of engineers and makes engineers focus more on creative work. Complex single-robot tasks bring challenges and higher error probability during recording and playback.

RPA Studio is a develop-state module of RPA Orchestrator and manages the RPA script and plugin packages. You can release the script and plugin packages to RPA Orchestrator in the runtime-state environment in one-click mode using a project. In this way, you can deliver script packages to the specified executor for unified management.
