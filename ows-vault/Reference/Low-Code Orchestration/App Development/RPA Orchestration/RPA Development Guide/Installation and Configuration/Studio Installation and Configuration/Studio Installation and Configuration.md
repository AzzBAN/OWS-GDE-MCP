# Studio Installation and Configuration

Before using Studio to develop a robotic process, you need to install Studio and complete related configuration.

-   **[[Installing Studio|Installing Studio]]**  
    Before using Studio to develop robotic processes, you need to install Studio.
-   **[[Configuring Studio|Configuring Studio]]**  
    After Studio is installed, you need to complete related configurations before using Studio functions.
-   **[[Managing RPA Certificates|Managing RPA Certificates]]**  
    After Studio is installed, use the certificate management function to enhance the security of data exchanges between Studio and the server, preventing user personal information from being maliciously attacked or illegally obtained.
-   **[[Making Studio Interwork with RPA Orchestrator|Making Studio Interwork with RPA Orchestrator]]**  
    In Studio, you can import or set the connection information of RPA Orchestrator to connect Studio to RPA Orchestrator.
-   **[[Making Studio Interwork with GDE Store|Making Studio Interwork with GDE Store]]**  
    You can configure the parameters for making GDE Store interwork with Studio. After Studio is successfully interworked with GDE Store, you can view or download extensions from GDE Store on the **Extension Management** page of Studio.
-   **[[Making Studio Interwork with ADC Studio|Making Studio Interwork with ADC Studio]]**  
    You can set the connection information about ADC Studio on Studio to make Studio interwork with ADC Studio. After ADC Studio is successfully interworked, you can release the developed RPA business process to GDE Store on the **Design** page of Studio.
-   **[[(Optional) Switching the Orchestration Mode|(Optional) Switching the Orchestration Mode]]**  
    You can switch the Studio orchestration mode based on site requirements.
-   **[[(Optional) Managing Extension Packages|(Optional) Managing Extension Packages]]**  
    In the Studio orchestration mode, you can view the installed official and third-party extension packages and customize the local extension packages.
