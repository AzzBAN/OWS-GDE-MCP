#### Prerequisites

-   Application Development Center (ADC), server of RPA Orchestrator, has been installed and deployed. For details, see topic "Installation" in GDE x.x.x Product Documentation.
-   You have created a user or machine-machine user on ADC for logging in to RPA Orchestrator. For details, see **Data Zone Configuration** > **Data Zone Configuration (default Tenant)** > **Identity Authentication Management** > **User and Role Permission Management** > **Configuring Machine-Machine User Authentication** in _GDE x.x.x Product Documentation_.
