#### Prerequisites

-   The orchestration mode has been set to **Studio**.
-   (Optional) To install the extension package of RPA Orchestrator, the following conditions must be met:
    -   Studio has been connected to RPA Orchestrator and switched to **Online**. For details, see [[Making Studio Interwork with RPA Orchestrator|Making Studio Interwork with RPA Orchestrator]].
    -   The extension package has been uploaded on the **Products and Services** > **RPA Orchestrator** > **Robots Asset** > **Plugin Management** page of RPA Orchestrator.
-   (Optional) To install the GDE Store extension package, either of the following conditions must be met:
    -   Studio has been connected to GDE Store and switched to **Online**. For details, see [[Making Studio Interwork with GDE Store|Making Studio Interwork with GDE Store]].
    -   Studio is not connected to GDE Store, but is successfully connected to RPA Orchestrator and is in the **Online** state. In addition, the GDE Store configuration already exists on the **Products and Services** > **Administration** > **GDE Store Configuration** page of RPA Orchestrator.
