#### Prerequisites

-   The server certificate file and CRL have been obtained and compressed into a .zip package. For details about how to obtain digital certificates on the web server, see [[How Do I Obtain the Service Certificate and CRL-|How Do I Obtain the Service Certificate and CRL?]]
