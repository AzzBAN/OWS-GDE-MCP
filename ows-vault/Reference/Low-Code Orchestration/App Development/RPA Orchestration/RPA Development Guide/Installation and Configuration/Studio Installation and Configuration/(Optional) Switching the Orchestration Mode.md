#### Context

Studio supports the following two orchestration modes:

-   Studio: designed for professional developers who are experienced in programming and can also use low-code tools to leverage all design capabilities of Studio. After Studio is installed, the Studio mode is used by default.
-   StudioE: designed for citizen developers to skip the error-prone manual programming. Its drag-and-drop mode reduces the coding workload but its development capability is weaker than that of Studio. Moreover, scripts developed in Studio cannot run in StudioE.
