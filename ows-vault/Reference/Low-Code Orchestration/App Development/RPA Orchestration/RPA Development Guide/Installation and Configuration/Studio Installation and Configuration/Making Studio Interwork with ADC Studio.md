#### Prerequisites

-   ADC Studio has been installed and deployed. For details, see topic "Installation" in _GDE x.x.x Product Documentation_.
-   GDE Store has been configured on the runtime-state page corresponding to ADC Studio. For details, see [GDE Store Configuration](../nottoctopics/en-us_topic_0000001259387502.html).
-   You have created a machine-machine account for connecting to ADC Studio. **Authentication Type** of the machine-machine account must be **AK/SK** and the account must be associated with the machine-machine role **adc\_integration**. For details, see [Configuring Machine-Machine User Authentication and Authorization](../nottoctopics/en-us_topic_0000001527308705.html).
