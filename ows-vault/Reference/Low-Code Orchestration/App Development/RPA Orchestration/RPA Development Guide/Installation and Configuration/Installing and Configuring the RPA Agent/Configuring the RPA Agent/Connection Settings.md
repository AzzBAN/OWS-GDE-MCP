#### Prerequisites

-   You have obtained the machine-machine account or login user account of GDE data zone.
    -   Machine-machine account: Access the GDE data zone page, choose **Administration** > **Identity Authentication** > **Machine-Machine User Management** to create a machine-machine account and record its password. The authentication type of the machine-machine account must be **basic**, and the bound human-machine user must be an existing RPA user. Otherwise, the created machine-machine account cannot be used to connect the agent to the management center.
    -   User account: user account (except the W3 account) and password for logging in to the GDE data zone.
-   You have checked that the agent is in the **Offline** state. Otherwise, the connection cannot be set.
