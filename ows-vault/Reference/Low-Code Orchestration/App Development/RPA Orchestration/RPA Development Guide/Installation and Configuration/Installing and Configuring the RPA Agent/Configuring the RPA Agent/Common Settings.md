#### Procedure

1.  Log in to the home page of the agent, click ![[en-us_image_0000002299227310.png]] in the upper right corner, and choose **Settings**.
2.  In the navigation pane, choose **Common Settings**.
3.  Modify the basic settings of the RPA agent based on site requirements.
    
    **Figure 1** Common Settings
    
    ![[en-us_image_0000001622328213.png]]
    
    **Table 1** Parameters on the Common Settings page  
    | Parameter | Description |
    | :-- | :-- |
    | Agent Version | Agent software version |
    | PC ESN | ESN of the PC where the agent software is installed, which is used to apply for a license |
    | VC Running Library | Whether the VC running library is installed
    -   Installed
    -   Not installed
    
     |
    | Select Language | Language used by the agent software
    
    -   Simplified Chinese
    -   English
    
     |
    | Open Log When running | Whether to record logs when the agent software is running
    
    -   Yes
    -   No
    
     |
    | Clean Environment After Execution | Whether to clear the data generated during the running of the agent software after the agent software is started
    
    -   Yes
    -   No
    
     |
    | Start When System Boot | Whether to start the agent software when the PC is started
    
    -   Yes
    -   No
    
     |
    | When closing the main window | Status of the agent software after the main window is closed
    
    -   Close
    -   Minimize
    
    You can also set prompt box appears to determine whether to receive a prompt message after the main window is closed. |
    | Script Scan Path | Path of the agent software scanning script Click Browse, and then select the path of the script to be scanned by the agent software. |
    | Recorded File Save Path | Path where the agent software stores screen recording files Click Browse, and then select the path for storing the screen recording files of the agent software. |
    | Task Logs | Size of the log file generated when the agent software is executed You can click Open or Clean to view log files or delete unnecessary log files based on site requirements. |
    | Python Third-Party Cache | Size of the third-party cache file generated when the agent software is executed You can click Open or Clean to view third-party cache files or delete unnecessary third-party cache files based on site requirements. |
    | Screen Record | Size of the screen recording file generated when the agent software is executed You can click Open or Clean to view screen recording files or delete unnecessary screen recording files based on site requirements. |
    | Script Backup | Size of the script backup file that is automatically downloaded or manually delivered when the agent software is in Online state You can click Open or Clear to view script backup files or delete unnecessary script backup files based on site requirements. The deletion does not affect the execution of subsequent tasks. |
    | Max Screen Record Number | Maximum number of screen recording files generated when the agent software is executed. The value ranges from 1 to 100. |
