# Configuring the RPA Agent

This section uses GDE IPA Assistant as an example to describe how to configure the RPA agent software.

-   **[[Common Settings|Common Settings]]**  
    Before you use the agent, configure the basic information about the agent, including the language, script scanning path, and license.
-   **[[Connection Settings|Connection Settings]]**  
    Before using the agent, set the parameters for connecting the agent and management center, for example, the management center address, executor or connector ID, and machine-machine account and password.
-   **[[License Application|License Application]]**  
    Before using an agent, you need to apply for the license of the agent, and then import the license file to the agent software.
-   **[[Certificate Management|Certificate Management]]**  
    Before using the agent, import the SSL certificate for establishing a secure connection between the agent and the management center.
-   **[[Configuring a Credential|Configuring a Credential]]**  
    A Picture in Picture (PiP) credential password frees users from repeatedly entering the credential password when running a script job in PiP mode.
-   **[[Tool Management|Tool Management]]**  
    Before using the agent, you need to install the corresponding extension program and web driver for the used browser.
