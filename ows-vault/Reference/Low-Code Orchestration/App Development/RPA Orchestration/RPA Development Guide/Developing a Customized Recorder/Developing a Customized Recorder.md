# Developing a Customized Recorder

Studio allows you to customize a recorder for a specified application based on service requirements.

-   **[[Preparing for the Development|Preparing for the Development]]**  
    Before you develop a customized recorder, obtain the required third-party components of the WebSocket client and establish the communication between the customized recorder and Studio.
-   **[[Configuring a Customized Recorder|Configuring a Customized Recorder]]**  
    Before you develop a customized recorder API, configure the information about the customized recorder in a specified file.
-   **[[Developing a Customized Recorder API|Developing a Customized Recorder API]]**  
    After you configure a customized recorder, develop the recording and pickup APIs based on service requirements.
-   **[[Developing a Playback Plugin for the Customized Recorder|Developing a Playback Plugin for the Customized Recorder]]**  
    After the customized recorder API is developed, develop the corresponding playback plugin based on service requirements.
