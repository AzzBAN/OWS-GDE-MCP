#### Prerequisites

You have obtained the required third-party components of the WebSocket client based on the language for developing the customized recorder.

**Table 1** Third-party components of the WebSocket client   
| Language for Developing a Customized Recorder | Third-Party Component of the WebSocket Client | Version |
| :-- | :-- | :-- |
| Java | Java-WebSocket | 1.5.1 or later |
| Python | websocket-client | 0.58.0 or later |
| C++ | websocketpp | 0.8.2 or later |
| JavaScript | Native HTML5 | Not restricted |
