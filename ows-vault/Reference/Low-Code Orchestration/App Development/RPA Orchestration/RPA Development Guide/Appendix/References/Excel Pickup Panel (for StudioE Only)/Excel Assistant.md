#### Description

The Excel assistant on the Excel pickup panel is used to perform operations on cells or areas in a specified Excel file. Five types of operations are preset in the system: Select, Text, Number, Date, and File. If other customized names exist in the name manager of the specified Excel file, StudioE will also load them to the Excel assistant for users.

![[en-us_image_0000001175447206.png]]

The functions of each operation type are as follows:

-   Select: Select a specified cell, area, or sheet in an Excel file.
-   Text: Perform operations on cells of an Excel file such as finding, replacing, and inputting the cell content and shifting between uppercase and lowercase.
-   Number: Perform operations such as retaining decimals, entering values, and rounding values in cells or cells of an Excel file
-   Date: Calculate the working day, obtain the current date, format the date, and enter the date in cells of an Excel file.
-   File: Perform operations on cells of an Excel file such as inputting a file path and obtaining a file name.
