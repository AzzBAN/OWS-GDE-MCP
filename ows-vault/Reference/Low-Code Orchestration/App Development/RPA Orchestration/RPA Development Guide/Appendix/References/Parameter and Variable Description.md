#### Definition

-   Parameter: Data transferred from external systems, which cannot be modified. Parameters include global parameters and local parameters. Global parameters can be used in any script but local parameters can be used only in specified scripts.
-   Variable: Variable data defined in the system, which can be changed as required. Variables include global variables and local variables (variables) based on their scopes. Global variables can be used in any script but local variables can be used only in specified scripts.
