#### Definition

**InputJson** is abnormal. The possible causes are as follows:

-   The robot fails to read the JSON file of the input variable.
-   The robot fails to read the JSON file by running the **readjson** command.
-   The robot fails to read the JSON file of the image recognized by the offline OCR.
