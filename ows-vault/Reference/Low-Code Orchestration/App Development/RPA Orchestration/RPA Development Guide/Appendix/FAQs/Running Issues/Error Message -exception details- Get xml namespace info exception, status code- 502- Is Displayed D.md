#### Symptom

The script fails to be executed. In the **Log** area in the lower part of the canvas, the error message "\[Detail\] \[NOK\]\[2021-11-05 13:10:38\]playbackScript.xml line:4 console.login \[Login server\] \[NOK\] (RobotError) exception details: Get xml namespace info exception, status code: 502" is displayed.
