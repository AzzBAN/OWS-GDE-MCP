#### Symptom

The **Invoke C#** control in the script fails to be called and the system displays the message "XXX has stopped working."

![[en-us_image_0000001217683566.png]]

Close the dialog box, open the executor client, click ![[en-us_image_0000001262524989.png]] in the upper right corner, and select **Log** to view the execution logs. The message "System execution error: Uncaptured exception occurred" is displayed in the log.
