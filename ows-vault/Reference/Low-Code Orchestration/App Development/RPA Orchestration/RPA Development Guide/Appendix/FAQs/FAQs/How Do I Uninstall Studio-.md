#### Procedure

1.  Choose **Control Panel** > **Programs** > **Remove Programs**. Right-click **GDE IPA Studio** _x.x.x_ and choose **Uninstall** from the shortcut menu.
2.  In the displayed dialog box, click **Next**.
3.  Select the cache and settings to be deleted based on site requirements.
    
    ![[en-us_image_0000002500850372.png]]
    
4.  Click **Uninstall**.
