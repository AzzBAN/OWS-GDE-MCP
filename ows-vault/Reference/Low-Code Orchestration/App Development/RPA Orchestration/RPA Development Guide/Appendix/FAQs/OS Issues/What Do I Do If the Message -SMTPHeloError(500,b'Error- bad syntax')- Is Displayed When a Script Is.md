#### Symptom

In Windows 10, when Studio is used to run a script and the **Send email(smtp)** control is used to send emails to the 163 mail box, the message "SMTPHeloError(500,b'Error: bad syntax')" is displayed on the **Log** tab page at the bottom of the canvas.
