# FAQs

This section describes common issues that may occur during the Studio usage and solutions.

-   **[[How Do I Search For the Required Content in a Project-|How Do I Search For the Required Content in a Project?]]**  
    Searching in a project helps you quickly locate the required content.
-   **[[How Do I Uninstall Studio-|How Do I Uninstall Studio?]]**  
    If you do not need to use Studio, you can uninstall it.
-   **[[How Do I Use the Automation-Related Controls of Machine Vision-|How Do I Use the Automation-Related Controls of Machine Vision?]]**  
    Machine vision–based automation control helps you use AI-related interfaces to operate windows or identify image on enterprise WeChat and DingTalk.
-   **[[How Do I Obtain the Service Certificate and CRL-|How Do I Obtain the Service Certificate and CRL?]]**  
    The digital certificate and CRL of the server can be exported using a browser for being used by Studio.
-   **[[How Do I Delete Service Certificates Imported into Studio-|How Do I Delete Service Certificates Imported into Studio?]]**  
    When a service certificate is invalid or is no longer used, the service certificate file that has been imported to Studio can be deleted.
-   **[[What Do I Do If the Screen Is Locked Because No Operation Is Performed for a Long Time During Script|What Do I Do If the Screen Is Locked Because No Operation Is Performed for a Long Time During Script Execution?]]**  
    When the script is executed by an executor, if no operation is performed for a long time, the PC screen is locked, affecting the subsequent script execution. In this case, you can use the **Run python Expression** control to solve the issue.
-   **[[How Do I Change Port Configurations of Studio and Assistant-|How Do I Change Port Configurations of Studio and Assistant?]]**  
    You can modify the port configurations of Studio and Assistant based on site requirements, preventing faults caused because the port is occupied.
