#### Symptom

On the **Settings** > **License** page of Studio, after you click **Remove** to delete the imported license, any of the following symptoms occurs in Studio:

-   The license fails to be removed and the message "Failed to remove the local independent license because of insufficient permissions. Start the license as an administrator and try again." is displayed on Studio.
-   The license is successfully removed but it still can be viewed on Studio.
