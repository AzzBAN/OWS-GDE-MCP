#### Symptom

Running a script takes a long time. When you click **Detail** in the **Log** area at the bottom of the canvas to view run logs, the error message "\[WARNING\] - com.huawei.antrobot.utils.communication.communication(is\_available\_service:75) - test service: password\*\*\*\*\*\*ception" is displayed.
