#### Procedure

1.  Start Studio.
2.  In the navigation pane, click ![[en-us_image_0000001178827428.png]].
3.  In the **Recently Edited Items** area, click the project name to go to the project design page.
4.  Choose **Advance** > **Find in Project** or press **Ctrl+Shift+F**.
5.  Enter a keyword in the displayed search box.
    
    ![[en-us_image_0000001178508674.png]]
    
6.  In the search results, click the required content to go to its location based on site requirements.
    
    -   If the current page is in the **Canvas** mode, double-click the search result to go to the location of the required content. If you click the search result, the page will be displayed in the **Xml Code** mode, and the required content is located by the cursor.
    -   If the current page is in the **Xml Code** mode, double-click the search result to go to the location of the required content, and use the cursor to locate the content. If you click the search result, the page will be displayed in the **Canvas** mode, and the corresponding control is located.
    
    ![[notice_3.0-en-us.png]]
    
    The historical search result is recorded by Studio only after the keyword is searched for and keyword is located by pressing **Enter** or clicking or double-clicking the search result. When there are a large number of historical search records, click **Clear historical search records**.
