#### Symptom

-   When a Java application opened by Internet Explorer is recorded in Studio, the related elements cannot be picked up.
-   When the Java application script is executed in Studio, in the **Log** area in the lower part of the canvas, the message "Check whether the target is correct or the jabswitch status is enable." is displayed.
