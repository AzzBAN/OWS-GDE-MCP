#### Symptom

When you execute the script that uses the **Run Macro** control to run a macro in an Excel file, the macro fails to be executed. In the **Log** area at the bottom of the canvas, an error message is displayed, indicating that the running of the _XX_ macro fails. The possible cause is that the macro is unavailable in the workbook or all macros are disabled.
