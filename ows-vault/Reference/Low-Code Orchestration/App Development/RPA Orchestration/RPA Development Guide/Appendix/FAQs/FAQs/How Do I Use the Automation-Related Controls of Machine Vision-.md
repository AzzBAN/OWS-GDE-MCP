#### Context

-   When the machine vision–based automation control is used, other controls can be used only after the **Set CV Target Window** control is used.
-   The recommended AI interfaces are as follows:
    -   URL of the recommended AI interface for enterprise WeChat: https://apigw-02.huawei.com/api/v1/ui-element/detect/wechat
    -   URL of the recommended AI interface for DingTalk: https://apigw-02.huawei.com/api/v1/ui-element/detect/dingding
