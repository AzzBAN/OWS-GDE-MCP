#### Symptom

-   When a web application opened by Google Chrome is recorded in Studio, the related elements cannot be picked up, and a message is displayed, indicating that the connection to the browser is interrupted and asking you to go to **chrome://extensions/** to check whether the browser plugin is correctly installed or enabled.
-   Google Chrome scripts fail to be executed in Studio. The log area under the canvas displays the "\[Detail\] \[NOK\]\[2021-12-03 15:19:44\]Complete the execution of \[atomic command\] \[playbackScript.xml Line 239\] Click a Web Page Element \[Click Web Element\] \[NOK\] \[RobotWebPluginError\] \[System execution error: Web plug-in control execution timed out. The playback plug-in is not started or not installed\] error message."
