#### Procedure

1.  Go to the **AppData\\Local\\HuaweiRPA\\certs** directory in the user directory, for example, **C:\\Users\\test\\AppData\\Local\\HuaweiRPA\\certs**.
2.  Delete the unnecessary service certificate from the directory.
