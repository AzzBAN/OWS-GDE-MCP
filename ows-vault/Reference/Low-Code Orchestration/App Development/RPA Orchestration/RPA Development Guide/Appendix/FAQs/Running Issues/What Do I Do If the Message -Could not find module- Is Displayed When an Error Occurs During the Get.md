#### Symptom

The **Get Data in QR Code** control in the script fails to be executed. In the **Log** area in the lower part of the canvas, the message "\[NOK\] (RobotFileNotFoundError) exception details: line:11 Could not find module '%Studio\\Robot\\components\\libzbar-64.dll' (or one of its dependencies). Try using the full path with constructor syntax" is displayed.
