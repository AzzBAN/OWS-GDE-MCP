# Manually Developing a Customized Plugin

This topic describes how to manually develop a customized plugin.

-   **[[Preparing for the Development|Preparing for the Development]]**  
    Before you develop a customized plugin, download the required plugin template file and set the corresponding Python development environment.
-   **[[Developing and Packaging Customized Plugins|Developing and Packaging Customized Plugins]]**  
    When you develop customized plugin, develop files such as **help.json**, **register.json**, and **action\_ext.py** based on site requirements. After the development is complete, package the customized plugin project file.
-   **[[Importing and Using a Customized Plugin|Importing and Using a Customized Plugin]]**  
    After a customized plugin is packaged, import the customized plugin project file to Studio for use.
