# Set the OCR operation window

**SetOnlineOcrWindow**

**Description:**

Setting the Online OCR Operation Window

1\. Prerequisites for use: use this control when there is a network;

2\. When the OCR engine is Huawei Manas, obtain the application user-id and user-key method: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course;" Chapter 10.1 Unit;

3\. When the OCR engine is Baidu, please refer to the webpage for the method of obtaining the API Key and Secret Key: https://cloud.baidu.com/doc/Reference/s/9jwvz2egb, corresponding to the parameters user-id and user-key.

4\. When the OCR engine is Huawei Cloud, the Huawei Cloud Account Name and Huawei Cloud IAM User Name correspond to the Account Name and IAM User Name.

Note: The smart form function added in version 3.2.0 has been moved to the \`Online OCR Auto Form\` control. Originally, the form function of this control cannot be edited, but the execution will not be affected.

**Input: none**
