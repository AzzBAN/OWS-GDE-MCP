# Set CV Target Window

**CV.setWindow**

**Description:**

Set the CV target window, and other CV controls operate based on this window. Note: The use of reference type values for the parameters of this control only supports explicit declarations in variables or parameters, and does not support variables that are referenced in context or nested.

1\. Enterprise WeChat recommended AI interface address: https://apigw-02.huawei.com/api/v1/ui-element/detect/wechat.

2\. Dingding recommended AI interface address: https://apigw-02.huawei.com/api/v1/ui-element/detect/dingding.

3\. Method to obtain application user\_id and user-key: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course.

**Input: none**
