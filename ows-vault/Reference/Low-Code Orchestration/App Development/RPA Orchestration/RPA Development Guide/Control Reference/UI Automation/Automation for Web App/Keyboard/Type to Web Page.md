# Type to Web Page

**type**

**Description:**

Enter text, optionally empty and then enter.

1\. The character length of the text is limited by the maxlength property of the edit box;

2\. When using this control to upload files, you need to open the option to allow access to file URLs in the extension, and the iframe cross-domain scenario is not supported.

**Input: none**
