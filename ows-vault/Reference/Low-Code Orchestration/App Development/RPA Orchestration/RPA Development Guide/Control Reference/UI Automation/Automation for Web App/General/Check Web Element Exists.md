# Check Web Element Exists

**hasElement**

**Description:**

Check whether the element exists on the current web page. (Note: The element may not be visible to users.) When the element does not exist, it will be retried within the timeout period until the element exists (the check result is True) or the execution times out (the check result is False).

**Input: none**
