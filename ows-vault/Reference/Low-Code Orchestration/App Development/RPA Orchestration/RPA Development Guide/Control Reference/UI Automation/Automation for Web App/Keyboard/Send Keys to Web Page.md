# Send Keys to Web Page

**sendKeys**

**Description:**

To use this command, the user needs to install the pyautogui third-party software by themselves\\nInstallation steps:\\n1. Enter the root directory of WeAutomate-Studio or weautomate-assistant installation;\\n2. Execute the command in the path to install: python/bin/python3 -m pip install pyautogui -i Mirror source.

send keys to web page, for the writing of each function key, please refer to the help document 1.1.4.4 function key.Due to the system Secure Attention Key (SAK), some function key combinations are not supported, such as: CTRL+ALT+DELETE, CTRL+SHIFT+DELETE and other combinations.

**Input: none**
