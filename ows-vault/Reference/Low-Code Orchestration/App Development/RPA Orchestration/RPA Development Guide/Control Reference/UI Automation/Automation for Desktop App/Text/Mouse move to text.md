# Mouse move to text

**getWordMove**

**Description:**

Pick a target area and move mouse to the target text in the area.

Tips:

1\. If a timeout exception occurs, try setting a larger timeout number.

2\. If the target text is not found, check the print.log file in the project document. If the print result is ### None data ###, which means the current control does not support text detect.

**Input: none**
