# Open Web Page

**openurl**

**Description:**

Open a web page;

IE browser search rules for opened pages: match from back to front, match priority: 1. Address and title all match 2. Address all match 3. Title all match 4. Index match window (only use index match, delete other match methods) 5. Element match window (only use element match, delete other match methods) 6. Addresses with \* wildcard fuzzy matching 7. Title with \* wildcard fuzzy matching 8. Not found;

Other browser search rules for opened pages: match from back to front, match priority: 1. Address and title all match 2. Address all match 3. Title all match 4. Address and title contain 5. Address contain 6. Title contain 7. Addresses with \* wildcard fuzzy matching 8. Title with \* wildcard fuzzy matching 9. Not found

**Input: none**
