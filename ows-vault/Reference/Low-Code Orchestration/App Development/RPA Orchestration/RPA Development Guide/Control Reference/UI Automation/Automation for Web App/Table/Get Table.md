# Get Table

**getTable**

**Description:**

Get the table information on the page and output the information; When obtaining multi-page table data, if the obtained data is incomplete, it may be due to network reasons that the element has not been loaded. Please set the next-page-delay parameter to wait for the element to be loaded according to the network situation

**Input: none**
