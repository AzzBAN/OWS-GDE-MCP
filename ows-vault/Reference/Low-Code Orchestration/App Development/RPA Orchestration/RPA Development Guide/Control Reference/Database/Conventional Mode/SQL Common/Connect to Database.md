# Connect to Database

**database.connect**

**Description:**

Connect to the database and return the connection instance. Currently supports mysql, mariadb, oracle, postgresql, mongodb. Windows to connect to the Oracle database requires additional download of the instantclient dependency package (link: https://oracle.github.io/odpi/doc/installation.html#windows), decompress it, add it to the computer's environment variables, and configure the corresponding Visual C++ environment. The current command may operate the production environment data, resulting in data changes, please use it with caution. Linux connection: Oracle Instant Client installation please refer to: https://python-oracledb.readthedocs.io/en/latest/user\_guide/installation.html#oracle-instant-client-zip-files.

**Input: none**
