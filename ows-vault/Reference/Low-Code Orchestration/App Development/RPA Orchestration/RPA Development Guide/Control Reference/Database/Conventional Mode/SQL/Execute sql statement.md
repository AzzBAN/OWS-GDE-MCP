# Execute sql statement

**database.execute**

**Description:**

Execute a SQL statement against a relational database. If you execute a query and return all query results, you can execute multiple SQL statements separated by semicolons.postgresql database SQL statements can only use single quotes, Oracle SQL statements can not end with a semicolon
