# Compare Text Similarity

**textSimilarityNLP**

**Description:**

For the input source sentence and a set of target sentences (the input text and the target sentence contain special characters, SQL injection may be recognized), the ability to calculate the similarity of the two sets of input texts is provided. This control integrates the Huawei Manas service to obtain application user\_id and User-key method: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course.

**Input: none**
