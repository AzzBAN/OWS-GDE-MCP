# Table Recognition

**getTableInfoOcr**

**Description:**

OCR online recognition form, return the data information in the picture:

Support to identify the cell content of a regular table with complete table lines (current table only supports complete tables with obvious horizontal and vertical lines, that is, the scene of inserting tables in the document, does not support scenes such as missing or bent table lines, does not support excel tables, does not support table embedding Set), structured output of the text content of each cell;

How to obtain user-id and user-key: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course.

**Input: none**
