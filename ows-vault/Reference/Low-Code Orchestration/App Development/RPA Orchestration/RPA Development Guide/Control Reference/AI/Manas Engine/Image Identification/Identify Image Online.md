# Identify Image Online

**getpicinfo\_online**

**Description:**

OCR recognizes the picture online and returns the data information in the picture:

1\. Usage guide: use online recognition when there is a network (warm reminder: based on the current data model, the image recognition result cannot be guaranteed to be 100% accurate);

2\. Usage scenario: Mainly identify button screenshots of webpages and apps;

3\. OCR online recognition currently has two data models, noah-scene and noah-doc, which can be selected for use. For details, see the help of parameter ocr-mode;

4\. Method to obtain application user\_id and user-key: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, view Chapter 3, Section 3.2 of the course.

**Input: none**
