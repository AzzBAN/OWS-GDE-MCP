# Extract keywords

**textKeyWordsNLP**

**Description:**

For the input text (the input text contains special characters, SQL injection may be recognized), the keyword extraction capability of the text is provided. This control integrates the Huawei Manas service to obtain the application user\_id and user-key method: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course.

**Input: none**
