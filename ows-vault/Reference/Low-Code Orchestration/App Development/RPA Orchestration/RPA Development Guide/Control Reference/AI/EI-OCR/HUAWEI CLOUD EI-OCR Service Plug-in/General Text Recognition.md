# General Text Recognition

**ocrGeneralText**

**Description:**

Recognize the text information on the picture, and return the recognized text and coordinates in json format. Supports text recognition in multiple scenarios such as scanned documents, electronic documents, books, bills, and forms.

**Input: none**
