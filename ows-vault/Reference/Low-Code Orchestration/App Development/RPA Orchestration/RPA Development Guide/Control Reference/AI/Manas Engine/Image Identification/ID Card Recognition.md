# ID Card Recognition

**getIdCardInfoOcr**

**Description:**

OCR recognizes the ID card picture and returns the data information in the picture:

Support for structured identification of all 9 fields on the front and back of the second-generation resident ID card, including name, gender, ethnicity, date of birth, address, ID card number, issuing authority, start date of validity period, and end date of validity period, currently temporarily Does not support identification of ethnic minority ID cards;

The input ID image must be complete and clear in order to improve the recognition accuracy;

How to obtain user-id and user-key: See https://connect.huaweicloud.com/courses/learn/Learning/sp:cloudEdu\_?courseNo=course-v1:HuaweiX+CBUCNXEA006+Self-paced&courseType=1, and see Section 3.2 of Chapter 3 of the course.

**Input: none**
