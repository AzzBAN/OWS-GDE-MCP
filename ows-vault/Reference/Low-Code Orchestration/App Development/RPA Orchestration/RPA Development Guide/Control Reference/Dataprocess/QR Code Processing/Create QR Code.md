# Create QR Code

**toqrcode**

**Description:**

Data generation QR code:

1\. The data is converted to a QR code, which does not have the encryption effect. If the QR code is lost, related information will be disclosed. Therefore, do not use it for private data transmission.

Input parameter:

1\. data, string type, mandatory, string to be converted to a QR code. A maximum of 512 characters can be converted.

2\. is-show, list type, optional, true or false. The default value is false.

3\. position, list type, optional, and image display position. This parameter is optional. The default value is center. This parameter is optional when is-show is set to true.

4\. image-size, number type, optional. Set the size of the image to be displayed. The length and width are the same. If the value is greater than the resolution of the local computer, the screen is adaptive. The value ranges from 300 to 1200.

5\. save-to, new\_file, optional. This parameter is mandatory if the image path is customized. If the relative path is specified, the image is stored in the project directory. By default, images are stored in the Pic folder in the project directory.

Output parameter:

image\_path\_ret: path for storing QR code images.

**Input: none**
