# Concurrent execution

**Parallel**

**Description:**

Used to call subscripts concurrently. The parameters and variables defined in the current script are invisible and cannot be modified in the called script. When a subscript requires the parameters or variables defined in the current script, you need to define parameters of the "in" type in the subscript and transfer the parameters or variables as input parameters in the current script.

**Input: none**
