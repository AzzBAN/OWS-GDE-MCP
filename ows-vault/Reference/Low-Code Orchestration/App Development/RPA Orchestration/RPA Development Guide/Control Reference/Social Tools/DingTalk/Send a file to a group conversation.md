# Send a file to a group conversation

**dingding.send\_file\_to\_conversation**

**Description:**

To send files to a group session, 1. Prerequisites for use: enable interface permissions in the DingTalk developer backend;

2\. Methods to obtain space\_id: 1) The first method can be obtained through the dingding.upload\_file control. The returned result is a dictionary consisting of spaceId and dentry\_id. The acquisition method is: @{upload\_file\_info\_ret\['space\_id'\]}; 2) Secondly, click the link to pin the customer End Cloud Disk -> Select the enterprise to which the application belongs -> Select the uploaded folder -> Click the copy link -> Copy the spaceId value in the link;

3\. Methods to obtain dentry\_id: 1) The first method is to obtain it through the dingding.upload\_file control. The returned result is a dictionary consisting of spaceId and dentry\_id. The acquisition method is: @{upload\_file\_info\_ret\['dentry\_id'\]}; 2) Secondly, click on DingTalk client Dingdisk->Select the company to which the application belongs->Select the uploaded folder->Click to copy the link->Copy the value of fileId in the link;

4\. Method to obtain conversation\_id: 1) Copy CorpId in DingTalk developer backend, link: https://login.dingtalk.com/oauth2/challenge.htm?redirect\_uri=https%3A%2F%2Fopen-dev.dingtalk.com %2Fdingtalk\_sso\_call\_back%3Fcontinue%3Dhttps%253A%252F%252Fopen-dev.dingtalk.com%252F%253Fspm%253Dding\_open\_doc.header.unLogin.openDevBtn&response\_type=code&client\_id=dingbakuoyxavyp5ruxw&scope=openid+corpid#/;

2) Click the link below to go to the API debugging page: https://open-dev.dingtalk.com/apiExplorer?spm=ding\_open\_doc.document.0.0.29b2722f5lvcqC#/jsapi?api=biz.chat.chooseConversationByCorpId, copy the CorpId of the step Paste the CorpId value into the open page and click Send Call;

3) Scan the QR code generated on the page after calling the interface;

4) After successfully scanning the QR code, click on the next page to initiate an appeal;

5) At this time, DingTalk allows you to choose a group conversation;

6) After selecting the session, the openConversationId of the target session will be returned.
