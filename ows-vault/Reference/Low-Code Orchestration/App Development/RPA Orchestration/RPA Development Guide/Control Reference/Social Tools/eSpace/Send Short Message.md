# Send Short Message

**inform.sendSmsHic**

**Description:**

Prerequisites for sending SMS messages based on the Huawei HIC SMS voice service platform:

1\. Apply for the user-id and user-key using the Huawei employee ID;Application link: http://console.hic.huawei.com/sns/#/guide/manual/list;

2.must be connected to the Internet;

3.The server restricts frequent sending. For example, frequent sending may lead to missing sending.

**Input: none**
