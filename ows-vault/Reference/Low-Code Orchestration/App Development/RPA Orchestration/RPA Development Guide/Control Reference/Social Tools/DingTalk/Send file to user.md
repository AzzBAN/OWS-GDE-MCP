# Send file to user

**dingding.send\_file\_to\_user**

**Description:**

Send files to users, 1. Methods to obtain space\_id: 1) The first method can be obtained through the dingding.upload\_file control. The returned result is a dictionary consisting of spaceId and dentry\_id. The acquisition method is: @{upload\_file\_info\_ret\['space\_id'\]}; 2) The second method is to click DingTalk client cloud disk -> select the enterprise to which the application belongs -> select the uploaded folder -> click copy link -> copy the spaceId value in the link;

3\. Methods to obtain dentry\_id: 1) The first method is to obtain it through the dingding.upload\_file control. The returned result is a dictionary consisting of spaceId and dentry\_id. The acquisition method is: @{upload\_file\_info\_ret\['dentry\_id'\]}; 2) The second method is to click Dingding Client nail disk->select the enterprise to which the application belongs->select the uploaded folder->click copy link->copy the value of fileId in the link.
