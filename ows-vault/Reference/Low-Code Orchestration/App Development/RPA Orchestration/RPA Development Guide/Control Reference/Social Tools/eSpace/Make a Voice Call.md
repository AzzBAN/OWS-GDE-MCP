# Make a Voice Call

**inform.voiceCallHic**

**Description:**

Making a Voice Call Based on the Huawei HIC SMS Voice Service Platform. Only calls in China are supported. Prerequisites:

1\. Use Huawei employee ID to apply for the user-id and user-key;Application link: http://console.hic.huawei.com/sns/#/guide/manual/list;

2.must be connected to the Internet.

**Input: none**
