# Set processing progress of item

**queue.set\_data\_progress**

**Description:**

Sets the progress of queue data:

Queues are created in the management center to provide asynchronous communication between clients. Data interaction between different robots can be implemented based on queues.

Search for the queue data to be set based on the UID and set the progress parameter to set the processing progress of the queue data.

**Input: none**
