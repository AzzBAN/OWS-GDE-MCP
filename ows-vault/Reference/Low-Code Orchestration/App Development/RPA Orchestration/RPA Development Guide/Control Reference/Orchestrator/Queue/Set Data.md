# Set Data

**queue.set\_json\_data**

**Description:**

Sets the JSON data of queue data:

Queues are created in the management center to provide asynchronous communication between clients. Data interaction between different robots can be implemented based on queues.

Search for the queue data to be set based on the UID and set the expected time of the queue data by other input parameters.

**Input: none**
