# Query Shared File list

**mc.queryFileList**

**Description:**

query file list from shared files in the management center. The returned file information includes:uid, fileName, fileType, uploadTime, size(the unit is byte), folder. When a variable is referenced, the corresponding data can be obtained from the return value based on the attribute name. For example, the uid of the first file is @{query\_file\_list\_ret\[0\]\["uid"\]}

**Input: none**
