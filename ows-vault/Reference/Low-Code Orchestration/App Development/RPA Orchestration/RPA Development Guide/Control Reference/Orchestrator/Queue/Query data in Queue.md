# Query data in Queue

**queue.query\_data**

**Description:**

Querying Multiple Data Records from a Queue.

Queues are created in the management center to provide asynchronous communication between clients. Data interaction between different robots can be implemented based on queues.

You can set page-no and page-size to query multiple records at a time.

Compared with the queue.consume\_data command, this command can query data in all states without changing the data status.

**Input: none**
