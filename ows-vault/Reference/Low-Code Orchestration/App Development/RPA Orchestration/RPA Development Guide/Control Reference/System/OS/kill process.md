# kill process

**killProcess**

**Description:**

Ends a specified process based on the specified process information. When using title to locate a process, do not open the directory with the same name as the app. Otherwise, the process cannot be stopped. If you want to close the browser by title, you can get the name of window with tools such as inspect.

**Input: none**
