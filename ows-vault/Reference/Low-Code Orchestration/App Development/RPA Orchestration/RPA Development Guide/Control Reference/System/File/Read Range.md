# Read Range

**pdfGetContents**

**Description:**

Obtains the text in the rectangle specified by the pos-upper-left and pos-lower-right parameters on the filter-page page in the PDF file or generates images based on the specified range.

Command

Run this command. Install the third-party software of the pymupdf later.

Installation procedure:

1\. Go to the python directory from the Studio installation directory.

2\. Open a terminal in this folder.

3\. Enter the command in a terminal window: python -m pip install pymupdf to install.The version cannot be earlier than 1.18.14.

Determine the coordinates.

In the PDF file, the upper left corner of the entire page is the origin, and the coordinates are 0 and 0. The lower right corner of the page is the pole, and the coordinate width (page width) and height (page height). The positive axis is the x axis from the origin to the right. The value range of x is 0 ≤ x ≤ width. Positive axis of the y axis starting from the origin. The value range of y is 0 ≤ y ≤ height.

**Input: none**
