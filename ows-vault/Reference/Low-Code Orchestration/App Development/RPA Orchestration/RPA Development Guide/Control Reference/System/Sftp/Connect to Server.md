# Connect to Server

**sftp.connect**

**Description:**

Connect to SFTP/FTP server.

1.Action support connecting SFTP server or FTP server(FTP protocol has security vulnerabilities and is not recommanded.).

2.Action support password login and private key login when connecting to SFTP server.

3.Action support user login and anonymous login when connecting to FTP server. Anonymous login succeed requires the FTP server to open anonymous login config.

4.When connected to Management Center, the remote server ip address is restricted by the Management Center whitelist, the config option is allow\_ip.

**Input: none**
