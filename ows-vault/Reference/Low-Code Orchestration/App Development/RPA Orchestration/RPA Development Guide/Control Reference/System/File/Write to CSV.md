# Write to CSV

**writeCsv**

**Description:**

Writes data to a csv file.

Note:

1.This command is used together with the readPdf command to save the table data read from the PDF to a csv file;

2.Run this command independently, but the table data needs to be constructed, Construct the data format {'table':\[\[\[\], \[\], \[\]\]\]}, for example, {'table':\[\[\['Name','Age'\], \['nana','12'\], \['ming', '13'\]\]\]}

**Input: none**
