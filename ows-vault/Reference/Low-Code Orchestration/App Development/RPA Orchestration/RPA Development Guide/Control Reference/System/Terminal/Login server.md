# Login server

**console.login**

**Description:**

Login to the remote server.

1.Connection protocol includes SSH and Telnet(The Telnet protocol has security vulnerabilities and is not recommanded).

2.SSH protocol connection allows password login and private key login. Telnet protocol connection only allows password login.

3.When connected to Management Center, the remote server ip address is restricted by the Management Center whitelist, the config option is allow\_ip.

4.Only one console connection allowed during the robot running. Use this action multiple will overwrite the previous connection.

5.This action may modify the production environment data, please use it with caution.

**Input: none**
