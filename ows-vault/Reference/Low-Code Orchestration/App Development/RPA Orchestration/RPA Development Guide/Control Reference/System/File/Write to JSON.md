# Write to JSON

**writeJson**

**Description:**

Write the correct JSON file or convert the data whose structure is in JSON format but the quotation marks are incorrect to the correct JSON format and write the data to the file.

Note:

Note: Data with incorrect quotation marks indicates that the key-value pair data is single quotation marks or some of them are single quotation marks. If the quotation marks on the left and right of a key or value are different, the data cannot be converted.

**Input: none**
