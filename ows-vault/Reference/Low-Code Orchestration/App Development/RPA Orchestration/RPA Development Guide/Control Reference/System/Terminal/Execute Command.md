# Execute Command

**console.run**

**Description:**

Run command on the remote host

1.When connected to Management Center, the execute command is restricted by the Management Center Whitelist, the config option is allow\_remote\_cmd.

2.The parameter timeout is 30s default. action get the server's echo continuously during the timeout period. If the end\_prompt is detected at the end of the echo, then return the echo.

3.Under SSH protocol connection, the end\_prompt parameter must input correctly; Telnet protocol connection does not need the end\_prompt parameter.

4.This action must used together with console.login and it executed after console.login.
