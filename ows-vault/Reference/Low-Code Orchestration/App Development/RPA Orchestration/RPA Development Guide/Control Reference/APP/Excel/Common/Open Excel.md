# Open Excel

**excelApplicationScope**

**Description:**

1.Open Excel file

2.If the file does not exist, create and open it

3.Warning:This command involves the operation of opening the Excel or CSV file. The file may contain automatically executed macros (may contain malicious code), which may pose security risks. Ensure that the file source is reliable and run this command with caution

4\. When operating the wps as an administrator, you need to modify the computer security policy: (1). Press Windows + R to open the Run window and type gpedit.msc to open the local group policy editor. (2) Choose Computer Configuration > Windows Settings > Security Settings > Local Policies > Security Options. (3) In Security Options, find "User Account Control: Run All Administrators in Administrator Approval Mode" and disable this security policy.

**Input: none**
