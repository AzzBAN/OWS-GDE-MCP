# Copy sheet

**excelCopySheet**

**Description:**

Copy the specified sheet and paste:

1\. If you need to copy to the same Excel file multiple times, use ExcelApplicationScope to open the target file

Warning:This command involves the operation of opening the Excel or CSV file. The file may contain automatically executed macros (may contain malicious code), which may pose security risks. Ensure that the file source is reliable and run this command with caution.
