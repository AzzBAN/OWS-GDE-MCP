# Get Email(POP)

**pop.getEmail**

**Description:**

1.Obtains emails using the pop protocol. You can filter emails by time, sender, recipient, and subject.(For details, see the usage of each parameter), you can only get the emails in the INBOX, and filtering by folder is not supported.

2.The email body is saved in contents.txt and contents.html. The pictures in the body are saved as attachments.

3.Obtain the email,Get multiple times, the same email will be overwritten.

4\. Please make sure the network is unblocked before getting emails.

**Input: none**
