# Create pivot table

**excelCreatePivotTable**

**Description:**

Read content from a specified range and create a pivot table. Note: Due to compatibility issues between Office and WPS, when using WPS to create a pivot table, you cannot specify the sheet and location to generate a pivot table,WPS generates a separate sheet and generates the pivot table in position A1.
