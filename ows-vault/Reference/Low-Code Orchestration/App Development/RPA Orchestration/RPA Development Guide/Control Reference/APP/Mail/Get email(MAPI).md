# Get email(MAPI)

**mapi.getEmail**

**Description:**

1.Obtain the email,the permission to start the Studio is the same as that of the Outlook (administrator or common user)

2.You can filter emails by time, sender, recipient, and subject.(For details, see the usage of each parameter.)

3.The email body is saved in contents.txt and contents.html. The pictures in the body are saved as attachments.

4.Obtain the email,Get multiple times, the same email will be overwritten.

5\. Please make sure the network is unblocked before getting emails.

**Input: none**
