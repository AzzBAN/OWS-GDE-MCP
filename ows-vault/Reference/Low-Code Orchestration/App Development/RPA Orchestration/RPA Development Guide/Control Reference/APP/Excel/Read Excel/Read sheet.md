# Read sheet

**excelReadSheet**

**Description:**

Extract Sheet content, default active sheet content.

1\. The 'Data Reading Mode of Merged Cells' is set to 'Reading unMerged', the 'Reading Mode' is set to 'Value', and the regional data is processed uniformly, which is fast. But the return value of the numeric type cells is all decimals.

2\. The 'Data Reading Mode of Merged Cells' is set to 'Reading Merged', the 'Reading Mode' is set to 'Text', and the cells in the range are accessed and processed one by one, which is slow.

3\. When there is a lot of data to be read, and there is no requirement for the return value of the numeric cell, you can choose the parameter configuration of method 1 to improve efficiency.

**samples**

The following configuration will obtain all the contents of Sheet1 in the Excel file. The merged cells are all empty strings except for the first one that has a value. The return value of a numeric type cell is a decimal. Skip trailing blank rows and columns. This kind of parameter configuration is uniformly processed in the region, and the speed is fast.
