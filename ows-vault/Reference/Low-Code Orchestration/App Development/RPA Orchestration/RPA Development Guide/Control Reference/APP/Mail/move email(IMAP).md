# move email(IMAP)

**imap.moveEmail**

**Description:**

1\. The IMAP protocol is used to move the emails that meet the conditions.

2\. Before obtaining an email, ensure that the network connection is normal.

3\. There is a communication delay between the client and the server. If the email fails to be moved, you can set the delay before execution.

**Input: none**
