# Send email(SMTP)

**smtp.sendEmail**

**Description:**

1.Send email by SMTP server.The frequent sending is limited. It is recommended that the sending interval be greater than 500 ms.

2.For details, see the usage of each parameter.

3\. Please ensure that the network is unblocked before sending emails.

**Input: none**

**Samples**

1\. Use Huawei smtp server smtp.huawei.com, port number to send emails, of which ports 465 and 587 are SSL ports, and port 25 is an insecure port;

2\. When you are not sure about the SSL port of the smtp server you are using, you can make a try in 465 and 587;

3\. In the protocol, smtp is an insecure protocol, and smtps\_unidirectional\_auth is a secure one-way authentication. If you have the CA certificate of the smtp server, you can import the CA certificate in Settings-Certificate Management-Import Certificate. If not, we will load the default Windows system. The CA certificate is used to verify the security of the server. smtps\_bidirectional\_auth is a secure two-way authentication. If you choose this protocol, you need to pass in the client certificate, client certificate private key, and private key password. The premise is that the smtp server you choose supports two-way authentication. When you choose smtp protocol, please use port 25, if you choose other protocols, please use port 465 or 587;

4\. The subject of the email is "Test mail run result report", the sender is from, the recipient is to, cc cc, bcc bcc, the body image is image, and the attachment is "D:\\test\\msc. png", the email account is user, and the password is password
