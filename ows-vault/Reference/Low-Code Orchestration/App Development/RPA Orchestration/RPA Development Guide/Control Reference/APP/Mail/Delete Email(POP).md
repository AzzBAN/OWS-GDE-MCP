**Samples**

1\. Search for emails that meet the filter criteria from popscn.huawei.com using a user name and a password.

2\. In protocol, POP3 is an insecure protocol and uses port 110. pop3s\_unidirectional\_auth is a secure unidirectional authentication protocol and uses port 995.

3\. If you have the CA certificate of the server, choose Settings > Certificate Management > Import Certificate to import the CA certificate. Otherwise, the default CA certificate of the Windows system is loaded to verify the security of the server. pop3s\_bidirectional\_auth indicates bidirectional authentication and uses port 995. If the server supports bidirectional authentication, besides the CA certificate, you also need to import the client certificate, private key, and private key password.

4\. Search for the first email that meets the following conditions and delete it: The recipient or CC is test@test.com. The receiving date is between 20190628000000 and 20190629000000. The sender is test@test.com and the subject contains hello.
