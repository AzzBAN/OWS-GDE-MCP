# Invoke Macro

**excelExecuteMacro**

**Description:**

Execute the macro (or function) in the Excel file

Note:You need to select the access permission for VBProject:

1\. Select Development Tools: File > Options > Custom Ribbon > Development Tools.

2\. Excel: Development Tools > Macro Security > Macro Settings > Trust Access to VBA Project Object Model.

3\. WPS: Development Tools > Macro Security > Reliable Publishers > Trust Access to Visual Basic Projects.

4\. Warning:This command involves macro operations (which may contain malicious code), which may pose security risks. Ensure that the file source is reliable and run this command with caution.
