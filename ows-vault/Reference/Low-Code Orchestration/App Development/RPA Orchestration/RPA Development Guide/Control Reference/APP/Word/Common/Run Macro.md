# Run Macro

**word.runMacro**

**Description:**

Invoke a sub (macro) or function in the VBA code component.Some VBA code can be successfully executed only when they are visible. If the macros fail to be executed in the background, open the document in the foreground visual mode.You need to select the access permission for VBProject:

1\. Select Development Tools: File > Options > Custom Ribbon > Development Tools.

2\. Word: Development Tools > Macro Security > Macro Settings > Trust Access to VBA Project Object Model.

3\. WPS: Development Tools > Macro Security > Reliable Publishers > Trust Access to Visual Basic Projects
