# Invoke the Macro Of VBA Module File

**excelInvokeVBA**

**Description:**

Invoke the sub or function in the VBA code module.

The settings of office and WPS are different:

1.To execute this command, you must go to the trust center of Excel-> Macro Settings-> Developer Macro Settings-> Trust Access to VBA Engineering Object Model;

2\. For the WPS personal edition, install VBA FOR WPS.exe 6.0 or later to enable the macro. Choose Options -> Trust Center -> Enable Macro to automatically add the document as a trusted document. On the WPS tool bar, choose Development Tool > Macro Security. (1) Select Low for Security Level; (2) Select Trust for Access to Visual Basic Projects for Reliable Publishers;

This command involves macro operations (which may contain malicious code), which may pose security risks. Ensure that the file source is reliable and run this command with caution.
