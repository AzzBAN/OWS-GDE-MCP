# Invoke Restful API

**requestApi**

**Description:**

1.Request restApi url

2.The data type of the headers and files parameters is a dictionary. If the value of the dictionary is a variable, do not add double quotation marks to the variable.

3\. If the data type of the body parameter is a dictionary and the value of the dictionary is a variable, do not add double quotation marks to the variable. If the XML text is transferred, you are advised to use triple quotation marks, for example """<xml....>"""

**Input: none**

For interface requests using OAuth2 authentication method, the grant type is authorization code mode. This grant type requires a customized operation process to log in to the authorization server and obtain authorization. In the sub-process, you need to log in to the authorization page to obtain authorization, and save the redirected URL after obtaining authorization to the output result, named auth\_response\_url. The sub-process is preset with an input parameter named auth\_url by default. Its content is the URL of the authorization page, which can be directly referenced in the custom operation process.

For interface requests using OAuth2 authentication method, the grant type is implicit mode. This grant type requires a customized operation process to log in to the authorization server and obtain authorization. In the sub-process, you need to log in to the authorization page to obtain authorization, and save the redirected URL after obtaining authorization to the output result, named auth\_response\_url. The sub-process is preset with an input parameter named auth\_url by default. Its content is the URL of the authorization page, which can be directly referenced in the custom operation process.
