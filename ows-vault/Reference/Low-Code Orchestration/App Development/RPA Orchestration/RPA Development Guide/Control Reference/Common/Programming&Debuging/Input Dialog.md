# Input Dialog

**system.simpleDialog**

**Description:**

An input dialog box pops up. Input parameter: value:string type,optional,Label of the dialog box. The default value is Please enter a value. Output parameter: systemsimpleDialog\_ret:content in the text box. If the text box is empty, click OK to return an empty string. Click Cancel or Close to return to None.

**Input: none**
