# Download File

**downloadFile**

**Description:**

download file from http or https. If the download link is an untrusted HTTPS link and a CA certificate is available, choose Settings > Certificate Management > Service Certificate to import the CA certificate, or set the verify parameter to false, the second method has security risks, and users must bear the risks.).
