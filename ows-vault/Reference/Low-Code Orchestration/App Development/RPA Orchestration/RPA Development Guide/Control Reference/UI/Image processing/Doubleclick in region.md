# Doubleclick in region

**citrix.dclickPicRegion**

**Description:**

Double-click on the picture under a certain area (combined with Citrix.waitForPic to identify a certain area); configure the offset of the x and y axis to control the position of the click in the picture, if not configured, click the center of the picture by default

**Input: none**
