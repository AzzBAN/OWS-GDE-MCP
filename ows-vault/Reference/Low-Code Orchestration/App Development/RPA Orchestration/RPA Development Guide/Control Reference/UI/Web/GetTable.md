# GetTable

**getTable**

**Description:**

Get the table information on the page and output the information:

1.When obtaining multi-page table data, if the obtained data is incomplete, it may be due to network reasons that the element has not been loaded. Please set the next-page-delay parameter to wait for the element to be loaded according to the network situation;

2.This command supports only standard tables with table tags on web pages. Data similar to tables is not supported.

3.The return value is of the DataFrame type by default and can be of the List type.
