# Send keys to active element

**sendKeysToCursor**

**Description:**

send keys to the element that is currently in focus:

1.This command is an advanced actionchains command and must be placed between the actionchains and perform commands. Otherwise, an error message indicating that the command does not exist is displayed.

2.the character length of the data is limited by the maxLength attribute of element. If the former is greater than the latter, only text of the maxlength attribute value can be entered.
