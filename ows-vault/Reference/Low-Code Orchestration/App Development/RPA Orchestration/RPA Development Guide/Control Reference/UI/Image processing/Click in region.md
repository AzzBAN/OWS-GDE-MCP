# Click in region

**citrix.clickPicRegion**

**Description:**

Left-click the picture under a specific area (combined with citrix.waitForPic to identify the specific area); configure the offset of the x and y axis to control the position in the picture, if not configured, click the center of the picture by default

**Input: none**
