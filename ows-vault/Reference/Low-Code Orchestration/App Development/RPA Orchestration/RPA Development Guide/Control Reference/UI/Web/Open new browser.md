# Open new browser

**new\_browser**

**Description:**

open new browser:

1.You can open Chrome, Firefox, and Internet Explorer. You can select a value from selenium\_driver\_type. The Chrome browser is opened by default.

2.The configuration parameters vary according to browsers.

**Input: none**
