# Release(actionchains)

**release**

**Description:**

release the left mouse button at an element position:

1.This command is an advanced actionchains command and must be placed between the actionchains and perform commands. Otherwise, an error message indicating that the command does not exist is displayed.

2.This command can be used with the clickAndHold command to implement the drag effect.
