# get control info

**getControlInfo**

**Description:**

Obtain the control information. The Name,ClassName,AutomationId,ControlType,Rect (control position), handle (control handle), DefaultAction (next default action), State (control status), Value (text value), Role, and Help of the control can be obtained. These can be captured with insepct.exe.
