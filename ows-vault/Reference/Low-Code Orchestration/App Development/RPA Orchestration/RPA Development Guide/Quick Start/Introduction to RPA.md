#### Studio

Studio provides the right automation canvas for you to build workflows on your local PC. After Studio is installed, select a desired orchestration mode.

![[en-us_image_0000002497800382.png]]

-   Studio: designed for professional developers who are experienced in programming and can also use low-code tools to leverage all design capabilities of Studio.
-   StudioE: designed for citizen developers to skip the error-prone manual programming. Its drag-and-drop mode reduces the coding workload but its development capability is weaker than that of Studio. Moreover, scripts developed in Studio cannot run in StudioE.
