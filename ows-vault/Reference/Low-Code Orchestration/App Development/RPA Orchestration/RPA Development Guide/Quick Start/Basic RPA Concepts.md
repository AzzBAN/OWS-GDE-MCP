#### What Is RPA?

RPA is broadly considered a form of business process automation. RPA is a technology that mimics the way humans interact with software. RPA technology creates bots that can manipulate data, run applications, complete tasks, make decisions based on predefined rules, and communicate with other digital systems. RPA is used to automate human activities that are manual, rule-based, and repetitive, speeding up standard data input processes previously handled by humans.

Compared with traditional workflow automation tools, RPA develops the action list by watching the user perform that task in the application's graphical user interface (GUI), and then perform the automation by repeating those tasks directly in the GUI. This can lower the barrier to use of automation and drastically speed up automation development.

RPA tools have strong technical similarities to GUI testing tools. These tools also automate interactions with the GUI, and often do so by repeating a set of demonstration actions performed by a user. RPA tools differ from such systems in that they allow data to be handled in and between multiple applications, for instance, receiving email containing an invoice, extracting the data, and then typing that into a bookkeeping system.

The use of RPA services also aligns with certain risks. For example, a more complex maintenance environment needs to be created for the existing software, or the GUI used by some applications may not be the most efficient and stable choice in some scenarios.

In general, RPA is considered as one of the most efficient methods for digital transformation. It can be seen as labor force provided by a virtual robot that is operated and managed by the service line (supported by IT), just like a human labor.
