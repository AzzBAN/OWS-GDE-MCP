# Quick Start

If you are new to Robotic Process Automation (RPA), focus on basic RPA concepts, identify the RPA functionalities, and then develop the first instance to help you quickly get started with RPA.

-   **[[Basic RPA Concepts|Basic RPA Concepts]]**  
    This topic describes the basic concepts of RPA and the functionalities of each module in RPA.
-   **[[Introduction to RPA|Introduction to RPA]]**  
    RPA consists of Studio, Assistant, and Connector. The combination of these three tools meets different requirements of RPA.
-   **[[Security Statement|Security Statement]]**  
    This section describes possible security risks when RPA is used and provides operation suggestions.
-   **[[GUI Introduction|GUI Introduction]]**  
    After learning the basic knowledge about RPA, you will further know the main graphical user interface (GUI) and shortcut keys of RPA.
-   **[[First Instance Development|First Instance Development]]**  
    This section describes how to quickly develop robotic script instances using an example.
