#### Main GUI in Studio

[Figure 1](#EN-US_TOPIC_0000001160857148__fig107865771211) shows the main GUI in Studio orchestration mode.

**Figure 1** Main GUI in Studio orchestration mode

![[en-us_image_0000002344627240.png]]

The functions of each functional area on the main page in Studio orchestration mode are as follows:

-   Area 1: The menu bar includes the following five level-1 menus: **Home**, **Design**, **Settings**, **Help**, and **Extension Management**. The main functions of the menu are as follows:
    -   **Home**: Studio home page used to open an existing project, import a recorded script, create a project, view recently edited projects, and create a project using a template
    -   **Design**: Studio process design page used to develop, debug, and verify RPA business processes
    -   **Settings**: Studio configuration page used to set parameters on the general, license, driver, certificate, connection, shortcut key, orchestration mode configuration, and other tab pages You can set the Studio information based on site requirements.
    -   **Help**: Help center of Studio used to provide help documents, access the forum, and obtain iLearning courses
    -   **Extension Management**: Extension package management page of Studio used to display installed extension packages and install required extension packages
-   Area 2: The toolbar includes the **UI Recorder**, **Run**, **Debug**, **Save**, **Publish**, **Advance**, and other buttons. The functions of these buttons are as follows:
    -   **UI Recorder**: Start a recorder. When you record steps on a web page, local Windows, or local Java application, Studio automatically converts the steps into an execution script of the RPA executor.
    -   **Run**: Play back or execute a recorded script to check whether the process in Studio is correct.
    -   **Debug**: Debug a recorded script to check whether the script in Studio can be executed and analyze and rectify faults occurred during script execution.
    -   **Save**: Save a recorded script to prevent the information recorded in Studio from being lost.
    -   **Publish**: Publish a recorded and debugged script to a local disk, RPA Orchestrator, or GDE Store.
    -   **Advance**: Search for sub-modules or check items and scripts in the project to quickly locate the control corresponding to the source code or view the check items and scripts.
    -   **Data Extract**: Click this button to obtain the web page data by following the wizard, and automatically generate the corresponding control on the canvas.
-   Area 3: This area displays projects and controls. You can drag the required controls to the canvas in Studio.
-   Area 4: This area enables you to edit the canvas and source codes. In this area, you can develop RPA business processes.
-   Area 5: This area provides canvas tools. You can use the **Undo**, **Redo**, **Zoom In**, **Zoom Out**, **Overview**, **Locate to Start**, **Auto Layout**, **Enable Auto Layout**, **Collapse sidebar**, and **Clear** buttons. When you develop an RPA process on the canvas, select tools as required.
    -   **Undo**: Go back to the previous operation.
    -   **Redo**: Go to the latest operation performed before you click **Undo**.
    -   **Zoom In** and **Zoom Out**: Zoom in or out on a process diagram on the canvas.
    -   **Overview**: View the overall thumbnail of the canvas.
    -   **Locate to Start**: Locate the start node in the middle of the canvas.
    -   **Auto Layout**: Display a process in the middle of the canvas and automatically arrange it.
    -   **Enable Auto Layout**: Automatically display a process in the middle of the canvas and arrange the process lines.
    -   **Collapse sidebar**: Collapse the sidebars on both sides of the canvas.
    -   **Clear**: Clear all controls on the current canvas.
-   Area 6: This area displays the control properties. When clicking a control on the canvas, you can view and edit the control properties on the **Attribute** tab page or view the control functions, parameters, and usage examples on the **Help** tab page.
-   Area 7: This area provides a debugging area. When executing or debugging a script, you can view the run logs and error list of the script, set global variables and parameters required for debugging the script, perform the health check on the script, view related script elements, or view script reference relationships.
