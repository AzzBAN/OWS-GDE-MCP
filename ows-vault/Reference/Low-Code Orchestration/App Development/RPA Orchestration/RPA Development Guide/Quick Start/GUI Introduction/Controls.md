#### Control List

[Table 1](#EN-US_TOPIC_0000001160697166__table18812191121310) describes the controls preset in Studio.

**Table 1** Control list    
| Type | Function | Studio | StudioE |
| :-- | :-- | :-- | :-- |
| UI Automation | Controls that can be used in web, desktop, and image-based applications Examples: Open Web Page, Click, and Compare Picture | Yes | Yes |
| APP | Controls that can be used in Excel, Word, and emails Examples: Read Excel, Open Word, and Send Email | Yes | Yes |
| System | Controls that can be used for the clipboard, time processing, and operating system Examples: Save the text data to the clipboard and Clip an Image | Yes | Yes |
| Common | Controls that can be used for text processing and calling Examples: Run python Expression and Invoke C# | Yes | Yes |
| Workflow | Controls that can be used for process control and exception handling Examples: Break the Loop and Throw Exception | Yes | Yes |
| AI | Controls that can be used by the NAIE-S engine and EI-OCR Examples: Image Identification and controls in EI-OCR | Yes | No |
| Dataprocess | Controls that can be used for two-dimensional data processing, QR code, and mathematical operations Examples: Get Table, Create QR Code, and Math | Yes | No |
| Database | Controls that can be used in relational and non-relational databases Examples: Connect to Database and Insert into Mongodb | Yes | No |
| Orchestrator | Controls that can be used for queue operations and human-machine collaboration in the management center Examples: Write Data and Creating a human-computer interaction tasks | Yes | No |
| Social Tools | Controls that can be used by social software Examples: Get Access Token or Send Text Message | Yes | Yes |
| Huawei Only | Controls that can be used for handling messages Examples: Send Short Message or Make a Voice Call | Yes | No |
| UI (deprecated) | Controls that can be used on web pages Example: Append Text | Yes | No |
