# GUI Introduction

After learning the basic knowledge about RPA, you will further know the main graphical user interface (GUI) and shortcut keys of RPA.

-   **[[Main GUIs|Main GUIs]]**  
    This section describes the GUIs and functions of the Studio agent in Studio and StudioE orchestration modes.
-   **[[Controls|Controls]]**  
    Studio provides a list of commonly used controls to accelerate RPA development.
-   **[[Shortcut Keys|Shortcut Keys]]**  
    You can use shortcut keys to improve the development efficiency of RPA processes.
-   **[[Function Keys|Function Keys]]**  
    You can use the function keys on the keyboard to complete keyboard-related operations when using the **sendKeys** commands in Studio.
