#### Shortcut Key List

[Table 1](#EN-US_TOPIC_0000001206417135__table14707101210506) lists the default shortcut keys in Studio.

**Table 1** Shortcut keys   
| Module | Shortcut Key | Description |
| :-- | :-- | :-- |
| Running | Ctrl + Shift+F10 | Run the main script. |
| Ctrl + F10 | Run the current script. |
| Ctrl + R | Start the UI recorder. |
| Canvas | Ctrl + S | Save |
| Ctrl + Shift + A | Save all |
| Ctrl + Z | Undo |
| Ctrl + Y | Redo |
| Ctrl + C | Copy |
| Ctrl + V | Paste |
| Ctrl + K | Generate block comments. |
| Delete | Delete |
| Ctrl + A | Select all |
| Ctrl + X | Cut |
| Ctrl+Mouse Wheel | Zoom in and out |
| Press and hold the left mouse button and drag | Select rectangular regions. |
| Ctrl+LeftMouseButton Press and hold the Right Mouse Button | Move the canvas. |
| Source Code | Ctrl + F | Search |
| Ctrl + Shift + F | Find in Project |
| Ctrl + Shift + / | Notes |
| Ctrl + H | Replace |
| Ctrl + D | Delete Row |
| Debug | F6 | Next Step |
| F8 | Next BreakPoint |
| Ctrl +Shift + F9 | Debug the main script |
| Ctrl + F9 | Debug the current script |
| Global System Configuration | Esc | Stop PickUp |
| Ctrl + Shift+ S | Stop Running |
| Others | F12 | Open Console |
| Ctrl + G | Switch canvas and script |
| Ctrl + T | Switch project and actions |
| Ctrl + P | Publish |
