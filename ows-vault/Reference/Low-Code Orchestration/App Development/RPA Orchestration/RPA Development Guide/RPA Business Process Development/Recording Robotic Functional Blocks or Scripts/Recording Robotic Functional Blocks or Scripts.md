# Recording Robotic Functional Blocks or Scripts

This section describes how to record robotic functional blocks or scripts.

-   **[[Introducing Recording Functions|Introducing Recording Functions]]**  
    This topic describes the basic concepts and functions related to recording.
-   **[[Recording a Robotic Functional Block|Recording a Robotic Functional Block]]**  
    Studio supports the recording of web applications, Windows applications, and Java applications. This topic describes how to record a robotic functional block.
-   **[[Recording a Robotic Subscript|Recording a Robotic Subscript]]**  
    Studio supports the recording of web applications, Windows applications, and Java applications. This topic describes how to record a robotic subscript.
-   **[[Clearing the Canvas and Recording a Robotic Script|Clearing the Canvas and Recording a Robotic Script]]**  
    You can clear the current canvas and record robotic scripts to automatically perform operations on specified web application pages or local applications.
