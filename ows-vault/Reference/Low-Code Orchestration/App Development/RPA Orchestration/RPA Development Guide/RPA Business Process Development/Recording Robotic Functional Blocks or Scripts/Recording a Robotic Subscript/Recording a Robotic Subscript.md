# Recording a Robotic Subscript

Studio supports the recording of web applications, Windows applications, and Java applications. This topic describes how to record a robotic subscript.

-   **[[Recording a Web Application Subscript|Recording a Web Application Subscript]]**  
    After you record a web application subscript, operations can be automatically performed on the specified web application pages.
-   **[[Recording a Local Application Subscript|Recording a Local Application Subscript]]**  
    After you record a local application script, operations can be automatically performed on the specified local application pages.
