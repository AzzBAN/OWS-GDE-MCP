# Recording a Robotic Functional Block

Studio supports the recording of web applications, Windows applications, and Java applications. This topic describes how to record a robotic functional block.

-   **[[Recording a Web Application Functional Block|Recording a Web Application Functional Block]]**  
    After you record web application functional blocks, operations can be automatically performed on specified web application pages.
-   **[[Recording a Local Application Functional Block|Recording a Local Application Functional Block]]**  
    After you record a local application functional block, operations can be automatically performed on the specified local application pages.
