# Creating a Project

Studio allows you to create a project manually or using a template.

-   **[[Manually Creating a Project|Manually Creating a Project]]**  
    Manually create a project before you develop robot scripts.
-   **[[Creating a Project Using a Template|Creating a Project Using a Template]]**  
    Select one of the templates preset in Studio to create a project based on site requirements.
-   **[[Using Git for Collaborative Project Development|Using Git for Collaborative Project Development]]**  
    By cloning an existing Git repository, you can develop a project collaboratively.
