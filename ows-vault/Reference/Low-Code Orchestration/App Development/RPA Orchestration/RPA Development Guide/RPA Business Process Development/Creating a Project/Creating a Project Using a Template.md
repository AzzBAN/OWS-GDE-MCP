#### Procedure

1.  Start Studio.
2.  In the navigation pane, click ![[en-us_image_0000001213342833.png]].
3.  (Optional) If the preset templates cannot meet requirements, import the required templates to Studio.
    
    1.  In the **Create from Template** area, click **Import**.
    2.  In the **Template Import** dialog box, configure the template import information.
        
        ![[en-us_image_0000001952449605.png]]
        
        **Table 1** Parameter description  
        | Parameter | Description |
        | :-- | :-- |
        | Template | Template package to be imported. Currently, only ZIP files can be imported, and a maximum of 10 template files can be selected at a time. Click Select and select the desired template package. |
        | Overwrite Template | Whether to overwrite the existing template when the name of the template to be imported is the same as that of an existing template in Studio.
        -   **Yes:** Replace the file.
        -   **No**: Cancel the import.
        
         | 3.  Click **OK**.
    4.  (Optional) To save a template in Studio to the local PC, export the required template.
        1.  In the template list, select one or more templates and click **Export**.
        2.  In the **Template Export** dialog box, configure the template export information.
            
            ![[en-us_image_0000001952620249.png]]
            
            **Table 2** Parameter description  
            | Parameter | Description |
            | :-- | :-- |
            | Template | Template to be exported |
            | Saved Path | Path for saving the template file. Click to select a path. | 3.  Click **OK**.
    
4.  In the **Create From Template** area, select a required template.
5.  In the displayed dialog box, configure the project information.
    
    ![[en-us_image_0000001256501386.png]]
    
    **Table 3** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Project Name | Project name, which can contain only Chinese characters, letters, digits, and underscores (\_). The value must start with a letter or Chinese character. |
    | Saved Path | Path for saving project files. Click to select a path. NOTE: You can choose > General from the navigation pane to set the default path for storing project files. |
    | Supported Operating System Types | Operating system types supported by the project
    -   Windows
    -   Linux
    
     |
    | Developers | Project developer. The value can contain only Chinese characters, letters, digits, and underscores (\_), and must start with a letter or Chinese character. |
    | Description | Description of a project | 6.  Click **Create**.
    
    After the project is created, Studio automatically displays the project design page, and the blocks and business processes of the template on the canvas. You can edit the template to develop a business process based on site requirements.
