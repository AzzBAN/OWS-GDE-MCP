#### Background

After a project is created, Studio saves the project files to a specified project path. The following figure shows the directory structure of the project.

![[en-us_image_0000001212595497.png]]

Each folder and file can be used as follows:

-   **bak**: stores robot script backup files of a project.
-   **Input**: stores the input files of a project.
-   **Lib**: stores the third-party libraries or codes on which the robot script of a project depends.
-   **Project**: stores the robot script files of a project.
-   **ScreenShot**: stores screenshot files generated during robot script recording.
-   **temp**: stores temporary files of a project.
-   **readme\_en\_US.txt**: stores the directory notes in English.
-   **readme\_zh\_CN.txt**: stores the directory notes in Chinese.
-   **Robot.xml**: stores the project basic information.
-   **\*.rpa**: stores the RPA file of a project that can be opened in one-click mode.
