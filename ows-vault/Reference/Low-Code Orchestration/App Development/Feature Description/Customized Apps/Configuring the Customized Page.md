#### Context

If an app developed by a developer is used by different projects, the page needs to be customized.

The page can be customized in either of the following ways:

-   **Override**: Completely clear the existing page configuration, which is similar to creating a page to replace the original one.
-   **Extend**: Customize the original page by adding components to the original page.
