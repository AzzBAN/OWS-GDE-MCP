#### Context

Assume that a developed app is provided for different projects. In different projects, most pages, logic, and functions of the app can be reused. Only some model properties need to be customized. For example, you need to add a property to an existing model.

When configuring a model, you need to set whether the model can be customized. You can add customized properties only for models whose **Allow Customization** is set to **Yes**.

**Allow Customization** can be set to **Yes** only for data models.
