#### Obtaining the JDBC Driver Package of a Model

To download the package from the runtime-state page, perform the following steps:

1.  Log in to the runtime-state environment as the **admin** user of a tenant.
2.  Choose **Model Management** > **Model JDBC Driver Download**.
3.  Click **Download** to obtain the JDBC driver package in ZIP format of the model.
4.  Decompress the ZIP package to obtain the JAR driver package.
