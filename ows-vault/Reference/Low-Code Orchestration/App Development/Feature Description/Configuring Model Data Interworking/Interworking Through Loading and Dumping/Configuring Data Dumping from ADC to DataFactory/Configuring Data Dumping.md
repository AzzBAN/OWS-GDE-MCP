#### Procedure

1.  Choose **Project Management**.
2.  Select the project to be operated.
3.  Select the module to be operated.
4.  Choose **Model**.
5.  (Form) Select the model to be operated, click **Manage**.
6.  (Canvas) In the canvas area, click ![[en-us_image_0000001578453748.png]] of the model for which you want to perform archiving configuration and select **Model Management**.
7.  Choose **Data Process (Dump)** from the navigation pane and configure the dump information.
    
    ![[en-us_image_0000001628454429.png]]
    
    **Table 1** Parameter description  
    | Name | Description |
    | :-- | :-- |
    | Dump Mode | Data extraction and dump mode. The options are Incremental and Full. |
    | Aging Period | Data retention period |
    | Dump Interval | Execution interval of a data dump task |
    | Dump Latency | Latency for executing a data dump task |
    | Logical Entity | Logical model for MetaOne. The name is automatically generated. |
    | Physical Entity | Physical model for MetaOne. The name is automatically generated. | 8.  Click **Submit**.
