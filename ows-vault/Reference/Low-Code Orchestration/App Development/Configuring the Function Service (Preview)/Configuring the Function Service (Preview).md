# Configuring the Function Service (Preview)

This chapter describes how to develop the function service. The permission for function service development is **Function Development**, and the corresponding role is **StudioFaasDeveloper**. If the developers do not have this permission, apply for it from the administrator.

-   **[[Introduction to Function Service|Introduction to Function Service]]**  
    This section describes functions provided by the function services.
-   **[[Configuring System Parameters of the Function Service|Configuring System Parameters of the Function Service]]**  
    You can create system parameters of the function service based on site requirements to facilitate subsequent service development and call.
-   **[[Managing the Dependency Package|Managing the Dependency Package]]**  
    This section describes how to create a dependency package and how to configure a tenant-level or project-level dependency package.
-   **[[Configuring a Third-Party Image Repository|Configuring a Third-Party Image Repository]]**  
    The system provides the third-party image repository management capability to enable the interworking with a third-party image repository and verify certificates, so that dependency packages can be downloaded from an external repository.
-   **[[Configuring Dependency Upgrade|Configuring Dependency Upgrade]]**  
    The system provides a page for managing dependency upgrade and supports the update of dependencies of third-party components in batches.
-   **[[Configuring a Function Service Template|Configuring a Function Service Template]]**  
    The system provides a page for managing function service templates, including adding, deleting, modifying, querying, exporting, and importing the templates. Currently, function service templates support only tenant-level templates by default.
-   **[[Creating Python Function Service|Creating Python Function Service]]**  
    The function service allows you to develop functions using Python code.
-   **[[Online Editor User Guide|Online Editor User Guide]]**  
    When editing function code, you can create and edit files and folders in the way same as that of managing projects. You can use the inline editor to compile function code inline. If you upload a .zip package, the frontend decompresses the package and displays it. You can edit the code inline.
-   **[[Online Python Function Service Debugging|Online Python Function Service Debugging]]**  
    After a function is created, you can debug it online.
-   **[[Local Debugging of a Python Function Service|Local Debugging of a Python Function Service]]**  
    After creating a function, you can use PyCharm to locally test the Python function service.
-   **[[FAQs|FAQs]]**  
    This section describes common issues that may occur during the function services.
