#### Prerequisites

-   PyCharm of a version between 2020.2 and 2022.2 (professional or community edition) has been installed.
-   The Pro Code plugin installation package has been obtained. For details, see [[Downloading the Local Debugging Tool|Downloading the Local Debugging Tool]].
