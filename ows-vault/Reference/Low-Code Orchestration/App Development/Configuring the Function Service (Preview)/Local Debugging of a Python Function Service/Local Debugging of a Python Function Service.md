# Local Debugging of a Python Function Service

After creating a function, you can use PyCharm to locally test the Python function service.

-   **[[Downloading the Local Debugging Tool|Downloading the Local Debugging Tool]]**  
    The local debugging tools include the Pro Code CLI offline tool and Pro Code plugin installation package.
-   **[[Installing the Pro Code CLI Offline Tool|Installing the Pro Code CLI Offline Tool]]**  
    You can use the Pro Code CLI offline tool to initialize a FaaS runtime environment locally so that you can use the breakpoint debugging function of PyCharm to implement local debugging.
-   **[[Installing the Pro Code Plugin|Installing the Pro Code Plugin]]**  
    Before using PyCharm to create a local Python project, you need to install the Pro Code plugin.
-   **[[Logging In to PyCharm|Logging In to PyCharm]]**  
    PyCharm interworks with the Pro Code CLI tool to implement the login function.
-   **[[Creating a Local Python Project|Creating a Local Python Project]]**  
    This section describes how to create a local Python project.
-   **[[Installing the Python Third-Party Components|Installing the Python Third-Party Components]]**  
    Before debugging a local Python project, you need to install the Python third-party component.
-   **[[Debugging a Local Python Project|Debugging a Local Python Project]]**  
    After creating a local Python project, you can debug functions in the project.
