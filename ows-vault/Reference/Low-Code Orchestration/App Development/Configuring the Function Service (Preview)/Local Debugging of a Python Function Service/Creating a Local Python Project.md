#### Prerequisites

-   PyCharm of a version between 2020.2 and 2022.2 (professional or community edition) has been installed.
-   Python 3.9.11 or later or Python 3.11.4 or later has been installed.
-   The Pro Code CLI offline tool has been installed.
-   The Pro Code plugin has been installed.
