#### Prerequisites

Node.js v18._x_ or later has been installed.

-   To check the Node.js version, open the CMD window on the local PC and run the **node -v** command on the CLI.
-   You can download Node.js from **https://nodejs.org/en/download**. If the installed Node.js version is too early, obtain the latest Node.js version with security hardening and install it.
-   There is a version mapping between Node.js and npm. Ensure that the npm version matches the Node.js version based on the mapping provided in [Nodejs Version Mapping](https://nodejs.org/en/about/previous-releases) to prevent version mismatch caused by manual npm upgrade.
    
    To check the npm version, open the CMD window on the local PC and run the **npm -v** command on the CLI.
