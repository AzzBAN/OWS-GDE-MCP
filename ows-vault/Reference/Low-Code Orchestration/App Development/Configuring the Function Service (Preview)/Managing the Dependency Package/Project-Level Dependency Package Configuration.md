#### Prerequisites

-   You have logged in to the develop-state environment and accessed the **Function Service** page.
-   The permission for editing project-level dependency packages is **Function Dependency Managing**, and the corresponding role is **StudioFaasDeveloper**. If you do not have the permission, apply for it from the administrator.
