#### Prerequisites

-   You have logged in to the develop-state environment and have obtained the function developer permission. The permission for function development is **Function Developing**, and the corresponding role is **StudioFaasDeveloper**. If you do not have the permission, apply for it from the administrator.
-   You have opened the **Function Service** menu.
-   Before debugging a function, you need to perform one-click deployment on the function. You can also enable hot deployment to prevent frequent one-click deployment during debugging.
