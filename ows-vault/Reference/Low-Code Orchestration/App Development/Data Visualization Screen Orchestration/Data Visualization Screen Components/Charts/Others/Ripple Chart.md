#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556942068.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Color | Color system of the ripple chart. |
| Transparency | Water ripple transparency. |
| Shadow Blur | Width of the shadow on the edge of the water ripple. |
| Shadow Color | Color of the shadow on the edge of the water ripple. |
| Center | Position of the ripple chart. |
| Radius | Percentage of the water ripple in the component canvas. |
| Amplitude | Water ripple amplitude. |
| Shape | Shape of the outer water ripple frame. | ![[en-us_image_0000001607342041.png]]

**Table 3** Animation Settings  
| Name | Description |
| :-- | :-- |
| Animation | Whether to start the initial animation of a chart. |
| Animation Easing | Slow-moving effect of the initial animation. For details about different slow-moving effects, see https://www.echartsjs.com/gallery/editor.html?c=line-easing. |
| Animation Duration | Duration of the initial animation, in milliseconds. |
| Animation Easing Update | Animation effect when data is updated. |
| Animation Duration Update | Animation duration when data is updated. | ![[en-us_image_0000001607501621.png]]

**Table 4** Label  
| Name | Description |
| :-- | :-- |
| Show | Whether to display the text label of the ripple chart. |
| Font | Text label font. You can set Font Family, Font Weight, Font Size, and Font Color. |
| Position | Position of the label text relative to the component. |
| Formatter | Label text format. Its value can be Percentage, Value, Name:Percentage, or Name:Value. | ![[en-us_image_0000001557101768.png]]

**Table 5** Background  
| Name | Description |
| :-- | :-- |
| Fill Color | Background filling color of the area other than water ripples. |
| Border Color | Color of the container background border. |
| Border Width | Width of the container background border line, in px. | **Outline**: outermost line of the ripple chart.

![[en-us_image_0000001556942184.png]]

**Table 6** Outline  
| Name | Description |
| :-- | :-- |
| Show | Whether to display the outline. |
| Border Distance | Distance between the outline and the ripple chart container, in px. |
| Border Color | Border color. |
| Border Width | Border width, in px. |
| Shadow Blur | Border shadow width, in px. |
