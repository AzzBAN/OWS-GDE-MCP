#### Properties

![[en-us_image_0000001556169412.png]]

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Content | Text content to be displayed. |
| Redirect URL | Page that a user is redirected to when the user clicks a text. |
| Open with | Page opening mode. The options include \_tab (open on a new tab page), \_self (open on the current page), and \_blank (open on a new page). |
| Alignment | Alignment mode of the text. There are three alignment modes: left-aligned, center-aligned (default), or right-aligned. | ![[en-us_image_0000001557056922.png]]

![[en-us_image_0000001557057734.png]]

**Table 2** Default Style  
| Name | Description |
| :-- | :-- |
| Font | You can set Font Family, Font Weight, Font Size, and Font Color. |
| Background | You can set the background color and image, as well as the background display mode of the text. |
| Border | You can set the style of the text border. |
| Opacity | You can set the transparency of a component. |
| Condition | You can set the font style of the text when the text content meets a certain condition. |
