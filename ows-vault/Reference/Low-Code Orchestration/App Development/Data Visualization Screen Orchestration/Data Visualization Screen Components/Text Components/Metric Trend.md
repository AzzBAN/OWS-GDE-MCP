#### Properties

-   **Layout**: arrangement mode of titles, values, and icons
    
    ![[en-us_image_0000001607111801.png]]
    
-   Title
    
    ![[en-us_image_0000001557071978.png]]
    
    -   **Title**: title content
    -   **Text Style**: font, font width, font size, and font color of the title
    
-   Value
    
    ![[en-us_image_0000001606952325.png]]
    
    -   **Text Style**: font, font width, font size, and font color of the value
    
-   Trend
    
    ![[en-us_image_0000001607112105.png]]
    
    -   **Text Style**: font, font width, font size, and font color of the trend information
    -   **Color of Increase Icon**: color of the ascending trend icon
    -   **Color of Equivalence Icon**: color of the flat trend icon
    -   **Color of Decrease Icon**: color of the descending trend icon
    
-   Unit
    
    ![[en-us_image_0000001607112277.png]]
    
    -   **Text**: text unit
    -   **Display Next to Value**: display position of the unit
    -   **Text Style**: font, font width, font size, and font color of the unit
    
-   Style
    
    ![[en-us_image_0000001557072430.png]]
    
    -   **Background** background color and background image of the component
    -   **Border**: border type, width, and color of the component
