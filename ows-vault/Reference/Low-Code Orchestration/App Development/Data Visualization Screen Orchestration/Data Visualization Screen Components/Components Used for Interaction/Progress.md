#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556682086.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Type | Progress bar display type. The options include No Text, Top Text, Bottom Text, Between Text, No Text Bar, and Text Bar. |
| Value Display Type | The value can be Percent or Digit. | ![[en-us_image_0000001607042069.png]]

**Table 3** Prefix Configuration  
| Name | Description |
| :-- | :-- |
| Text Content | Text content to be displayed in the prefix. |
| Font | The value includes Font Family, Font Weight, Font Size, and Font Color. | ![[en-us_image_0000001606842637.png]]

**Table 4** Suffix Configuration  
| Name | Description |
| :-- | :-- |
| Text Content | Text content to be displayed in the suffix. |
| Font | The value includes Font Family, Font Weight, Font Size, and Font Color. | ![[en-us_image_0000001556203670.png]]

**Table 5** Background  
| Name | Description |
| :-- | :-- |
| Direction | Progress gradient color direction. The value can be Horizontal or Vertical. |
| Color | Progress color. You can select multiple color gradients. |
| Background Color | Default background color. | ![[en-us_image_0000001556363142.png]]

**Table 6** Style  
| Name | Description |
| :-- | :-- |
| Border Radius | Progress bar with a rounded corner |
| Opacity | Transparency of the progress bar |
