#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001783057270.png]]

**Table 2** Basic properties  
| Name | Description |
| :-- | :-- |
| Edit States Toggle Panel | You can click it to go to the page for editing the status switching panel. |
| Carousel | If you select Yes, the system automatically switches between different states on the panel. This parameter is used together with the period attribute configuration. To use with the tab panel, set this property to No. |
| Duration | Duration for switching the status on the states toggle panel | **Edit States Toggle Panel**

On the states toggle panel, click **+Add a State** to add a state. Double-click the state name to change the name. The editing page of the dynamic panel is basically the same as that of the data visualization screen page. In the **Basic Properties** area on the right, you can set the page for each state and adjust the background color and background image.

![[en-us_image_0000001783216762.png]]

**Table 3** Basic properties  
| Name | Description |
| :-- | :-- |
| Background Color | Background color of each state |
| Background Image | Background image of each state |
