#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001607034525.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Date Type | Date and time type to be displayed in the text box. The options are Time, Date time, and Date and time range. |
| Date Format | Format of the date and time displayed in the text box. | ![[en-us_image_0000001607034809.png]]

**Table 3** Default Style  
| Name | Description |
| :-- | :-- |
| Font | Font style of the text in the date and time text box. |
| Background | Background style of the date and time text box. |
| Border | Border style of the date and time text box. |
| Opacity | Transparency of the text box and drop-down list. | ![[en-us_image_0000001556515082.png]]

**Table 4** Activation Style  
| Name | Description |
| :-- | :-- |
| Font Focus Color | Font color of the text box and drop-down list when they are activated. |
| Background Focus Color | Background color of the text box and drop-down list when they are activated. |
| Border Focus Color | Border color of the text box and drop-down list when they are activated. |
