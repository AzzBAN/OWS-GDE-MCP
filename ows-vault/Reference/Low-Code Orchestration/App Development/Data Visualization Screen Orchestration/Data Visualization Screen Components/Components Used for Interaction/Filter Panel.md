#### Properties

![[en-us_image_0000002231855654.png]]

**Table 1** Properties  
| Name | Description |
| :-- | :-- |
| Edit Panel Content | Allows you to drag subcomponents to the filter panel on the displayed sub-canvas. |
| Background Color | Allows you to set the background color of the filter panel. A gradient color can be configured. |
| Enable Vertical Scrollbar | Specifies whether to display the vertical scrollbar. |
| Enable Horizontal Scrollbar | Specifies whether to display the horizontal scrollbar. |
| Scrollbar Width | Allows you to set the width of the scrollbar. |
| Thumb Color | Allows you to set the color of the scrollbar slider. |
| Thumb Radius | Allows you to set the corner radius of the scrollbar slider. |
| Track Color | Allows you to set the color of the scrollbar track. |
| Track Radius | Allows you to set the corner radius of the scrollbar track. |
