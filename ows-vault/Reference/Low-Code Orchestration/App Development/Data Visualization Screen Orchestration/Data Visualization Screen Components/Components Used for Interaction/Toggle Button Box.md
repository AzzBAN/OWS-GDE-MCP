#### Properties

![[en-us_image_0000001556189094.png]]

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001607028369.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Value | Initial value of the component. |
| Spacing | Distance between buttons. | ![[en-us_image_0000001556669002.png]]

**Table 3** Animation Settings  
| Name | Description |
| :-- | :-- |
| Rotation Display | Whether to enable the rotation display mode. |
| Animation Duration | Animation duration. The value is an integer ranging from 1000 to 50000. | ![[en-us_image_0000001606869621.png]]

**Table 4** Default Style  
| Name | Description |
| :-- | :-- |
| Font | Font style. |
| Text Align | Alignment mode of the button text. |
| Background | Background color. |
| Border | Border style. | ![[en-us_image_0000001607029373.png]]

**Table 5** Activation Style  
| Name | Description |
| :-- | :-- |
| Font Color | Text color. |
| Background Color When Focus | Background color when the button is activated. |
| Border Color When Activated | Border color when the border is activated. |
