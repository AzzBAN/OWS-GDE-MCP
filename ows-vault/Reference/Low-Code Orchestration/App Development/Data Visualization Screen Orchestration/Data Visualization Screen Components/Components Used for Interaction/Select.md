#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556669878.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Placeholder | Used to set the default prompt content, for example, -Select-. |
| Value Field | Bound value field. |
| Display Field | Fields displayed in the drop-down list. |
| Multiple | Multiple election switch from a drop-down list. |
| Force Selection | Forcible selection switch. | ![[en-us_image_0000001556669970.png]]

**Table 3** Default Style  
| Name | Description |
| :-- | :-- |
| Font | Font of the selected value in the drop-down list. You can set Font Family, Font Weight, Font Size, and Font Color. |
| Background Color | Background color of the drop-down list. |
| Border | Type, width, and color of the drop-down list border. |
| Border Radius | Radius of the rounded corner of the border. |
| Opacity | Transparency of the drop-down list. | ![[en-us_image_0000001607029921.png]]

**Table 4** Hover Style  
| Name | Description |
| :-- | :-- |
| Font Color When Blur | Color of the selected value when the cursor is moved over the drop-down list. |
| Background Color When Blur | Background color when the cursor is moved over the drop-down list. |
| Border Color When Blur | Border color when the cursor is moved over the drop-down list. | ![[en-us_image_0000001556510102.png]]

**Table 5** Activation Style  
| Name | Description |
| :-- | :-- |
| Font Focus Color | Font color when a drop-down list is selected. |
| Background Focus Color | Background color when a drop-down list is selected. |
| Border Focus Color | Border color when a drop-down list is selected. | ![[en-us_image_0000001607150181.png]]

**Table 6** MultiSelect Style  
| Name | Description |
| :-- | :-- |
| Font | Font style of the selected value in the multi-selection scenario. |
| Background Color | Background color of the selected value in the multi-selection scenario. |
| Close Tag Color | Color of the close icon in the multi-selection scenario. |
| Close Tag Background Color | Background color of the close icon in the multi-selection scenario. |
| Close Tag Color When Blur | Color of the icon when the cursor is moved over the close icon in the multi-selection scenario. |
| Close Tag Background Color When Blur | Background color of the icon when the cursor is moved over the close icon in the multi-selection scenario. | ![[en-us_image_0000001556350794.png]]
