#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556360490.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Value | Initial status of the switch. |
| Value When Activated | Value when the switch is toggled on. |
| Value When Inactivated | Value when the switch is toggled off. | ![[en-us_image_0000001556680350.png]]

**Table 3** Default Style  
| Name | Description |
| :-- | :-- |
| Border Radius | Switch frame radian |
| Button Color | Color of the switch button. |
| Opacity | Transparency of the Switch Button component. | ![[en-us_image_0000001606880821.png]]

**Table 4** Activation Style  
| Name | Description |
| :-- | :-- |
| Background Activation Color | Background color when the switch is toggled on. | ![[en-us_image_0000001606881053.png]]

**Table 5** Deactivate Style  
| Name | Description |
| :-- | :-- |
| Background Deactivation Color | Background color when the switch is toggled off. |
