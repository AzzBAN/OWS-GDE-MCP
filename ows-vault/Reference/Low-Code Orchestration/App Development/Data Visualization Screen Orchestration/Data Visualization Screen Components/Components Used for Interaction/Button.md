#### Properties

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556363702.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Text | Text displayed on a button. |
| Type | Button type. The options are Default, Text, and Icon. |
| Icon Class | Icons for the buttons of the Default or Icon type. |
| Bottom | Whether the icon of a button of the Default type can be placed at the end of the button. | ![[en-us_image_0000001556363914.png]]

**Table 3** Default Style  
| Name | Description |
| :-- | :-- |
| Font | Text and icon styles of the three types of buttons. |
| Background image | Background image of the button of the Default type (set either this parameter or the Background Color parameter). |
| Duplicate background image | Duplicate background image of the button of the Default type (set either this parameter or the Background Color parameter). |
| Background image size | Background image size of the button of the Default type (set either this parameter or the Background Color parameter). |
| Direction | Gradient direction of the background color of the button of the Default type (set either this parameter or the background image parameters) |
| Background Color | Background color of the button of the Default type (set either this parameter or the background image parameters). You can set multiple values. |
| Border | Border style of the button of the Default type. |
| Border Radius | Border radius of the button of the Default type. |
| Opacity | Transparency of all types of buttons. | ![[en-us_image_0000001607163509.png]]

**Table 4** Hover Style  
| Name | Description |
| :-- | :-- |
| Font Color When Blur | Font color of a button when the cursor is hovered over the button. |
| Background Color When Blur | Background color of a button of the Default type when the cursor is hovered over the button. |
| Border Color When Blur | Border color of a button of the Default type when the cursor is hovered over the button. | ![[en-us_image_0000001606844057.png]]

**Table 5** Activation Style  
| Name | Description |
| :-- | :-- |
| Font Color | Font color of a button when the button is clicked. |
| Background Color When Focus | Background color of a button of the Default type when the button is clicked. |
| Border Color When Activated | Border color of a button of the Default type when the button is clicked. |
