#### Properties

![[en-us_image_0000002279757116.png]]

**Table 1** Properties  
| Name | Description |
| :-- | :-- |
| Edit Panel Content | Allows you to drag subcomponents to the iterator on the displayed sub-canvas. |
| Empty Message | Prompt message displayed when the original data is empty. |
| Column Size | Allows you to set the number of columns displayed in each row of the iterator. |
| Page Size | Allows you to set the number of iteration items displayed on each page of the iterator. |
| Pagination Or Carousel | Allows you to switch between pagination and carousel display. |
| Carousel Direction | Allows you to set the carousel direction. |
| Carousel Duration | Allows you to set the carousel duration. |
| Hover Pause | Specifies whether to enable the hover pause function. |
| Indicator Position | Allows you to set the carousel indicator position. |
| Indicator Default Style | Allows you to set the width and height of the carousel indicator in the default state. |
| Indicator Activation Style | Allows you to set the width and height of the carousel indicator in the activated state. |
| Fill Color | Allows you to set the carousel indicator color. |
| Item Width | Allows you to set the width of the iteration item (available when the width is sufficient; otherwise, the width is adaptive). |
| Item Height | Allows you to set the height of the iteration item (available when the height is sufficient; otherwise, the height is adaptive). |
| Column Spacing | Allows you to set the spacing between columns of the iteration item (available when the width is sufficient; otherwise, the spacing is 0). |
| Row Spacing | Allows you to set the spacing between rows of the iteration item (available when the height is sufficient; otherwise, the spacing is 0). |
