#### Properties

![[en-us_image_0000001556661730.png]]

**Table 1** Fundamental properties  
| Name | Description |
| :-- | :-- |
| Hidden | Whether to hide a component. If a component is hidden by default, components in the group can no longer use unified data sources. |
| Id | Component ID, which can be changed to a required value. |
| Size | The value includes width and height of the component. The unit is px. |
| Position | The value includes the horizontal coordinate and vertical coordinate of the component. The unit is px. The horizontal coordinate indicates the pixel distance between the upper left corner of the component and the left boundary of the page, and the vertical coordinate indicates the pixel distance between the upper left corner of the component and the upper boundary of the page. |
| Rotate | Rotation angle of the component with the center as the center point. The unit is degree (°). | ![[en-us_image_0000001556342390.png]]

**Table 2** Basic Properties  
| Name | Description |
| :-- | :-- |
| Placeholder | Used to hold prompt information or example of a field. The component is displayed before the focus is obtained. The component disappears after the focus is obtained. |
| Value | Initial value of the component. | ![[en-us_image_0000001607141993.png]]

**Table 3** Icon Configuration  
| Name | Description |
| :-- | :-- |
| Prefix Icon | Icon in the header of a text box. |
| Prefix Image | Image in the header of a text box. The priority is lower than that of the icon. |
| Suffix Icon | Icon at the end of a text box. |
| Suffix Image | Image at the end of a text box. The priority is lower than that of the icon. | ![[en-us_image_0000001607022241.png]]

**Table 4** Default Style  
| Name | Description |
| :-- | :-- |
| Font | Font style of the text box. |
| Background | Background style of the text box. |
| Border | Border style of the text box. |
| Padding | Inner margin of the text box. |
| Opacity | Transparency of the text box. | ![[en-us_image_0000001556342822.png]]

**Table 5** Hover Style  
| Name | Description |
| :-- | :-- |
| Font Color When Blur | Font color when the cursor is placed in the text box. |
| Background Color When Blur | Background color when the cursor is placed in the text box. |
| Border Color When Blur | Border color when the cursor is placed in the text box. | ![[en-us_image_0000001606862745.png]]

**Table 6** Activation Style  
| Name | Description |
| :-- | :-- |
| Font Focus Color | Font color when the text box gets the focus. |
| Background Focus Color | Background color when the text box gets the focus. |
| Border Focus Color | Border color when the text box gets the focus. |
