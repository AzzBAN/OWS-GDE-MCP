#### Canvas Operations

-   You can drag a component from the component library on the left to the canvas to add a component.
-   You can right-click a component in the canvas and choose **Copy**, **Move To Top**, **Move To Bottom**, **Move Up**, **Move Down**, or **Delete** from the shortcut menu.
-   You can select multiple components in the canvas, right-click a component, and choose **Create Group** from the shortcut menu to combine multiple components into a group for unified management. After being grouped, the components can be nested into another group. You can right-click a component in a group and choose **Delete Group** from the shortcut menu.
-   You can click ![[en-us_image_0000001851007429.png]] in the lower right corner of the canvas to view the shortcut keys supported by the canvas.
-   When two or more components are selected at the same time, you can align the components by clicking the **Top**, **Middle**, **Bottom**, **Left**, **Center**, or **Right** button.
    
    When three or more components are selected at the same time, you can arrange the components horizontally or vertically by clicking the **Horizontal** or **Vertical** button.
    
-   When multiple same components are selected at the same time, the properties of the upper-layer components are displayed on the right. You can modify the properties in batches.
