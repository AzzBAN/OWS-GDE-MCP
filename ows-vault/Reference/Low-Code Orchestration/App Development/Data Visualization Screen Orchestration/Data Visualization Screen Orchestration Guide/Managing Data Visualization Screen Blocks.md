#### Background

A block is a combination of multiple components and cards.

The system accumulates multiple blocks based on service scenarios for developers to use. When using a block, developers can instantiate, add, delete, or modify the component content in the block.

Developers can save orchestrated data visualization screen components as blocks for personal use or sharing.
