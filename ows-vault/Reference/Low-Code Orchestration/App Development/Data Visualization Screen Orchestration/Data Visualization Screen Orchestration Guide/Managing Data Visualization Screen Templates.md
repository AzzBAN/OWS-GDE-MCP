#### Background

You can select an existing data visualization screen template and create a data visualization screen based on the template to improve efficiency.

Alternatively, you can create a template and use it to create a data visualization screen. This can improve the efficiency of creating data visualization screens with similarities.

Similar to page templates created in projects, data visualization screen templates are global assets and have a permission system independent from projects.
