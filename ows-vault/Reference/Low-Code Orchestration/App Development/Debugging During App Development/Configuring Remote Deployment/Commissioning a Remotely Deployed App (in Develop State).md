#### Context

After developing an app in the develop-state environment, a developer can remotely deploy the app in different environments for testing and releasing.

![[note_3.0-en-us.png]]

Data orchestration-related apps strongly depend on data sources. Therefore, during remote deployment, ensure that the corresponding data source has been configured in the remote environment. This restriction does not apply to other orchestration scenarios.
