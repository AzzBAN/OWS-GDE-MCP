#### Prerequisites

-   A project has been orchestrated.
-   (Optional) If the AI quality detection capability needs to be enabled, ensure that you have completed the following operations:
    -   Contact the **master** tenant, set the system-level parameter **global\_aqm\_ai\_detection\_enabled** to **true**, and set **Enabling Policy** of the current tenant to **Enable** in the tenant-level Copilot configuration.
    -   Contact the tenant administrator and set the tenant-level parameter **aqm\_ai\_detection\_enabled** to **true**.
