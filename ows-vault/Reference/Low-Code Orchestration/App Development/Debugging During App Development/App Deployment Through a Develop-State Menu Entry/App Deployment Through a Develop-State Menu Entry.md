# App Deployment Through a Develop-State Menu Entry

App deployment through a develop-state menu entry refers to the entire process in which the system packages a project into a runtime-state app and deploys the app to the runtime-state environment. The deployment is mainly used for debugging in the development phase.

-   **[[Describing the Deployment Capabilities|Describing the Deployment Capabilities]]**  
    
-   **[[One-Click Deployment|One-Click Deployment]]**  
    One-click deployment allows you to package the current project into an app and install it in the runtime-state environment.
