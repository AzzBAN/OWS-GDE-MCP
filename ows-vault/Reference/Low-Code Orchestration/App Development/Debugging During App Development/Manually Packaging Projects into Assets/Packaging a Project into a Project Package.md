#### Context

Packaging a project into a project package is to export a project as a project package suffixed with .gdk. The exported project package can be imported to the develop-state environment for orchestration and modification.

When packaging a project package, you can set **Read-only**. If it is enabled, you cannot modify the project package when importing the project package to the environment again.

After the package is packaged, you can view the packaged assets on the **Asset Management** page.
