# Manually Packaging Projects into Assets

Developers can manually package projects into multiple types of assets.

-   **[[Packaging a Project into an App|Packaging a Project into an App]]**  
    An app is an entity that can be directly run in the runtime-state environment. You can package an app into a project and compile the project into an entity for running in the runtime-state environment.
-   **[[Packaging a Project into a Project Package|Packaging a Project into a Project Package]]**  
    A project that is edited online can be packaged into a project package for downloading and exporting assets in develop state.
-   **[[Packaging a Project into a Service Components (for Replication)|Packaging a Project into a Service Components (for Replication)]]**  
    
-   **[[Packaging a Project into a Service Components (for Running)|Packaging a Project into a Service Components (for Running)]]**  
    
-   **[[Packaging a Project into an Upgrade Package|Packaging a Project into an Upgrade Package]]**  
    An upgrade package, also called a patch package, is an incremental package of modules and elements.
-   **[[Managing Project Templates|Managing Project Templates]]**  
    A project template is used to create a project based on a specified template, improving project creation efficiency. In addition to the basic templates preset in the system, developers can customize templates.
