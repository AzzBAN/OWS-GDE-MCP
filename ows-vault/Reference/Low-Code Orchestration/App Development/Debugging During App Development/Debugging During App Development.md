-   **[[App Deployment Through a Develop-State Menu Entry|App Deployment Through a Develop-State Menu Entry]]**  
    App deployment through a develop-state menu entry refers to the entire process in which the system packages a project into a runtime-state app and deploys the app to the runtime-state environment. The deployment is mainly used for debugging in the development phase.
-   **[[Manually Packaging Projects into Assets|Manually Packaging Projects into Assets]]**  
    Developers can manually package projects into multiple types of assets.

    Through remote deployment, apps in the current system can be deployed in multiple remote systems. This section describes how to perform remote app deployment.
