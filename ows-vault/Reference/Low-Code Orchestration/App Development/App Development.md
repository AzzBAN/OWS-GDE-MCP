# App Development

-   **[[Setting Up a Project|Setting Up a Project]]**  
    A project is a basic concept in the develop-state environment. All orchestration elements belong to a project. You can manage these elements by project.
-   **[[Orchestration of Simple Object Management Apps|Orchestration of Simple Object Management Apps]]**  
    The simple object management apps are used to orchestrate basic elements, including models, services, events, timers, pages, documents, menus, data processing, and permission management.
-   **[[Configuring a Process|Configuring a Process]]**  
    A process is designed for a business object and is operated by different roles in different phases. This helps customers configure and develop processes in graphical mode.

-   **[[GDELink Mobile App Orchestration|GDELink Mobile App Orchestration]]**  
    To support mobile app development of GDE developers, GDELink provides visualized Web-based orchestration pages, rich orchestration resources, low-barrier drag-and-drop development mode, and flexible and convenient UI customization capabilities. In addition, it has the following advantages: native code expansion of the mobile app, integration of custom plugins, HTML5 apps, and applets, and flexible release and upgrade management modes for mobile apps to achieve custom packaging and release or upgrade management for services. GDELink provides multi-layer orchestration and development capabilities in multiple dimensions and at multiple intervals to enable ecosystem users and partners to quickly build mobile app capabilities and support efficient implementation of various mobile office solutions. This section describes how to orchestrate the GDELink mobile app.
